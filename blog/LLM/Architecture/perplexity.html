Perplexity

LLM

Perplexity is one of those metrics that everyone uses but not all people can explain clearly. Mathematically, perplexity is equivalent to cross-entropy loss in the sense that there is a one-to-one mapping between them. However, perplexity can be interpreted more intuitively: a perplexity of K means the model is, on average, as confused as if it were choosing uniformly among K equally likely words.

Cross-Entropy Loss

To understand perplexity, we first need to recall the cross-entropy loss. For a sequence of N tokens, each with a vocabulary of possible classes, the cross-entropy loss is:

Cross-Entropy = - sum_{i=1}^{N} sum_{j=1}^{K} I(y_i = j) * log(y_hat_j)

Here I(y_i = j) is the indicator function (1 if the true token is j, 0 otherwise) and y_hat_j is the model's predicted probability for class j.

Definition

Perplexity is defined as the exponential of the average cross-entropy loss:

Perplexity = exp(Cross-Entropy Loss / N)

where N is the number of predictions (tokens) in the sequence.

Why Perplexity is More Interpretable

The key advantage of perplexity over raw cross-entropy is interpretability.

If someone tells you the cross-entropy loss is 3.056, it is difficult to develop an intuition for what that number means in practical terms. How good or bad is the model?

A perplexity of 3.7 means the model is, on average, as confused as if it were choosing among 3.7 equally likely words at each position.

Proving the Interpretation

Why does perplexity correspond to the number of equally likely choices?

Suppose there are K words in the vocabulary, and the model has no idea which one to pick, assigning each word equal probability 1/K. Then:

Cross-entropy for N predictions:

        = - sum_{i=1}^{N} sum_{j=1}^{K} I(y_i = j) * log(1/K)

        = - sum_{i=1}^{N} log(1/K)

        = - sum_{i=1}^{N} (log(1) - log(K))

        = sum_{i=1}^{N} log(K)

        = N * log(K)

Now computing perplexity:

Perplexity = exp(N * log(K) / N) = exp(log(K)) = K

So when the model assigns uniform probability over K words, the perplexity is exactly K.

Interpreting Changes in Perplexity

Another benefit of perplexity is that improvements become easy to communicate:

When cross-entropy goes down by 10%, what does this mean concretely? Because cross-entropy is high unlinear, decreasing 10% from 1000 to 900 is not the same as decreasing 10% from 100 to 90. But if perplexity drops from 69 to 51, the interpretation is clearer: the model was previously confused among 69 equally likely words on average, and now it is only confused among 51.
