Linear Self-Attention

LLM

A concise handwritten version of this note is available as a PDF.

The idea behind linear self-attention is simple: computing (QK^T)V requires O(s^2) computational time, while computing Q(K^T V) requires only O(s). However, in order to switch the computational order, we need to replace softmax with something else that allows this reordering.

Recap: Standard Self-Attention

The standard self-attention mechanism computes:

Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V

The shapes of the matrices are:

  • Q: (seq, d_k)
  • K: (seq, d_k)
  • V: (seq, d_v)

Computational Complexity

Let s denote the sequence length, d the model dimension (d_k or d_v).

  • Computing QK^T: O(s^2 d) -- but since d is fixed and relatively small (e.g. 1024), this is effectively O(s^2)
  • Multiplying (QK^T) V: O(s^2 d) -- again effectively O(s^2)

The key problem is QK^T. Sequence length s can be very long, while d is fixed and relatively small. The s^2 term dominates and makes standard attention prohibitively expensive for long sequences.

The Solution: Linear Self-Attention

Linear self-attention replaces the softmax with a feature mapping function and changes the order of computation:

LinearAttention(Q, K, V) = phi(Q) (phi(K)^T V) / (phi(Q) (phi(K)^T 1))

There are three key ideas here:

1. Change the Order of Multiplication

In standard attention, we compute (Q K^T) V -- multiplying Q and K first produces an s x s matrix, then we multiply by V. In linear attention, we compute Q (K^T V) -- multiplying K and V first:

Standard:  (Q . K^T) . V
           O(s^2) + O(s^2 d)  =  O(s^2)

Linear:    Q . (K^T . V)
           O(s d^2) + O(s d)  =  O(s)

Since d is fixed and small relative to s, the linear version scales as O(s) rather than O(s^2). This is the fundamental insight -- by rearranging the associativity of matrix multiplication, we avoid ever forming the s x s attention matrix.

2. The Feature Mapping phi

We cannot simply reorder the multiplication in standard attention because softmax is applied to QK^T as a whole (it normalizes across columns for each row). Instead, we replace softmax with a feature mapping phi applied independently to Q and K, which allows the reordering.

A common choice for phi is:

phi(x) = ELU(x) + 1

where ELU(x) = { x           if x > 0
               { alpha(e^x - 1)  otherwise    (normally alpha = 1)

Why this choice? Three reasons:

  1. Forces all values to be positive. Since ELU(x) >= -1 for all x (with alpha=1), adding 1 ensures phi(x) >= 0. This is important because we want the feature-mapped values to act like unnormalized attention weights, which must be non-negative.
  2. Introduces non-linearity. Softmax is non-linear; a purely linear replacement would lose expressiveness. ELU + 1 preserves non-linear transformation of the inputs.
  3. Approximates the softmax kernel. Recall that in standard attention, the (i, j) entry of the attention matrix is proportional to exp(q_i . k_j). When we use feature mappings, phi(Q) phi(K)^T gives us entry phi(q_i) . phi(k_j). With the exponential in ELU, this loosely approximates the product of exponentials: e^(q_i,1) * e^(k_j,1) + ... + e^(q_i,d) * e^(k_j,d), which is related to exp(q_i . k_j) via a kernel decomposition.

3. The Normalization Denominator

The denominator phi(Q)(phi(K)^T 1) serves as the normalizing factor, analogous to how softmax normalizes attention weights to sum to 1. Expanding it:

phi(Q)(phi(K)^T 1) = [phi(q_i) . phi(k_j)]  summed over j
                   = sum_j  phi(q_i) . phi(k_j)

This is the sum of all "attention weights" for query i, ensuring the output is a proper weighted average of the values, just like standard attention.

Summary

  • Linear attention computes Q(K^T V) instead of (QK^T)V, avoiding the s x s matrix entirely -- O(s) instead of O(s^2)
  • A feature mapping phi (e.g., ELU + 1) replaces softmax to enable this reordering while keeping values non-negative
  • The denominator normalizes the output to be a proper weighted average, analogous to softmax normalization

Trade-off: linear attention is much faster for long sequences, but the approximation of softmax by the feature mapping means some expressive power is lost. In practice, linear attention works well for many tasks where sequence length is the bottleneck, but standard attention is better for harder tasks.
