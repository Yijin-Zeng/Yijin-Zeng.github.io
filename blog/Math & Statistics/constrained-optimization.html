Constrained Optimization

Mathematics

A concise handwritten version of this note is available as a PDF.

The Standard Form

We sometimes face constrained optimization problems:

(q)  min  f(x)
      x
          s.t. g_i(x) <= 0  for all i = 1, ..., m

This form is known as the standard form for constrained optimization problem. Any other formulation can be converted into this. For example, if we want to maximize f(x) rather than minimize it, we have max f(x) = min -f(x). Also, an equality constraint g(x) = 0 can be equivalently written into two inequalities: g(x) <= 0 and -g(x) <= 0.

The Penalty Method (Naive Approach)

To solve the constrained problem as described above, a simple (but may be impractical) idea is to convert the problem into an unconstrained problem by adding a penalty for violating constraints:

min  f(x) + sum_i I(g_i(x))
x

        where I(z) = 0     if z <= 0
                    +inf (or a large value if violating slightly is acceptable)  otherwise

The problem of this approach is that it makes optimization process hard. The infinite penalty creates walls in the loss surface; if gradient descent starts on the wrong side, it can never cross over. Even with a large finite penalty instead of infinity, the sharp discontinuity makes optimization extremely difficult.

Lagrange Multiplier Method

Instead of introducing penalty, let us consider how Lagrange multiplier method approach the constrained problem. First, define the Lagrangian form for the problem:

L(x, lambda) = f(x) + lambda^T g(x)

where lambda = (lambda_1, ..., lambda_m)^T
      g(x) = (g_1(x), ..., g_m(x))^T

Notice that the original problem (q) is now equivalent to:

(p)  min  max  L(x, lambda)
      x  lambda>=0

The reason is that for a feasible x (where all g_i(x) <= 0), the max over lambda >= 0 just gives f(x) since the lambda terms are non-positive. For an infeasible x, some g_i(x) > 0, and lambda can drive the Lagrangian to infinity. So the min-max formulation introduced by the Lagrangian form naturally enforces the constraints.

The Dual Problem

Next, we consider the so called dual problem of problem (p). First, notice that for any function phi(x, y), we have:

min phi(x,y) <= phi(x,y) <= max phi(x,y)
 x                             y

=> max min phi(x,y) <= min max phi(x,y)
    y   x              x   y

This gives us the Lagrange dual problem:

(d)  max  min  L(x, lambda)
    lambda  x
     s.t. lambda >= 0

Denote q(lambda) = min_x L(x, lambda) — this is called the inner problem. The dual problem in general much easier than the original problem (q). Consider the following three reasons:

  1. Simpler constraints: we go from g_i(x) <= 0 (which could be arbitrarily complex) to lambda_i >= 0 (simple box constraints, the easiest kind)
  2. Convexity: even if min f(x) is non-convex, max q(lambda) is always a convex problem
  3. Dimensionality reduction (in some cases): say x is in R^10000 and we have 5 constraints; the dual reduces the problem to only 5 dimensions

Solve the Dual Problem

We now consider how to solving the dual problem (d).

  1. Ideal case: we solve the (unconstrained) inner problem, get the analytical form for the vector x. Then we put the form of x back into the dual problem, solve the dual problem (by taking the gradient with respect to the vector λ and setting the result to zero), find the solutions for each λ_i >= 0, and we take the results as they are.
  2. Practical algorithm (dual ascent):
    1. Initialize: Start with an initial guess for the vector of penalty variables, λ, ensuring every individual penalty element starts at λ_i >= 0.
    2. Primal Update (Inner Problem): Using the currently fixed λ vector, computationally find the multi-dimensional vector x that minimizes the Lagrangian: x^(k+1) = argmin_x L(x, λ^k).
    3. Dual Update (Gradient Ascent): Evaluate the constraint violations for all m constraints, g_i(x^(k+1)). Update each penalty variable in the λ vector individually by taking a step in the direction of its specific gradient: λ_i^(k+1) = max(0, λ_i^k + α * g_i(x^(k+1))) (note that g_i(x^(k+1)) is the gradient wrt λ_i at x^(k+1)) for all i = 1, ..., m, where α is the step size. The max(0, ...) operation ensures no individual penalty ever drops below zero.
    4. Iterate: Repeat steps (b) and (c) until the vectors x and λ both stabilize and stop changing (convergence).

Duality Gap

Although the dual problem could be much easier than the original problem. Keep in mind that the results for the dual problem could be smaller than the original problem. The difference between the original and dual solutions is called duality gap:

G = q* - d*

where q* = optimal value of original problem
      d* = optimal value of dual problem
  • G = 0 (strong duality): the dual gives the exact solution
  • G > 0 (weak duality): the dual only gives a lower bound, which means the x found by the dual is not in the feasible region of the original problem

When Does Strong Duality Hold?

Naturally, we want to know when the strong duality would hold. A sufficient (but not necessary) condition is Slater's condition:

  1. Convexity: f(x) and all g_i(x) are convex
  2. Strict feasibility: there exists at least one x such that g_i(x) < 0 for all i (strictly inside the feasible region, not on the boundary)

Why might weak duality happen? In the inner problem min_x (f(x) + lambda^T g(x)), when g_i(x) > 0 (violating the constraint), we get a penalty lambda_i * g_i(x). But if f(x) is very small at that point, the violation might be worth it from the Lagrangian's perspective.

KKT Conditions

While the Lagrange method gives us a simpler dual problem, it doesn't directly solve the problem. We often solve constrained optimization directly using KKT (Karush-Kuhn-Tucker) conditions. These give a local minimum (or global, if Slater's condition holds).

The four conditions are:

  1. Stationarity: grad_x f(x) + lambda^T grad_x g(x) = 0 — at the minimum, the gradient of the Lagrangian must be zero
  2. Primal feasibility: g_i(x) <= 0 for all i — the solution must satisfy the original constraints
  3. Dual feasibility: lambda_i >= 0 for all i — multipliers must be non-negative
  4. Complementary slackness: lambda_i * g_i(x) = 0 for all i — either the constraint is active (g_i = 0) or its multiplier is zero

The complementary slackness condition is the most interesting one. Intuitively, it says that if a constraint is not tight (g_i(x) < 0 we're strictly inside the feasible region), then lambda_i = 0, i.e. that constraint doesn't matter at the optimum.

Using KKT to Find Solutions

KKT conditions are both a checklist to verify a candidate solution and a tool to find one:

  1. Guess which constraints are active (on the boundary); this follows complementary slackness condition which says for each constraint either g_i(x) = 0 or lambda_i = 0
  2. Solve for x and lambda from the stationarity and complementary slackness equations; suppose x is in R^k_1 and lambda is in R^k_2, then stationarity codition provides R^k_1 equations and complementary slackness provides R^k_2 equations
  3. Check feasibility; if it passes, found a local minimum. If not, go back to step 1 with a different guess

Different guesses in step 1 can give different local minima. With m constraints, there are 2^m possible combinations to try in the worst case. In some cases, the guess could be dramastically simpler. For example, if the target function is simply the sum of xi, then we can evaluate if each xi is on the boundary seperately.
