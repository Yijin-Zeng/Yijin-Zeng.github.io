Gaussian Identities

Mathematics

A concise handwritten version of this note is available as a PDF.

Gaussian distribution is arguably the most important single distribution (due to CLT), and it has a lot of interesting properties.

Univariate Gaussian Distribution

The density is

f(x; μ, σ) = 1/√(2πσ²) · exp(-(x-μ)²/(2σ²))

Showing It Is a Proper Distribution

Instead of solving ∫f(x;μ,σ)dx directly, we use a multiplication trick: pair the integral with a second copy of itself (over a dummy variable y) and switch to polar coordinates.

∫_R f(x;μ,σ)dx · ∫_R f(y;μ,σ)dy
= 1/(2πσ²) ∫_R∫_R exp( -((x-μ)²+(y-μ)²)/(2σ²) ) dx dy

Let (x-μ) = r cosθ, (y-μ) = r sinθ.

J = ∂(x,y)/∂(r,θ) = ( cosθ  -r sinθ )
                    ( sinθ   r cosθ )

|J| = r cos²θ + r sin²θ = r

Hence

∫_R f(x;μ,σ)dx · ∫_R f(y;μ,σ)dy
= 1/(2πσ²) ∫_0^{2π} ∫_0^∞ exp(-r²/(2σ²)) r dr dθ
= 1/(2πσ²) ∫_0^{2π} [ -σ² exp(-r²/(2σ²)) ]_0^∞ dθ
= 1/(2πσ²) ∫_0^{2π} σ² dθ
= 1/(2πσ²) · 2πσ² = 1

Both factors in the product are the same integral (just with the variable renamed), and both are positive, so if their product is 1, each one individually must equal 1.

Deriving Its Moment Generating Function

So what does its moment generating function look like?

E(e^{tX}) = ∫ e^{tx} · 1/√(2πσ²) exp(-(x-μ)²/(2σ²)) dx

= 1/√(2πσ²) ∫ exp( tx - (x² + μ² - 2μx)/(2σ²) ) dx

= 1/√(2πσ²) ∫ exp( -1/(2σ²) ( x² - 2μx - 2σ²tx + μ² ) ) dx

= 1/√(2πσ²) ∫ exp( -1/(2σ²) ( (x - (μ+σ²t))² - σ⁴t² - 2μσ²t ) ) dx

= exp( σ²t²/2 + μt ) · 1/√(2πσ²) ∫ exp( -1/(2σ²)(x-(μ+σ²t))² ) dx

= exp( σ²t²/2 + μt )

If μ = 0, σ = 1, we have E(e^{tX}) = e^{t²/2}. Differentiating this MGF successively at t = 0 gives the raw moments of the standard normal:

E(X)  = ( t e^{t²/2} )|_{t=0} = 0
E(X²) = ( e^{t²/2} + t² e^{t²/2} )|_{t=0} = 1
E(X³) = ( t e^{t²/2} + 2t e^{t²/2} + t³ e^{t²/2} )|_{t=0} = 0
E(X⁴) = ( e^{t²/2} + t² e^{t²/2} + 2t² e^{t²/2} + 2t² e^{t²/2} + 3t² e^{t²/2} + t⁴ e^{t²/2} )|_{t=0} = 3

Multivariate Gaussian Distribution

f(x; μ, Σ) = (2π)^{-n/2} det(Σ)^{-1/2} exp( -1/2 (x-μ)^T Σ^{-1} (x-μ) )

Showing It Is a Proper Distribution

I = ∫_{R^n} exp( -1/2 (x-μ)^T Σ^{-1} (x-μ) ) dx
  = ∫_{R^n} exp( -1/2 y^T Σ^{-1} y ) dy     (y = x - μ)

Since Σ is a valid covariance matrix, we must have Σ = SΛS^T, where S is orthonormal and Λ is diagonal with λ_i > 0. So Σ^{-1} = SΛ^{-1}S^T, and

y^T Σ^{-1} y = y^T S Λ^{-1} S^T y = z^T Λ^{-1} z,   where z = S^T y

Because S is an orthogonal matrix, ∂z/∂y = S, so |det(S)| = 1 (since SS^T = I ⇒ |S||S^T| = 1 ⇒ det(S) = ±1). So we have

I = ∫_{R^n} exp( -1/2 z^T Λ^{-1} z ) dz
  = ∫_{R^n} exp( Σ_i -z_i²/(2λ_i) ) dz_1...dz_n
  = Π_i √(2πλ_i)
  = (2π)^{n/2} |Σ|^{1/2}         since |Σ| = |S||Λ||S^T| = |Λ| = Π_i λ_i

This makes f integrate to (2π)^{-n/2}|Σ|^{-1/2} · (2π)^{n/2}|Σ|^{1/2} = 1. Along the way, this also gives the two directions we use constantly: if Z ~ N(0,I) then Σ^{1/2}Z + μ ~ N(μ,Σ); and if X ~ N(μ,Σ) then Σ^{-1/2}(X-μ) ~ N(0,I).

Mean and Variance of the Multivariate Gaussian

E(X) = ∫_{R^n} (2π)^{-n/2} det(Σ)^{-1/2} x exp( -1/2 (x-μ)^T Σ^{-1} (x-μ) ) dx

     = ∫_{R^n} (2π)^{-n/2} det(Σ)^{-1/2} (y+μ) exp( -1/2 y^T Σ^{-1} y ) dy   (y = x-μ)

     = μ + ∫_{R^n} (2π)^{-n/2} det(Σ)^{-1/2} y exp( -1/2 y^T Σ^{-1} y ) dy
                                                └──────────── = 0 due to symmetry ────────────┘

     = μ

For the covariance, Cov(X) = E((X-μ)(X-μ)^T):

Cov(X) = ∫_{R^n} (x-μ)(x-μ)^T (2π)^{-n/2} det(Σ)^{-1/2} exp( -1/2 (x-μ)^T Σ^{-1} (x-μ) ) dx

       = ∫_{R^n} y y^T (2π)^{-n/2} det(Σ)^{-1/2} exp( -1/2 y^T Σ^{-1} y ) dy   (y = x-μ)

Let z = Σ^{-1/2} y,  so y = Σ^{1/2} z:

       = ∫_{R^n} Σ^{1/2} z z^T Σ^{1/2} (2π)^{-n/2} det(Σ)^{-1/2} exp( -1/2 z^T z ) |det(Σ^{1/2})| dz

       = Σ^{1/2} ( ∫_{R^n} z z^T (2π)^{-n/2} exp(-1/2 z^Tz) dz ) Σ^{1/2}
                    └──────────────── all independent now, this integral = I ────────────────┘

       = Σ^{1/2} I Σ^{1/2}

       = Σ

Conditional Distribution

If (X,Y) ~ N( (μ_x; μ_y), (Σ_xx Σ_xy; Σ_yx Σ_yy) ), then what is Y|X?

f_{X,Y}(x,y; μ,Σ) = (2π)^{-n/2} det(Σ)^{-1/2} exp( -1/2 (x-μ_x; y-μ_y)^T Σ^{-1} (x-μ_x; y-μ_y) )

Let Λ = Σ^{-1} be the precision matrix. (Note the note briefly reuses the same letter Λ here as the diagonal eigenvalue matrix from the earlier eigendecomposition Σ = SΛS^T — Λ = Σ^{-1} = (SΛS^T)^{-1} = SΛ^{-1}S^T — but the resulting object, block-partitioned below, is the precision matrix, not the eigenvalue matrix.) It is positive-definite as well:

Λ = ( Λ_xx  Λ_xy )
    ( Λ_yx  Λ_yy )

where Λ_xx and Λ_yy are symmetric, and Λ_xy = Λ_yx^T

Expanding the joint density's quadratic form in block form:

-1/2 (x-μ_x; y-μ_y)^T Λ (x-μ_x; y-μ_y)

= -1/2 ( (x-μ_x)^T Λ_xx (x-μ_x) + (y-μ_y)^T Λ_yx (x-μ_x)
         + (x-μ_x)^T Λ_xy (y-μ_y) + (y-μ_y)^T Λ_yy (y-μ_y) )

Now note that f_{Y|X}(y|x;μ,Σ) = f_{X,Y}(x,y;μ,Σ) / f_X(x;μ,Σ) is a function of y only, given x. Keeping only the terms that depend on y and folding everything else into a constant:

-1/2 (x-μ_x; y-μ_y)^T Λ (x-μ_x; y-μ_y)

= -1/2 ( y^T Λ_yy y + 2y^T ( Λ_yx(x-μ_x) - Λ_yy μ_y ) ) + const

= -1/2 ( y^T Λ_yy y + 2y^T Λ_yy ( Λ_yy^{-1} Λ_yx(x-μ_x) - μ_y ) ) + const

Note that any multivariate Gaussian distribution has the exponent

-1/2 (x-μ)^T Σ^{-1} (x-μ) = -1/2 ( x^T Σ^{-1} x - x^T Σ^{-1} μ - μ^T Σ^{-1} x ) + const
                            = -1/2 ( x^T Σ^{-1} x - 2x^T Σ^{-1} μ ) + const
                                     └─ quadratic term ─┘   └─ linear term ─┘

Matching the quadratic term in y gives Cov(Y|X) = Λ_yy^{-1} (and symmetrically Cov(X|Y) = Λ_xx^{-1}), and matching the linear term gives

E(Y|X) = μ_y - Λ_yy^{-1} Λ_yx (x-μ_x)      (symmetrically:  E(X|Y) = μ_x - Λ_xx^{-1} Λ_xy (y-μ_y) )

Now, the problem is to express the precision matrix Λ = Σ^{-1} = (Λ_xx Λ_xy; Λ_yx Λ_yy) using Σ = (Σ_xx Σ_xy; Σ_yx Σ_yy). To do this, we apply the Schur complement based on Gaussian elimination. For a generic block matrix (A B; C D):

( A  B ) ( I        0 )   ( A-BD^{-1}C   B )
( C  D ) (-D^{-1}C  I ) = (      0       D )

( I  -BD^{-1} ) ( A-BD^{-1}C   B )   ( A-BD^{-1}C   0 )
( 0    I      ) (      0       D ) = (      0       D )

So we have

( I  -BD^{-1} ) ( A  B ) ( I        0 )   ( A-BD^{-1}C   0 )
( 0    I      ) ( C  D ) (-D^{-1}C  I ) = (      0       D )

=> ( A  B )   ( I  BD^{-1} ) ( A-BD^{-1}C   0 ) ( I       0 )
   ( C  D ) = ( 0    I     ) (      0       D ) ( D^{-1}C I )

=> ( A  B )^{-1}   ( I        0 ) ( (A-BD^{-1}C)^{-1}   0     ) ( I  -BD^{-1} )
   ( C  D )      = (-D^{-1}C  I ) (        0          D^{-1} ) ( 0     I     )

           ( I        0 ) ( M   0     ) ( I  -BD^{-1} )
         = (-D^{-1}C  I ) ( 0  D^{-1} ) ( 0     I     )

           ( M            0     ) ( I  -BD^{-1} )
         = (-D^{-1}CM    D^{-1} ) ( 0     I     )

           (       M              -MBD^{-1}      )
         = ( -D^{-1}CM     D^{-1}CMBD^{-1}+D^{-1} )

where M = (A - BD^{-1}C)^{-1}
