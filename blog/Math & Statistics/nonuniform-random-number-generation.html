Nonuniform Random Number Generation

Mathematics

A concise handwritten version of this note is available as a PDF.

Most random number generators only give us samples from Uniform(0,1). The question we look at here is how to turn those uniform samples into samples from some other distribution F(x).

Inversion Method

Let U ~ Uniform(0,1), and let X ~ F(x) where F^{-1}(·) exists. Then

F^{-1}(U) ~ F(x)

Proof:

P(F^{-1}(U) ≤ x) = P(U ≤ F(x)) = F(x)

So if we can compute the inverse CDF, we can plug a uniform sample straight into it and get a sample from the target distribution.

Example: generate the exponential distribution. We have f_X(x) = λe^{-λx}. Integrating gives the CDF:

F(x) = λ ∫_0^x e^{-λz} dz
     = λ ( -1/λ e^{-λz} |_{z=0}^{x} )
     = λ ( 1/λ - 1/λ e^{-λx} )
     = 1 - e^{-λx}

Let y = 1 - exp(-λx). Solving for x:

exp(-λx) = 1 - y
=> -λx = log(1-y)
=> x = log(1-y) / (-λ)

so F^{-1}(x) = log(1-x) / (-λ). Combined with the inversion result above,

log(1-U) / (-λ) ~ Exp(λ)

The problem with this method is that not all distributions have F^{-1}(·) in closed form. For example, the Gaussian distribution has no explicit form for F^{-1}(·).

Acceptance-Rejection Method

Suppose we have a density function f we cannot directly sample from, but we can sample from another density function g, such that there exists a constant C < ∞ with

f(x) ≤ Cg(x), ∀x

Then the acceptance-rejection method does:

While True:
    X ~ g(x)
    U ~ Uniform(0,1)
    if U ≤ f(X) / (Cg(X)):
        accept X

Proof that the accepted samples follow f:

P(X ≤ z | U ≤ f(X)/(Cg(X)))
= P(X ≤ z, U ≤ f(X)/(Cg(X))) / P(U ≤ f(X)/(Cg(X)))
= [ ∫_{-∞}^{z} ∫_0^{f(x)/(Cg(x))} g(x) du dx ] / [ ∫_{-∞}^{∞} ∫_0^{f(x)/(Cg(x))} g(x) du dx ]
= [ ∫_{-∞}^{z} f(x)/C dx ] / [ ∫_{-∞}^{∞} f(x)/C dx ]
= ∫_{-∞}^{z} f(x) dx
= F_X(z)

The inner integral over U just picks up the height f(x)/(Cg(x)), which cancels one factor of g(x) and leaves f(x)/C. The C in the denominator then cancels against the C in the numerator, leaving exactly the CDF of f.

Box-Muller Method

Let θ ~ Uniform(0, 2π) and R² ~ Exp(1/2). If R² ~ Exp(1/2), then

P(R < r) = P(R² < r²)
         = ∫_0^{r²} 1/2 e^{-z/2} dz
         = 1 - e^{-r²/2}

Differentiating gives the density of R:

f_R(r) = (-e^{-r²/2})′ = r e^{-r²/2}

Now let X = R cosθ, Y = R sinθ. The claim is that X, Y ~ N(0,1), independently.

Proof: Denote the map f((R,θ)) = (X,Y). Since X = Rcosθ, Y = Rsinθ, we have

X² + Y² = R²  =>  R = √(X²+Y²) = (X²+Y²)^{1/2}

Also, Y/X = tanθ, so θ = tan^{-1}(Y/X). So f^{-1} exists, and the Jacobian of (R,θ) with respect to (x,y) is

J = [ x(x²+y²)^{-1/2}          y(x²+y²)^{-1/2}       ]
    [ -1/(1+(y/x)²) · y/x²     1/(1+(y/x)²) · 1/x   ]

Taking the determinant:

|J| = x(x²+y²)^{-1/2} · 1/(1+(y/x)²) · 1/x
      + y(x²+y²)^{-1/2} · 1/(1+(y/x)²) · y/x²
    = (x²+y²)^{-1/2} · 1/(1+(y/x)²) · (1 + y²/x²)
    = (x²+y²)^{-1/2}
    = 1/√(x²+y²)

So the joint density of X, Y is

f_{X,Y}(x,y) = f_R(r) · f_θ(θ) · |J|
             = √(x²+y²) · exp(-1/2(x²+y²)) · 1/(2π) · 1/√(x²+y²)
             = 1/(2π) exp(-1/2(x²+y²))
             = 1/√(2π) exp(-x²/2) · 1/√(2π) exp(-y²/2)

which factors into the product of two independent standard normal densities. So drawing θ ~ Uniform(0,2π) and R² ~ Exp(1/2) and setting X = Rcosθ, Y = Rsinθ gives two independent samples from N(0,1), without ever needing the Gaussian inverse CDF.

(Box & Muller, 1958.)
