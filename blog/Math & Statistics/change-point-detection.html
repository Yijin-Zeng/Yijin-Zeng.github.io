A concise review for change point detection methods

Statistics

A more formal, technical review is available as a PDF.

Change point detection is about spotting when something changes fundamentally in the data. Think of it like watching a heart rate monitor: most of the time it's steady, but when something happens, e.g. exercise, stress, rest, the pattern changes. It is often very useful to detect these transition moments accurately, and quickly.

Why Does This Matter?

Change point detection is a very important topic in statistics and machine learning, because change points can show up everywhere, and we often want to detect them as quickly as possible. Consider the following fields and cases:

  • Finance: financial markets are notoriously volatile. This unpredictability comes from the inherent noise in the data, meaning that even if a model is 'true', there is still randomness. However, it also comes from 'change points', which are unexpected, permanent shifts in the underlying 'true model' over time. Detecing such change points is definitely a billion dolloars question. For a practical example of this problem, look at the ADIA Lab Structural Break Challenge .
  • Manufacturing: during manufacturing, we want to know when a machine starts malfunctioning as quickly as possible. For instance, consider a production line calibrated to yield items weighing 100g (±10g). If a mechanical fault occurs, the machine might abruptly shift to producing 200g items.
  • Health: we can continuously monitor people's key health metrics (e.g. using Apple watch), like heart rate, blood pressure, and blood sugar to track their overall condition. A fundamental change in one of these metrics can signal the onset of a disease or a medical event that requires proactive intervention.

Key challenges

As in many other fields, change point detection is a balancing act. There are many inherent trade-offs we can encounter, most dominantly:

  • Detection Delay vs. False Alarm Rate: We almost always want to detect a shift as soon as it happens (low detection delay). At the same time, we want to avoid flagging changes when the system is actually stable (low false alarm rate). Unfortunately, these two goals conflict. A highly sensitive algorithm tends to generate more false alarms. Consider the extreme case of an algorithm that flags every single data point as a change point: it would detect real changes instantly, but its false alarm rate would be so high that the model is completely useless.
  • Detection Delay vs. Computational Burden: Change point detection algorithms can become quite complex, e.g. methods based on neural networks or Gaussian processes. Generally, a more complex algorithm yields a lower detection delay, but requires significantly more computational power. Time and memory complexity are crucial considerations in change point detecion, especially in scenarios where we can receive millions of data points per second, e.g. in cyber security.

Change Point Detection Methods

Introduction

We provide intuitive explanations for some of the most frequently used change point detection methods. We divide them into two categories: single change point methods, which assume there is only one shift in the sequence, and multiple change point methods, which can handle sequences with several shifts. However, we shouldn't view these categories as completely separate, since many multiple change point methods are actually adaptations of single change point techniques.

Single Change Point Methods

Consider observations $y = (y_1, \dots, y_n)$, where each $y_i \in \mathbb{R}$. We assume $y$ is a realization from a random sequence $Y = (Y_1, \dots, Y_n)$ such that $Y_1, \dots, Y_\tau \sim F_1$ and $Y_{\tau+1}, \dots, Y_n \sim F_2$, where $F_1$ and $F_2$ are unknown cumulative density functions. Our goal is to decide whether $F_1 = F_2$, and if not, provide an estimate $\hat{\tau}$ of $\tau$.

1. Cumulative Sum (CUSUM)

CUSUM is a foundational algorithm for sequential change point detection proposed by Page (1954).

The statistic: CUSUM computes

$$S_m = \sum_{i=1}^{m} \log\frac{f_2(y_i)}{f_1(y_i)} - \min_{k \le n} \sum_{i=1}^{k} \log\frac{f_2(y_i)}{f_1(y_i)}$$

where $f_1$ and $f_2$ are the density functions of $F_1$ and $F_2$ respectively. This can be computed recursively as

$$S_m = \max\!\left(S_{m-1} + \log\frac{f_2(y_i)}{f_1(y_i)},\, 0\right)$$

which makes it suitable for online (sequential) change point detection.

Normal case: Suppose $F_1$ and $F_2$ are both univariate normal distributions with means $\mu_1$ and $\mu_2$ ($\mu_2 > \mu_1$) and the same variance $\sigma^2$. Then the CUSUM statistic simplifies to

$$S_m = \max\!\left(S_{m-1} + y_m - \frac{\mu_1 + \mu_2}{2},\, 0\right)$$

Detection rule: CUSUM flags a change point when $S_m$ exceeds a pre-defined threshold $L$. The threshold is typically chosen to control the false alarm probability, often via Monte Carlo simulations under the null hypothesis.

Key property: When data are normally distributed and all parameters are known, CUSUM guarantees optimal performance in terms of detection delay (Lorden, 1971). However, in practice, parameters are often unknown, which degrades performance.

2. Likelihood Ratio Test

Hinkley (1970) considers the likelihood ratio test for change point detection. Suppose each $Y_i$ follows a distribution $F$ with probability density function $f$ independently. The estimated change point $\hat{\tau}$ maximizes the likelihood function:

$$L(t) = \sum_{i=1}^{t} \log f(y_i, \theta_1) + \sum_{i=t+1}^{n} \log f(y_i, \theta_2)$$

where $\theta_1$ and $\theta_2$ are parameters that may differ before and after the change point.

Test statistic: To test whether a change point exists, we compute

$$S = 2\left(L(\hat{\tau}) - \sum_{i=1}^{n} \log f(y_i, \theta)\right)$$

where $\theta$ is the parameter estimate under the null hypothesis of no change. If $S$ exceeds a threshold $c$, we conclude a change point exists at $\hat{\tau}$.

Normal case: When $\theta_1$ and $\theta_2$ are unknown parameters in a normal distribution, the asymptotic distribution of $\hat{\tau}$ is known (Hinkley, 1970). The challenge is deriving the asymptotic distribution of $S$ under the null hypothesis for general distributions—examples for normal, gamma, and Poisson cases are discussed by Chen and Gupta (2012).

The threshold problem: Choosing $c$ is non-trivial. One approach uses the Bonferroni inequality to control false alarm probability, but this bound is overly conservative for large $n$. When parameters are unknown and must be estimated, the generalized likelihood ratio (GLR) statistic can become very insensitive to real change points, as noted by Hawkins et al. (2003).

3. t-Test Based Detection

Hawkins et al. (2003) propose a more practical approach when parameters $\mu_1$, $\mu_2$, and $\sigma$ are unknown. Suppose the pre- and post-change distributions are Gaussian but with unknown parameters:

$$\begin{aligned} Y_i &\sim \mathcal{N}(\mu_1, \sigma^2) \quad \text{for } i = 1, 2, \dots, \tau \\ Y_i &\sim \mathcal{N}(\mu_2, \sigma^2) \quad \text{for } i = \tau + 1, \dots, T \end{aligned}$$

The algorithm: For any candidate split point $j$, define:

  • $\bar{Y}_{jn} = \frac{1}{j} \sum_{i=1}^{j} Y_i$ as the sample mean of observations 1 to $j$
  • $\bar{Y}'_{jn} = \frac{1}{n-j} \sum_{i=j+1}^{n} Y_i$ as the sample mean of observations $j$+1 to $n$
  • $V_{jn} = \sum_{i=1}^{j} (Y_i - \bar{Y}_{jn})^2 + \sum_{i=j+1}^{n} (Y_i - \bar{Y}'_{jn})^2$ as the residual sum of squares

For each $j$, compute the two-sample $t$-statistic:

$$T_{jn} = \sqrt{\frac{j(n-j)}{n}} \cdot \frac{\bar{Y}_{jn} - \bar{Y}'_{jn}}{\hat{\sigma}_{jn}}$$

where $\hat{\sigma}_{jn} = V_{jn}/(n-2)$. If $Y_1, \dots, Y_n$ are i.i.d. $\mathcal{N}(\mu_1, \sigma)$, then $T_{jn}$ follows a $t$-distribution with $n-2$ degrees of freedom.

Detection rule: Define

$$T_{\max,n} = \max_j T_{jn} \qquad \text{and} \qquad \hat{\tau}_n = \arg\max_j T_{jn}$$

If $T_{\max,n}$ exceeds a decision threshold $h_n$, we conclude $\mu_1 \ne \mu_2$ and estimate the change point as $\hat{\tau}_n$.

The problem of choosing a threshold: Setting $h_n$ requires careful calibration. One could use the Bonferroni inequality, but as Hawkins et al. (2003) note, this bound is overly conservative for large $n$. In practice, Monte Carlo simulation is often the most reliable approach. The same threshold challenge arises in the likelihood ratio approach—while we can control the false alarm rate theoretically, doing so without being overly conservative is difficult when the process is in control and $n$ is large.

4. Rank-Based Detection

Hawkins and Deng (2010) develop a distribution-free change point detection method using ranks. This approach works without assuming any specific distribution, making it highly robust.

The rank statistic: Define

$$D_{ij} = \mathrm{sgn}(Y_i - Y_j) = \begin{cases} 1, & \text{if } Y_i > Y_j \\ 0, & \text{if } Y_i = Y_j \\ -1, & \text{if } Y_i < Y_j \end{cases}$$

Then compute

$$U_{k,n} = \sum_{i=1}^{k} \sum_{j=k+1}^{n} D_{ij}, \qquad 1 \le k \le n-1$$

and the normalized test statistic

$$T_{k,n} = \frac{U_{k,n}}{\sqrt{k(n-k)(n+1)/3}}$$

Asymptotic distribution: Under the null hypothesis $H_0$: $\theta = 0$ (no change), by relating $T_{k,n}$ to the Mann-Whitney statistic, we have

$$T_{k,n} \to \mathcal{N}(0,1) \quad \text{as } n, k \to \infty$$

Detection rule: Define

$$T_{\max,n} = \max_k T_{k,n} \qquad \text{and} \qquad \hat{\tau}_n = \arg\max_k T_{k,n}$$

If $T_{\max,n}$ exceeds threshold $h_n$, reject $H_0$ and estimate the change point as $\hat{\tau}_n$. Due to the difficulty of analytically determining $h_n$ for a given false alarm probability, Monte Carlo simulations are typically used.

Why ranks work: By using only the relative ordering of observations, this method is completely robust to outliers and works for any continuous distribution. Similar rank-based approaches using Kolmogorov-Smirnov and Cramér-von Mises tests are discussed by Ross and Adams (2012).

Multiple Change Point Methods

In practice, data sequences often contain multiple change points rather than just one. Suppose we observe $y = (y_1, y_2, \dots, y_n)$, where $y_i \in \mathbb{R}$ and $y$ is a realization of random sequence $Y = (Y_1, Y_2, \dots, Y_n)$. The sequence is piecewise i.i.d. with a set of change points $\tau = (\tau_1, \dots, \tau_m)$, where each $\tau_i \in \mathbb{N}$, $\tau_0 = 1$, $\tau_{m+1} = n$, and $\tau_i < \tau_j$ if and only if $i < j$.

The change points partition $Y$ into segments such that

$$\begin{aligned} Y_{\tau_j}, \dots, Y_{\tau_{j+1}} &\sim F_j, \quad j = 0, \dots, m \\ F_i &\ne F_{i+1}, \quad i = 0, \dots, m-1 \end{aligned}$$

For notational convenience, we'll denote the sequence $y_a, y_{a+1}, \dots, y_b$ as $y_{a:b}$.

1. Binary Segmentation

Binary segmentation (Scott and Knott, 1974) is a popular greedy algorithm that has become one of the best-performing methods for practical change point detection problems (Killick and Eckley, 2014; van den Burg and Williams, 2020).

The recursive algorithm: Binary segmentation adapts a single change point test statistic and applies it recursively. First, apply the test to the entire sequence. If a change point is detected, split the sequence at that point. Then apply the procedure recursively to each segment until no further change points are found.

Mathematical formulation: Specifically, Scott and Knott (1974) assume $Y_i$ are independent and follow $\mathcal{N}(\mu_i, \sigma)$. They test the null hypothesis $H_0$: $\mu_1 = \mu_2 = \dots = \mu_n$ against the alternative that $\mu_i$ takes one of two possible values $m_1$ or $m_2$. To implement binary segmentation, first find the partition $B_0$ that maximizes the between-groups sum of squares:

$$B_0 = \arg\max_t \left[\left(\sum_{i=1}^{t} y_i - \sum_{i=t+1}^{n} y_i\right)^2 + \left(\sum_{i=t+1}^{n} y_i - \sum_{i=1}^{t} y_i\right)^2\right]$$

The maximum likelihood estimate of the variance is

$$\hat{\sigma}^2 = \frac{1}{n} \sum_{i=1}^{n} \left(y_i - \frac{1}{n}\sum_{j=1}^{n} y_j\right)^2$$

Under $H_0$ (equal means in both groups), the test statistic

$$\lambda = \frac{\pi}{2(\pi-2)} \cdot \frac{B_0}{\hat{\sigma}^2}$$

is asymptotically $\chi^2$-distributed. If $\lambda$ leads to rejection of $H_0$, repeat the procedure on the two resulting segments until no further rejections occur.

The greedy limitation: If the first split isn't optimal, all subsequent splits inherit that error. Binary segmentation works best when there's one dominant change, but can struggle with multiple subtle shifts.

2. Wild Binary Segmentation (WBS)

Wild Binary Segmentation (Fryzlewicz, 2014) addresses the greedy nature of binary segmentation through randomization. Rather than always testing the full sequence, WBS is motivated by the observation that binary segmentation performs poorly when multiple change points are clustered.

The random sampling approach: Unlike binary segmentation, WBS doesn't attempt to estimate change points using the whole sequence directly. Instead, Fryzlewicz (2014) proposes randomly sampling many subintervals ($Y_s$, $Y_{s+1}$, $\dots$, $Y_e$), where $s$ and $e$ are integers with $1 \le s < e \le n$. Then compute the CUSUM statistic for all subintervals:

$$Y^b_{s:e} = \sqrt{\frac{e-b}{n(b-s+1)}} \sum_{i=s}^{b} Y_i - \sqrt{\frac{b-s+1}{n(e-b)}} \sum_{i=b+1}^{e} Y_i$$

The largest $|Y^b_{s:e}|$ among all subintervals is taken as the candidate change point for the entire sequence. A hypothesis test is performed under the null that the candidate is not a change point. If the null is rejected, split the sequence at this point and apply the procedure recursively until no further rejections occur.

Why randomization helps: By testing many random windows instead of just the full sequence, WBS avoids committing to a potentially suboptimal first split. This makes it particularly effective when change points are close together or when the first change isn't the most pronounced.

3. Pruned Exact Linear Time (PELT)

PELT (Killick et al., 2012) builds on work by Jackson et al. (2005), who propose a greedy search algorithm for multiple change points. Unlike binary segmentation and wild binary segmentation, which greedily search for multiple change points, Jackson et al. (2005) and Killick et al. (2012) estimate all change points simultaneously by solving an optimization problem.

The optimization framework: The goal is to minimize

$$\min_{\tau \in \{1,\dots,n\}} \left\{\sum_{i=1}^{m+1} c(y_{\tau_{i-1}+1:\tau_i})\right\} + \beta f(m)$$

where $c(\cdot)$ is a segmentation cost function (e.g., variance of the sub-sequence), and $\beta f(m)$ is a penalty term for preventing overfitting. The cost function is designed to be sensitive to the presence of change points in the subsequence: if the subsequence doesn't contain change points, the cost value should be small; otherwise, it should be large. The penalty term prevents over-segmentation by penalizing the number of change points detected.

Jackson et al.'s recursion: Jackson et al. (2005) consider the case $\beta f(m) = \beta m$ and show that

$$\begin{aligned} F(y_{1:n}) &= \min_{\tau \in \{1,\dots,n\}} \left\{\sum_{i=1}^{m+1} \left[c(y_{\tau_{i-1}+1:\tau_i}) + \beta\right]\right\} \\ &= \min\left\{F(y_{1:t}) + c(y_{t+1:n}) + \beta\right\} \end{aligned}$$

This recursive formulation allows the problem to be solved via dynamic programming. However, the computational time for the recursive search is high, as noted by Killick et al. (2012).

The pruning strategy: Killick et al. propose an efficient pruning strategy to reduce computational time. If $c(\cdot)$ satisfies the condition that for all $t < s < T$,

$$c(y_{t+1:s}) + c(y_{s+1:T}) + K \le c(y_{t+1:T})$$

then if

$$F(y_{1:t}) + c(y_{t+1:s}) + K \ge F(y_{1:s})$$

at any future time $T > s$, $t$ can never be the optimal last change point prior to $T$ and can be pruned from consideration. This pruning process dramatically reduces computational complexity while preserving the accuracy of the original algorithm by Jackson et al. (2005), achieving $O(mn^2)$ time complexity in the worst case but often approaching linear time in practice.

4. Nonparametric Maximum Likelihood

Zou et al. (2014) consider a nonparametric maximum likelihood approach that makes no distributional assumptions. The key insight is that for $n$ univariate random variables $Y_1, Y_2, \dots, Y_n \sim F$, the empirical cumulative distribution function $\hat{F}(\mu)$ of $y_1, \dots, y_n$ satisfies

$$n\hat{F}(\mu) \sim \mathrm{Binomial}(n, F(\mu))$$

for any fixed $\mu$.

The likelihood function: Assume there are $m$ change points and denote the empirical cumulative distribution function of $y_{\tau_j:\tau_{j+1}}$ as $\hat{F}^{\tau_j+1}(\mu)$. For fixed $\mu$, the log-likelihood can be written as

$$L(\tau_1, \dots, \tau_m) = \sum_{k=0}^{m} (\hat{\tau}_{k+1} - \hat{\tau}_k) \left\{\hat{F}^{\tau_k+1}(\mu) \log \hat{F}^{\tau_k+1}(\mu) + \left[1 - \hat{F}^{\tau_k+1}(\mu)\right] \log\left[1 - \hat{F}^{\tau_k+1}(\mu)\right]\right\}$$

For each fixed $\mu$, the likelihood $L(\tau_1, \dots, \tau_m)$ is expected to increase as each $\tau_i \to \tau_i$. Hence one approach estimates the change points $\tau$ by maximizing the likelihood function $L(\tau_1, \dots, \tau_m)$ directly.

Dealing with $\mu$ dependence: However, the estimated change points depend on the choice of $\mu$, which is hard to choose in practice. To overcome this, Zou et al. (2014) suggest choosing a weight function $w(\mu)$ and maximizing the integrated likelihood

$$R(\tau_1, \dots, \tau_m) = \int_{-\infty}^{\infty} L(\tau_1, \dots, \tau_m)\, dw(\mu)$$

where, in their implementation,

$$dw(\mu) = \left\{\hat{F}_1^n(\mu)\left(1 - \hat{F}_1^n(\mu)\right)\right\}^{-1} d\hat{F}_1^n(\mu)$$

Estimating the number of change points: Since $m$ is unknown, they further propose estimating it by minimizing

$$R(\tau_1, \dots, \tau_m) + m\xi_n$$

where $\xi_n$ is the Bayesian information criterion (Schwarz, 1978). Let $\overline{K}_n$ be the upper bound on the number of change points. Zou et al. (2014) show that if

$$\xi_n = \overline{K}_n^3 (\log K_n)^2 (\log n)^{2+c}$$

for any $c > 0$, then under mild conditions, the estimated number of change points converges in probability to the true number, and $\hat{\tau}$ is close to $\tau$. The optimization problem is solved via dynamic programming with computational cost $O(mn^2)$. Haynes et al. (2017) further propose an approximation to reduce computational complexity.

5. Energy-Based Detection

Energy change point detection (ECD) (Matteson and James, 2014) is a multivariate nonparametric change point detection algorithm that combines the energy distance (Székely et al., 2005) and the bisection method (Vostrikova, 1981).

The energy distance: For two multivariate sequences $X^{n_1} = (X_1, \dots, X_{n_1})$ and $Z^{n_2} = (Z_1, \dots, Z_{n_2})$, the energy distance is defined as:

$$\begin{aligned} \epsilon(X^{n_1}, Z^{n_2}; \alpha) &= \frac{1}{n_1 n_2} \sum_{j=1}^{n_1} \sum_{i=1}^{n_2} \|X_j - Z_i\|^\alpha \\ &\quad - \frac{1}{2 n_1^2} \sum_{j=1}^{n_1} \sum_{i=1}^{n_1} \|X_j - X_i\|^\alpha \\ &\quad - \frac{1}{2 n_2^2} \sum_{j=1}^{n_2} \sum_{i=1}^{n_2} \|Z_j - Z_i\|^\alpha \end{aligned}$$

Convergence property: It can be shown that the statistic

$$\frac{mn}{m+n}\, \epsilon(X^n, Z^m; \alpha)$$

converges in distribution to a non-degenerate random variable if and only if

$$(X_1, \dots, X_{n_1}, Z_1, \dots, Z_{n_2}) \sim F(x)$$

where $F(x)$ is a cumulative density function with $\mathbb{E}|X|^\alpha < \infty$ ($\alpha < 2$). Otherwise,

$$\frac{mn}{m+n}\, \epsilon(X^n, Z^m; \alpha) \to \infty$$

Change point detection via bisection: Denote $Y^\tau = (Y_1, \dots, Y_\tau)$ and $Y^\kappa = (Y_{\tau+1}, \dots, Y_n)$. Matteson and James (2014) propose searching for a change point $\hat{\tau}$ by solving

$$\arg\min_{\tau,\kappa}\, \epsilon(Z^\tau, Z^\kappa_\kappa)$$

Then, a two-sample hypothesis test between $Y_1, \dots, Y_{\hat{\tau}}$ and $Y_{\hat{\tau}+1}, \dots, Y_n$ is performed using the permutation method. If the null hypothesis is rejected at the specified significance level, $\hat{\tau}$ is considered a change point, and the sequence is split into two disjoint subsequences. This procedure is repeated recursively on the split subsequences until no change point is detected.

Why energy works for multivariate data: The energy statistic naturally handles multivariate data without requiring specific distributional assumptions. It's sensitive to differences in any aspect of the distribution—mean, variance, correlation structure, or higher moments. A similar kernel-based approach is considered by Harchaoui et al. (2009a).

The Threshold Problem

Nearly every method requires choosing a decision threshold to declare a change point. This threshold fundamentally governs the trade-off between detection delay and false alarm rate.

Common strategies include:

  • Bonferroni correction: Controls false alarm probability via probabilistic bounds, but tends to be overly conservative for large $n$ (Hawkins et al., 2003).
  • Monte Carlo simulation: Generate data under the null hypothesis (no change) and empirically determine the threshold that achieves your desired false alarm rate. This is often the most reliable practical approach.
  • Information criteria: For methods like PELT and nonparametric maximum likelihood, penalty terms based on BIC help control model complexity.

There's no escaping this fundamental trade-off: more sensitive detection inevitably increases false alarms. The optimal threshold depends on the relative costs of missed detections versus false alarms in your specific application.
