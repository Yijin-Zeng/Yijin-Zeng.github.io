Singular Value Decomposition (SVD)

Mathematics

A concise handwritten version of this note is available as a PDF.

Singular value decomposition (SVD) is a highlight of linear algebra -- almost all of the basic but important concepts in the subject show up somewhere in it. Unlike diagonalization, SVD works for any matrix $A \in \mathbb{R}^{n \times m}$. Diagonalization requires the matrix to be square, and even then, not every square matrix is diagonalizable.

What Is SVD?

$$A = U \Sigma V^\top$$
  • $U$ is orthonormal, made of the eigenvectors of $A A^\top$
  • $V$ is orthonormal, made of the eigenvectors of $A^\top A$
  • $\Sigma$ is a diagonal matrix of singular values $\sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_r > 0$

How It Is Derived

$A A^\top$ is a symmetric positive semi-definite matrix, so it is always diagonalizable: $A A^\top = U \Lambda U^\top$, where $\Lambda = \mathrm{diag}(\sigma_{u1}, \dots, \sigma_{um})$, every $\sigma_{ui} \ge 0$, and $U$ is orthonormal.

Take any eigenvector $u_i$ of $A A^\top$ with a non-zero eigenvalue $\sigma_{ui}$:

$$\begin{aligned} A A^\top u_i &= \sigma_{ui} u_i \\ \Rightarrow\; u_i^\top A A^\top u_i &= \sigma_{ui} u_i^\top u_i \\ \Rightarrow\; \|A^\top u_i\|^2 &= \sigma_{ui} \end{aligned}$$

Now look at what happens if we left-multiply by $A^\top$ instead:

$$\begin{aligned} A^\top A A^\top u_i &= \sigma_{ui} A^\top u_i \\ \Rightarrow\; A^\top A (A^\top u_i) &= \sigma_{ui} (A^\top u_i) \end{aligned}$$

So $A^\top u_i$ is itself an eigenvector of $A^\top A$, with the same eigenvalue $\sigma_{ui}$. Denote its normalized version:

$$v_i = \frac{A^\top u_i}{\|A^\top u_i\|} = \frac{A^\top u_i}{\sqrt{\sigma_{ui}}}$$

Rearranging gives $A^\top u_i = \sqrt{\sigma_{ui}} \cdot v_i$. Left-multiplying by $A$:

$$\begin{aligned} A A^\top u_i &= A v_i \sqrt{\sigma_{ui}} \\ \Rightarrow\; \sigma_{ui} u_i &= \sqrt{\sigma_{ui}} \cdot A v_i \\ \Rightarrow\; \sqrt{\sigma_{ui}} \cdot u_i &= A v_i \qquad (*) \end{aligned}$$

So for every eigenvector $u_i$ of $A A^\top$ with a positive eigenvalue, there is a corresponding eigenvector $v_i$ of $A^\top A$ with the same eigenvalue, satisfying $A v_i = \sigma_i u_i$ where $\sigma_i = \sqrt{\sigma_{ui}}$. The same argument runs the other way: starting from an eigenvector of $A^\top A$ gives a matching eigenvector of $A A^\top$ with the same eigenvalue.

Collecting all $r$ such pairs together (ordered by $\sigma_1 \ge \dots \ge \sigma_r > 0$):

$$A (v_1, \dots, v_r) = (u_1, \dots, u_r)\, \mathrm{diag}(\sigma_1, \dots, \sigma_r)$$

Why Is r the Rank of A?

Two facts, put together:

  1. $\mathrm{rank}(A^\top A) = \mathrm{rank}(A)$. They have the same null space: if $Ax = 0$ then $A^\top A x = 0$ trivially; conversely if $A^\top A x = 0$ then $x^\top A^\top A x = 0$, i.e. $\|Ax\|^2 = 0$, so $Ax = 0$. Same null space means same row space, hence $\mathrm{rank}(A^\top A) = \mathrm{rank}(A)$, and by the same logic $\mathrm{rank}(A) = \mathrm{rank}(A^\top) = \mathrm{rank}(A A^\top)$.
  2. $A^\top A$ can be diagonalized as $U' \Lambda U'^\top$ where $U'$ is an invertible (orthonormal) matrix. Multiplying by an invertible matrix never changes rank -- if $Mx = 0$ for invertible $M$ then $x = 0$, so $A^\top A$ and its diagonal form share the same null space. That means $\mathrm{rank}(A^\top A)$ is exactly the number of non-zero, i.e. positive, eigenvalues.

Combining both: the number of positive eigenvalues of $A^\top A$ -- which is exactly $r$, the number of $(u_i, v_i)$ pairs we found above -- equals $\mathrm{rank}(A)$.

Assembling the Full Decomposition

So far $A (v_1, \dots, v_r) = (u_1, \dots, u_r)\, \mathrm{diag}(\sigma_1, \dots, \sigma_r)$, using only the eigenvectors with positive eigenvalues. Notice $u_i \in \mathrm{Col}(A)$ (each $u_i$ is a scaled $Av_i$). Symmetrically, from $(*)$ we also get $A^\top (u_1, \dots, u_r) = \mathrm{diag}(\sigma_1, \dots, \sigma_r)(v_1, \dots, v_r)$, so each $v_i \in \mathrm{Col}(A^\top)$.

Now let $u_{r+1}, \dots, u_n$ be an orthonormal basis of $\mathrm{null}(A^\top)$, and $v_{r+1}, \dots, v_m$ be an orthonormal basis of $\mathrm{null}(A)$. Putting everything together:

$$A (v_1, \dots, v_r, v_{r+1}, \dots, v_m) = (u_1, \dots, u_r, u_{r+1}, \dots, u_n)\, \Sigma$$

where $\Sigma \in \mathbb{R}^{n \times m}$ is $\mathrm{diag}(\sigma_1, \dots, \sigma_r)$ padded with zeros. Since $(v_1, \dots, v_m)$ and $(u_1, \dots, u_n)$ are both full orthonormal bases (orthogonal matrices), we can right-multiply both sides by $V^\top$ to get the familiar form:

$$A = U \Sigma V^\top$$

This is exactly the decomposition we started with -- what this derivation shows is that it always exists, for any matrix $A$, by building it directly out of the eigenvectors of $A A^\top$ and $A^\top A$.
