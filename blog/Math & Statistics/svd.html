Singular Value Decomposition (SVD)

Mathematics

A concise handwritten version of this note is available as a PDF.

Singular value decomposition (SVD) is a highlight of linear algebra -- almost all of the basic but important concepts in the subject show up somewhere in it. Unlike diagonalization, SVD works for any matrix A ∈ R^(n×m). Diagonalization requires the matrix to be square, and even then, not every square matrix is diagonalizable.

What Is SVD?

A = U Σ V^T
  • U is orthonormal, made of the eigenvectors of A A^T
  • V is orthonormal, made of the eigenvectors of A^T A
  • Σ is a diagonal matrix of singular values σ_1 ≥ σ_2 ≥ ... ≥ σ_r > 0

How It Is Derived

A A^T is a symmetric positive semi-definite matrix, so it is always diagonalizable: A A^T = U Λ U^T, where Λ = diag(σ_u1, ..., σ_um), every σ_ui ≥ 0, and U is orthonormal.

Take any eigenvector u_i of A A^T with a non-zero eigenvalue σ_ui:

A A^T u_i = σ_ui u_i
=> u_i^T A A^T u_i = σ_ui u_i^T u_i
=> ||A^T u_i||^2 = σ_ui

Now look at what happens if we left-multiply by A^T instead:

A^T A A^T u_i = σ_ui A^T u_i
=> A^T A (A^T u_i) = σ_ui (A^T u_i)

So A^T u_i is itself an eigenvector of A^T A, with the same eigenvalue σ_ui. Denote its normalized version:

v_i = A^T u_i / ||A^T u_i|| = A^T u_i / √σ_ui

Rearranging gives A^T u_i = √σ_ui · v_i. Left-multiplying by A:

A A^T u_i = A v_i √σ_ui
=> σ_ui u_i = √σ_ui · A v_i
=> √σ_ui · u_i = A v_i   (*)

So for every eigenvector u_i of A A^T with a positive eigenvalue, there is a corresponding eigenvector v_i of A^T A with the same eigenvalue, satisfying A v_i = σ_i u_i where σ_i = √σ_ui. The same argument runs the other way: starting from an eigenvector of A^T A gives a matching eigenvector of A A^T with the same eigenvalue.

Collecting all r such pairs together (ordered by σ_1 ≥ ... ≥ σ_r > 0):

A (v_1, ..., v_r) = (u_1, ..., u_r) diag(σ_1, ..., σ_r)

Why Is r the Rank of A?

Two facts, put together:

  1. rank(A^T A) = rank(A). They have the same null space: if Ax = 0 then A^T A x = 0 trivially; conversely if A^T A x = 0 then x^T A^T A x = 0, i.e. ||Ax||^2 = 0, so Ax = 0. Same null space means same row space, hence rank(A^T A) = rank(A), and by the same logic rank(A) = rank(A^T) = rank(A A^T).
  2. A^T A can be diagonalized as U' Λ U'^T where U' is an invertible (orthonormal) matrix. Multiplying by an invertible matrix never changes rank -- if Mx = 0 for invertible M then x = 0, so A^T A and its diagonal form share the same null space. That means rank(A^T A) is exactly the number of non-zero, i.e. positive, eigenvalues.

Combining both: the number of positive eigenvalues of A^T A -- which is exactly r, the number of (u_i, v_i) pairs we found above -- equals rank(A).

Assembling the Full Decomposition

So far A (v_1, ..., v_r) = (u_1, ..., u_r) diag(σ_1, ..., σ_r), using only the eigenvectors with positive eigenvalues. Notice u_i ∈ Col(A) (each u_i is a scaled Av_i). Symmetrically, from (*) we also get A^T (u_1, ..., u_r) = diag(σ_1, ..., σ_r)(v_1, ..., v_r), so each v_i ∈ Col(A^T).

Now let u_{r+1}, ..., u_n be an orthonormal basis of null(A^T), and v_{r+1}, ..., v_m be an orthonormal basis of null(A). Putting everything together:

A (v_1, ..., v_r, v_{r+1}, ..., v_m) = (u_1, ..., u_r, u_{r+1}, ..., u_n) Σ

where Σ ∈ R^(n×m) is diag(σ_1, ..., σ_r) padded with zeros. Since (v_1, ..., v_m) and (u_1, ..., u_n) are both full orthonormal bases (orthogonal matrices), we can right-multiply both sides by V^T to get the familiar form:

A = U Σ V^T

This is exactly the decomposition we started with -- what this derivation shows is that it always exists, for any matrix A, by building it directly out of the eigenvectors of A A^T and A^T A.
