Numerical Stability and QR Decomposition

Mathematics

A concise handwritten version of this note is available as a PDF.

Suppose we are solving the system Ax = b. In practice, b is rarely exact. It often contains small measurement errors (for example, if we save 0.1 in float32, we probably end up saving something like 0.10000000012). We denote the error of b as Δb. Similarly, we have an error ΔA for A.

Error Propagation and the Condition Number

So we have (A+ΔA)(x+Δx) = b+Δb, where x+Δx is the exact solution for this perturbed system, and the additional terms are there because of the numerical approximation. Expanding the left side:

Ax + AΔx + ΔAx + ΔAΔx = b + Δb

Since Ax = b, this gives AΔx + ΔAx + ΔAΔx = Δb. We drop the second order term ΔAΔx, because it will be much smaller than the rest:

AΔx + ΔAx ≈ Δb
=> Δx ≈ A^-1 (Δb - ΔAx)

Taking norms:

||Δx|| = ||A^-1 (Δb - ΔAx)||
       ≤ ||A^-1|| · ||Δb - ΔAx||
       ≤ ||A^-1|| ( ||Δb|| + ||ΔA|| · ||x|| )

This uses the matrix norm ||M|| = max_{x≠0} ||Mx|| / ||x||, which gives ||Mx|| ≤ ||M|| · ||x||. If the norm for vectors here is the L2 norm, then ||M|| = σ_max(M), the largest singular value.

Dividing by ||x||:

||Δx|| / ||x|| ≤ ||A^-1|| ( ||Δb|| / ||x|| + ||ΔA|| )

Since Ax = b, we have ||Ax|| = ||b||, so ||b|| ≤ ||A|| · ||x||, which means 1 / ||x|| ≤ ||A|| / ||b||. Substituting this in:

||Δx|| / ||x|| ≤ ||A^-1|| ( ||A|| · ||Δb|| / ||b|| + ||ΔA|| )
              = ||A^-1|| · ||A|| · ( ||Δb|| / ||b|| + ||ΔA|| / ||A|| )
              = K(A) · ( ||Δb|| / ||b|| + ||ΔA|| / ||A|| )

where K(A) = ||A|| · ||A^-1|| = σ_max / σ_min is known as the condition number.

What this means: if the condition number of A is small, the error Δx is small relative to x. If K(A) is large, the error could be large.

Why QR Decomposition Instead of the Normal Equations

Intuition of the condition number via SVD: A = UΣV^T, where U and V^T are rotations and Σ is the stretch. If the condition number is large, A stretches a lot along some direction and compresses a lot in other directions.

Note that:

A^T A = V Σ U^T U Σ V^T = V Σ² V^T

so σ_max(A^T A) = σ_max(A)² and σ_min(A^T A) = σ_min(A)², hence K(A^T A) = K(A)². Squaring A squares the condition number, so working directly on A^T A is not good if A already has a bad condition number.

Example: in linear regression, we solve X^T X β = X^T y. If we do β̂ = (X^T X)^-1 X^T y directly, we lose a lot of precision if X has a serious multicollinearity problem, since X^T X squares the condition number of X.

A computationally safer approach for solving β is QR decomposition:

X^T X β = X^T y
R^T Q^T Q R β = R^T Q^T y
R^T R β = R^T Q^T y
R β = Q^T y

solved by backward substitution, so we never actually form X^T X.

QR Decomposition and the Gram-Schmidt Process

Review: Projection

To understand QR decomposition, we first review the concept of projection.

Project a vector a onto another vector b:

(a - λb)^T b = 0
=> a^T b = λ b^T b
=> λ = a^T b / b^T b
=> λb = (b b^T / b^T b) a

where b b^T / b^T b is the projection matrix of b.

Project a vector a onto a space B with basis {b_1, ..., b_n}:

(a - Bλ)^T b_i = 0   for all i
=> B^T (a - Bλ) = 0
=> B^T a - B^T B λ = 0
=> λ = (B^T B)^-1 B^T a
=> Bλ = B (B^T B)^-1 B^T a

where B (B^T B)^-1 B^T is the projection matrix into Col(B).

Note that the projection matrix P = A(A^T A)^-1 A^T has the same column space as A: since P = A(A^T A)^-1 A^T, Col(P) ⊆ Col(A). And PA = A, so Col(A) ⊆ Col(P). Hence Col(A) = Col(P).

The Gram-Schmidt Process

The idea of the Gram-Schmidt process: subtract from every new vector its projections in the directions already set.

Worked example: perform Gram-Schmidt on (a, b, c).

A = a
A' = A / ||A||

B = b - (A^T b / A^T A) A = b - (A'^T b) A'
B' = B / ||B||

C = c - (A^T c / A^T A) A - (B^T c / B^T B) B = c - (A'^T c) A' - (B'^T c) B'
C' = C / ||C||

This gives an orthonormal set {A', B', C'} from {a, b, c}, which is the Q in QR decomposition.
