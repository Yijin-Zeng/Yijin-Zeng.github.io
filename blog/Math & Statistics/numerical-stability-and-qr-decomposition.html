Numerical Stability and QR Decomposition

Mathematics

A concise handwritten version of this note is available as a PDF.

Suppose we are solving the system $Ax = b$. In practice, $b$ is rarely exact. It often contains small measurement errors (for example, if we save 0.1 in float32, we probably end up saving something like 0.10000000012). We denote the error of $b$ as $\Delta b$. Similarly, we have an error $\Delta A$ for $A$.

Error Propagation and the Condition Number

So we have $(A+\Delta A)(x+\Delta x) = b+\Delta b$, where $x+\Delta x$ is the exact solution for this perturbed system, and the additional terms are there because of the numerical approximation. Expanding the left side:

$$Ax + A\Delta x + \Delta A x + \Delta A \Delta x = b + \Delta b$$

Since $Ax = b$, this gives $A\Delta x + \Delta A x + \Delta A \Delta x = \Delta b$. We drop the second order term $\Delta A \Delta x$, because it will be much smaller than the rest:

$$\begin{aligned} A\Delta x + \Delta A x &\approx \Delta b \\ \Rightarrow\; \Delta x &\approx A^{-1} (\Delta b - \Delta A x) \end{aligned}$$

Taking norms:

$$\begin{aligned} \|\Delta x\| &= \|A^{-1} (\Delta b - \Delta A x)\| \\ &\le \|A^{-1}\| \cdot \|\Delta b - \Delta A x\| \\ &\le \|A^{-1}\| \left( \|\Delta b\| + \|\Delta A\| \cdot \|x\| \right) \end{aligned}$$

This uses the matrix norm $\|M\| = \max_{x \ne 0} \|Mx\| / \|x\|$, which gives $\|Mx\| \le \|M\| \cdot \|x\|$. If the norm for vectors here is the $L_2$ norm, then $\|M\| = \sigma_{\max}(M)$, the largest singular value.

Dividing by $\|x\|$:

$$\frac{\|\Delta x\|}{\|x\|} \le \|A^{-1}\| \left( \frac{\|\Delta b\|}{\|x\|} + \|\Delta A\| \right)$$

Since $Ax = b$, we have $\|Ax\| = \|b\|$, so $\|b\| \le \|A\| \cdot \|x\|$, which means $1 / \|x\| \le \|A\| / \|b\|$. Substituting this in:

$$\begin{aligned} \frac{\|\Delta x\|}{\|x\|} &\le \|A^{-1}\| \left( \|A\| \cdot \frac{\|\Delta b\|}{\|b\|} + \|\Delta A\| \right) \\ &= \|A^{-1}\| \cdot \|A\| \cdot \left( \frac{\|\Delta b\|}{\|b\|} + \frac{\|\Delta A\|}{\|A\|} \right) \\ &= K(A) \cdot \left( \frac{\|\Delta b\|}{\|b\|} + \frac{\|\Delta A\|}{\|A\|} \right) \end{aligned}$$

where $K(A) = \|A\| \cdot \|A^{-1}\| = \sigma_{\max} / \sigma_{\min}$ is known as the condition number.

What this means: if the condition number of $A$ is small, the error $\Delta x$ is small relative to $x$. If $K(A)$ is large, the error could be large.

Why QR Decomposition Instead of the Normal Equations

Intuition of the condition number via SVD: $A = U\Sigma V^\top$, where $U$ and $V^\top$ are rotations and $\Sigma$ is the stretch. If the condition number is large, $A$ stretches a lot along some direction and compresses a lot in other directions.

Note that:

$$A^\top A = V \Sigma U^\top U \Sigma V^\top = V \Sigma^2 V^\top$$

so $\sigma_{\max}(A^\top A) = \sigma_{\max}(A)^2$ and $\sigma_{\min}(A^\top A) = \sigma_{\min}(A)^2$, hence $K(A^\top A) = K(A)^2$. Squaring $A$ squares the condition number, so working directly on $A^\top A$ is not good if $A$ already has a bad condition number.

Example: in linear regression, we solve $X^\top X \beta = X^\top y$. If we do $\hat\beta = (X^\top X)^{-1} X^\top y$ directly, we lose a lot of precision if $X$ has a serious multicollinearity problem, since $X^\top X$ squares the condition number of $X$.

A computationally safer approach for solving $\beta$ is QR decomposition:

$$\begin{aligned} X^\top X \beta &= X^\top y \\ R^\top Q^\top Q R \beta &= R^\top Q^\top y \\ R^\top R \beta &= R^\top Q^\top y \\ R \beta &= Q^\top y \end{aligned}$$

solved by backward substitution, so we never actually form $X^\top X$.

QR Decomposition and the Gram-Schmidt Process

Review: Projection

To understand QR decomposition, we first review the concept of projection.

Project a vector $a$ onto another vector $b$:

$$\begin{aligned} (a - \lambda b)^\top b &= 0 \\ \Rightarrow\; a^\top b &= \lambda b^\top b \\ \Rightarrow\; \lambda &= \frac{a^\top b}{b^\top b} \\ \Rightarrow\; \lambda b &= \frac{b b^\top}{b^\top b}\, a \end{aligned}$$

where $\dfrac{b b^\top}{b^\top b}$ is the projection matrix of $b$.

Project a vector $a$ onto a space $B$ with basis $\{b_1, \dots, b_n\}$:

$$\begin{aligned} (a - B\lambda)^\top b_i &= 0 \quad \text{for all } i \\ \Rightarrow\; B^\top (a - B\lambda) &= 0 \\ \Rightarrow\; B^\top a - B^\top B \lambda &= 0 \\ \Rightarrow\; \lambda &= (B^\top B)^{-1} B^\top a \\ \Rightarrow\; B\lambda &= B (B^\top B)^{-1} B^\top a \end{aligned}$$

where $B (B^\top B)^{-1} B^\top$ is the projection matrix into $\mathrm{Col}(B)$.

Note that the projection matrix $P = A(A^\top A)^{-1} A^\top$ has the same column space as $A$: since $P = A(A^\top A)^{-1} A^\top$, $\mathrm{Col}(P) \subseteq \mathrm{Col}(A)$. And $PA = A$, so $\mathrm{Col}(A) \subseteq \mathrm{Col}(P)$. Hence $\mathrm{Col}(A) = \mathrm{Col}(P)$.

The Gram-Schmidt Process

The idea of the Gram-Schmidt process: subtract from every new vector its projections in the directions already set.

Worked example: perform Gram-Schmidt on $(a, b, c)$.

$$\begin{aligned} A &= a \\ A' &= A / \|A\| \\[6pt] B &= b - \frac{A^\top b}{A^\top A} A = b - (A'^\top b) A' \\ B' &= B / \|B\| \\[6pt] C &= c - \frac{A^\top c}{A^\top A} A - \frac{B^\top c}{B^\top B} B = c - (A'^\top c) A' - (B'^\top c) B' \\ C' &= C / \|C\| \end{aligned}$$

This gives an orthonormal set $\{A', B', C'\}$ from $\{a, b, c\}$, which is the $Q$ in QR decomposition.
