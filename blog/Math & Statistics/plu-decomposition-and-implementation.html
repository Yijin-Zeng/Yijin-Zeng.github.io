PLU Decomposition and Implementation

Mathematics

A concise handwritten version of this note is available as a PDF.

How to Solve a Linear System?

We want to solve Ax = b. As an example, take

A = [ 2  4 -2 ]     b = [ 2 ]
    [ 4  9 -3 ]         [ 8 ]
    [-2 -3  7 ]         [10]

The idea is to do Gaussian elimination first, so the equation becomes

[ 2  4 -2 ]         [2]
[ 0  1  1 ] x =     [4]
[ 0  0  4 ]         [8]

Then we can do backward substitution to solve x_1, x_2, x_3 easily:

4x_3 = 8              => x_3 = 2
x_2 + x_3 = 4          => x_2 = 2
2x_1 + 4x_2 - 2x_3 = 2 => x_1 = -1

Gaussian Elimination

Going back to the same example, write A and b together as an augmented matrix and eliminate row by row.

[ 2  4 -2 |  2]
[ 4  9 -3 |  8]
[-2 -3  7 | 10]

Second row − 2×first row:

[ 2  4 -2 |  2]
[ 0  1  1 |  4]
[-2 -3  7 | 10]

Third row + first row:

[ 2  4 -2 |  2]
[ 0  1  1 |  4]
[ 0  1  5 | 12]

Third row − second row:

[ 2  4 -2 | 2]
[ 0  1  1 | 4]
[ 0  0  4 | 8]

That's the upper triangular system we used above.

Each Elimination Step Has a Simple Matrix Representation

Each of the row operations above can be written as left-multiplication by a matrix. For instance, "second row − 2×first row" is

E_21 = [ 1  0  0]
       [-2  1  0]
       [ 0  0  1]

LU Decomposition

To generalize, we have

E_{n,n-1} ... E_{m1} ... E_{21} A = U

where the product of elimination matrices on the left are the elimination steps, and U is the resulting upper triangular matrix. Inverting both sides,

A = E_21^{-1} E_{m1}^{-1} ... E_{n,n-1}^{-1} U

Result 1: if E_ij is the identity matrix with L_ij at entry (i,j), then E_ij^{-1} is the identity matrix with -L_ij at entry (i,j).

Result 2: the product E_21^{-1} E_31^{-1} ... E_{n,n-1}^{-1} is a single lower triangular matrix with all the -L_ij entries stacked in their respective positions, e.g.

[    1      0    0]
[ -L_21     1    0]
[ -L_31  -L_32   1]

We can prove this by induction: multiplying E_ij^{-1} (which has -L_ij at entry (i,j) and zeros elsewhere off the diagonal) into the product so far only fills in entry (i,j) with -L_ij, since the entry at (i,j) in the partial product is still zero at that point and any other entries below the diagonal are left untouched.

The effect of this matrix: a Gaussian elimination step takes the i-th row, times L_ij, and adds it to the j-th row, where j > i. So this operation only affects entry (i,j).

So we have A = LU. This is the known LU decomposition.

LU Decomposition Isn't Always Possible

For example, if

A = [0 2 3]
    [1 3 5]
    [4 0 2]

then the first row cannot eliminate the second or third row, because the (1,1) entry is 0.

Define the row exchange matrix P_ij as the identity matrix with rows i and j swapped. The effect of this matrix: P_ij A swaps rows A_i and A_j of A.

An important property of P_ij: P_ij = P_ij^{-1}. This is obvious because P_ij^2 = I — swap rows i and j, then swap them again, and we're back where we started.

PLU Decomposition

So in many cases we have a chain that mixes elimination steps and row exchanges, something like (E ... P E ... P E ... E) A = U, and we want to collect all the P's together. Since PE = E'P where E' = PEP, each time we push a permutation matrix P through an elimination matrix E, E turns into a new elimination matrix E' acting on the permuted row indices.

Concretely, for a chain like E_32 P_23 E_31 E_21:

E_32 P_23 E_31 E_21
= E_32 E'_31 P_23 E_21
= E_32 E'_31 E'_21 P_23

where

E'_31 = P_23 E_31 P_23
      = P_23 (I + L_31 e_3 e_1^T) P_23
      = I + L_31 P_23 e_3 e_1^T P_23
      = I + L_31 e_2 e_1^T   (goes to row 2)

and similarly

E'_21 = I + L_21 e_3 e_1^T   (goes to row 3)

Putting it back together, E_32 P_23 E_31 E_21 A = U becomes E_32 E'_31 E'_21 (P_23 A) = U, so

P_23 A = (E_32 E'_31 E'_21)^{-1} U = LU

This is the PLU decomposition: PA = LU.
