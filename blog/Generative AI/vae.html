Variational Autoencoders (VAE)

Generative AI

A concise handwritten version of this note is available as a PDF.

Variational autoencoders (VAE) are a type of probabilistic generative model. The core idea is to model the "true" distribution as an integral over a latent variable:

$$\mathrm{pr}(x) = \int \mathrm{pr}(z)\, \mathrm{pr}(x|z)\, dz$$ $$\begin{aligned} \mathrm{pr}(z) &: \text{latent variable} \\ \mathrm{pr}(x|z) &: \text{conditional likelihood given the latent variable} \end{aligned}$$

Examples

Two examples of what this buys us.

1. Gaussian Mixture Model. The latent variable is cluster membership: $z_{ij} = 1$ if point $x_i$ belongs to cluster $C_j$, 0 otherwise. The conditional likelihood is just a Gaussian, $\mathrm{pr}(x_i \mid z_{ij} = 1) = \mathcal{N}(x_i; \mu_j, \Sigma_j)$. Both pieces are simple, but a weighted average of them — say $p(z=1) = 0.5$, $p(z=2) = 0.5$ — can already model a complex, bimodal distribution.

2. 2D non-linear latent variable model. Say the data is 2D and scattered along a curve. How do we model this distribution? Put a Gaussian prior on a scalar $z$, map it through a non-linear function $f(z; \phi)$, and place a Gaussian at every point along the curve:

$$\mathrm{pr}(x) = \int \mathrm{pr}(z)\, \mathcal{N}(x; f(z; \phi), \Sigma)\, dz$$ 
    z axis (latent)              x space (data)
    ────●────────►               ○ ○ ○
        │ f(z; φ)               ○     ○ ○      each circle is a
        ▼                      ○         ○ ○   Gaussian; averaging
    curve in x-space                       ○   them along f(z; φ)
                                               traces the curve

Conclusion for both: a weighted average of simple Gaussian distributions can be used to approximate a very complicated distribution.

The Problem of VAE

Take the model above and try to do maximum likelihood on it directly:

$$\mathrm{pr}(x) = \int \mathrm{pr}(z)\, \mathrm{pr}(x|z; \phi)\, dz = \int \mathcal{N}(z; 0, I)\, \mathcal{N}(x; f(z; \phi), \sigma^2 I)\, dz$$

This has no analytical form. We can approximate it with Monte Carlo instead, to estimate the marginal likelihood of $x$:

$$\mathrm{pr}(x) \approx \mathbb{E}_{z\sim\mathcal{N}(0,I)} \Big[ \mathcal{N}(x; f(z; \phi), \sigma^2 I) \Big]$$

However, because the dimension of $z$ is high, we need a very large sample size to make this work. For a given image $x$, if we sample randomly from $z \sim \mathcal{N}(0, I)$, it is very likely (>99.9% of the time) that $\mathcal{N}(x; f(z; \phi), \sigma^2 I) \approx 0$. So it is hard to maximize the marginal likelihood $\mathrm{pr}(x)$ directly.

Instead, we will try to push up the lower bound of the marginal likelihood.

Deriving the ELBO

Multiply and divide by a proposed distribution $q(z)$ inside the log, then apply Jensen's inequality:

$$\begin{aligned} \log \mathrm{pr}(x|\phi) &= \log \left( \int \mathrm{pr}(x, z|\phi)\, dz \right) \\ &= \log \left( \int q(z) \cdot \frac{\mathrm{pr}(x, z|\phi)}{q(z)}\, dz \right) \\ &\ge \int q(z) \log \left( \frac{\mathrm{pr}(x, z|\phi)}{q(z)} \right) dz \qquad (\text{Jensen's inequality}) \end{aligned}$$

This is known as the evidence lower bound (ELBO). This proposed $q(z)$ can be anything, as long as it is a valid distribution, and it decides how far the ELBO is from $\mathrm{pr}(x|\phi)$. We can learn it as well, and denote it as $q(z|\theta)$ below:

$$\mathrm{ELBO}(\theta, \phi) = \int q(z|\theta) \log \left( \frac{\mathrm{pr}(x, z|\phi)}{q(z|\theta)} \right) dz$$ $$\begin{aligned} \text{change } \theta &: \text{push up the ELBO itself} \\ \text{change } \phi &: \text{move the ELBO (and the target) up together} \end{aligned}$$

Another perspective of VAE: the neural network architecture built to maximize the ELBO is the VAE.

Analyzing the ELBO

1. Tightness of the bound

Expand $\mathrm{pr}(x, z|\phi) = \mathrm{pr}(z|x, \phi)\, \mathrm{pr}(x|\phi)$:

$$\begin{aligned} \mathrm{ELBO}(\theta, \phi) &= \int q(z|\theta) \log \left( \frac{\mathrm{pr}(z|x, \phi)\, \mathrm{pr}(x|\phi)}{q(z|\theta)} \right) dz \\ &= \log \mathrm{pr}(x|\phi) - \mathrm{KL}\big( q(z|\theta), \mathrm{pr}(z|x, \phi) \big) \end{aligned}$$

When the proposed distribution $q(z|\theta) = \mathrm{pr}(z|x, \phi)$, we have $\mathrm{ELBO}(\theta, \phi) = \log \mathrm{pr}(x|\phi)$. However, $\mathrm{pr}(z|x, \phi) = \mathrm{pr}(z)\, \mathrm{pr}(x|z, \phi) / \mathrm{pr}(x|\phi)$ could be very complex.

2. Constructing a loss function from the ELBO

Now expand the joint the other way, $\mathrm{pr}(x, z|\phi) = \mathrm{pr}(x|z, \phi)\, \mathrm{pr}(z)$, where $\mathrm{pr}(z)$ is the prior $z \sim \mathcal{N}(0, I)$:

$$\begin{aligned} \mathrm{ELBO}(\theta, \phi) &= \underbrace{\int q(z|\theta) \log \mathrm{pr}(x|z, \phi)\, dz}_{\text{reconstruction error}} - \underbrace{\mathrm{KL}\big( q(z|\theta), \mathrm{pr}(z) \big)}_{\text{the proposed distribution } q(z|\theta) \text{ will be penalized if it deviates from prior } \mathrm{pr}(z)} \\ &= \mathbb{E}_{z\sim q(z|\theta)} \big[ \log \mathrm{pr}(x|z, \phi) \big] \end{aligned}$$

Putting the Two Analyses Together

Combining the above two analyses, we now know that:

  1. We want the proposed distribution $q(z|\theta)$ to be close to $\mathrm{pr}(z|x, \phi)$, so that ELBO $\to$ target.
  2. We want the proposed distribution to minimize reconstruction error, which means it should provide enough information about the observation $x$.
  3. We also want $q(z|\theta)$ to be close to $\mathrm{pr}(z)$, so it should stay simple.

Solution: we let

$$q(z|\theta) = q(z|x, \theta) = \mathcal{N}\big( z; g_\mu(x, \theta), g_\Sigma(x, \theta) \big)$$

where $g_\mu$ and $g_\Sigma$ are neural networks that read $x$ and output a mean and covariance. This is the variational approximation to $\mathrm{pr}(z|x, \phi)$, and it is also the encoder. This could be very complex, so this approximation may not be good, in which case the ELBO is not close to the log marginal likelihood.

Summary

The loss function is:

$$\begin{aligned} L(\theta, \phi) &= -\int q(z|x, \theta) \log \mathrm{pr}(x|z, \phi)\, dz + \mathrm{KL}\big( q(z|x, \theta), \mathrm{pr}(z) \big) \\ &= -\mathbb{E}_{z\sim q(\cdot|x,\theta)} \big[ \log \mathrm{pr}(x|z, \phi) \big] + \mathrm{KL}\big( q(z|x, \theta), \mathrm{pr}(z) \big) \\ &\approx -\frac{1}{n} \sum_i \log \mathrm{pr}(x|z_i, \phi) + \mathrm{KL}\big( q(z|x, \theta), \mathrm{pr}(z) \big) \qquad z_i \sim q(z|x, \theta) \end{aligned}$$

Here $z$ is also high dimension, so why will this approximation work, but $\int \mathrm{pr}(z)\, \mathrm{pr}(x|z, \phi)\, dz = \mathbb{E}_{z\sim\mathcal{N}(0,I)}[\mathrm{pr}(x|z, \phi)]$ will fail?

Reason: if $z \sim \mathcal{N}(0, I)$, then $\mathrm{pr}(x|z, \phi) \approx 0$. If, however, $z \sim q(\cdot|x, \theta)$, then $\mathrm{pr}(x|z, \phi) > 0$. The compression step (encoder) narrows down the scope in latent space to a small region:

   Latent Space N(0, I)                Sample Space
   ┌───────────────────┐              ┌──────────────────┐
   │  x x x  ┌──┐      │   decoder    │        ┌──┐      │
   │  x x    │ ∘│ ─────┼─────────────►│        │ x│      │
   │    x x  └──┘      │ decompression│  x x   └──┘      │
   │  x   x x   x      │◄─────────────┼─ x  x x   x      │
   └───────────────────┘   encoder    └──────────────────┘
     the compression step q(·|x, θ)     compression
     narrows the scope in latent
     space to a small region

Since $q(z|x, \theta)$ is Gaussian and the prior is Gaussian, the KL term has an explicit form, so no sampling is needed for that term.

Encoder and Decoder

x (image) → encoder → μ, Σ  ── z = μ + Σ^(1/2)·ε, ε ~ N(0,I) ──→ decoder → f(z; φ)
            learns pr(z|x)      (reparameterization trick)          learns the mean
                = N(μ, Σ)                                                │
                                    loss: log N( x; f(z; φ), σ²I )   ◄────┘
                                          σ normally fixed at 1 or 0.5

This $\Sigma$ needs to be symmetric and semi-positive definite. Normally we assume $\Sigma = \mathrm{diag}(\sigma_1^2, ..., \sigma_n^2)$; otherwise we use the Cholesky decomposition $\Sigma = LL^{\top}$, where $L$ is a lower-triangular matrix with positive values on its diagonal.

Why does the decoder not learn $\sigma$? If the image is hard, it could push $\sigma \to \infty$; if the image is easy, it would push $\sigma \to 0$. So the decoder normally just learns the mean.

Underneath this, there's a tension: we need to encode as much information about the image as possible to minimize reconstruction error, versus we need to be simple enough so that $\mathrm{KL}(q(z|x, \theta), \mathcal{N}(0, I))$ is small.

A Few More Notes

1. Remember the target is to maximize $\mathrm{pr}(x|\phi)$. The loss function of VAE is maximizing the ELBO directly. So how about the distance between ELBO and $\mathrm{pr}(x|\phi)$?

$$\mathrm{pr}(x|\phi) = \mathrm{ELBO}(\theta, \phi) + \mathrm{KL}\big( q(z|\theta), \mathrm{pr}(z|x, \phi) \big)$$

The marginal likelihood depends on the decoder only. So for a given decoder $\phi$, it is a constant for the encoder. As long as the encoder is pushing up ELBO, it is minimizing the distance $\mathrm{KL}(q(z|\theta), \mathrm{pr}(z|x, \phi))$, although we don't know what $\mathrm{pr}(z|x, \phi)$ is. We can also think the encoder here is only trying to help the decoder learn: without an encoder, the decoder needs to evaluate the whole latent space to evaluate $\mathrm{pr}(x|\phi)$; with an encoder, it helps to narrow down the space to $q(z|x, \theta)$.

2. To generate an image from a VAE:

z ~ N(0, I)   (independent Gaussian)   →   decoder   →   generated image

3. In order to improve the quality of the generated images from a VAE, it seems not enough to model the prior $\mathrm{pr}(z)$ and the latent space $\mathrm{pr}(z|x)$ as Gaussian. Diffusion can generate higher quality images, and can be considered a VAE with hierarchical priors.
