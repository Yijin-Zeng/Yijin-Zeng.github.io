Variational Autoencoders (VAE)

Generative AI

A concise handwritten version of this note is available as a PDF.

Variational autoencoders (VAE) are a type of probabilistic generative model. The core idea is to model the "true" distribution as an integral over a latent variable:

pr(x) = ∫ pr(z) pr(x|z) dz

pr(z)    : latent variable
pr(x|z)  : conditional likelihood given the latent variable

Examples

Two examples of what this buys us.

1. Gaussian Mixture Model. The latent variable is cluster membership: z_ij = 1 if point x_i belongs to cluster C_j, 0 otherwise. The conditional likelihood is just a Gaussian, pr(x_i | z_ij = 1) = N(x_i; μ_j, Σ_j). Both pieces are simple, but a weighted average of them — say p(z=1) = 0.5, p(z=2) = 0.5 — can already model a complex, bimodal distribution.

2. 2D non-linear latent variable model. Say the data is 2D and scattered along a curve. How do we model this distribution? Put a Gaussian prior on a scalar z, map it through a non-linear function f(z; φ), and place a Gaussian at every point along the curve:

pr(x) = ∫ pr(z) N(x; f(z; φ), Σ) dz

    z axis (latent)              x space (data)
    ────●────────►               ○ ○ ○
        │ f(z; φ)               ○     ○ ○      each circle is a
        ▼                      ○         ○ ○   Gaussian; averaging
    curve in x-space                       ○   them along f(z; φ)
                                               traces the curve

Conclusion for both: a weighted average of simple Gaussian distributions can be used to approximate a very complicated distribution.

The Problem of VAE

Take the model above and try to do maximum likelihood on it directly:

pr(x) = ∫ pr(z) pr(x|z; φ) dz = ∫ N(z; 0, I) N(x; f(z; φ), σ²I) dz

This has no analytical form. We can approximate it with Monte Carlo instead, to estimate the marginal likelihood of x:

pr(x) ≈ E_{z~N(0,I)} [ N(x; f(z; φ), σ²I) ]

However, because the dimension of z is high, we need a very large sample size to make this work. For a given image x, if we sample randomly from z ~ N(0, I), it is very likely (>99.9% of the time) that N(x; f(z; φ), σ²I) ≈ 0. So it is hard to maximize the marginal likelihood pr(x) directly.

Instead, we will try to push up the lower bound of the marginal likelihood.

Deriving the ELBO

Multiply and divide by a proposed distribution q(z) inside the log, then apply Jensen's inequality:

log pr(x|φ) = log ( ∫ pr(x, z|φ) dz )

            = log ( ∫ q(z) · pr(x, z|φ) / q(z) dz )

            ≥ ∫ q(z) log ( pr(x, z|φ) / q(z) ) dz     ← Jensen's inequality

This is known as the evidence lower bound (ELBO). This proposed q(z) can be anything, as long as it is a valid distribution, and it decides how far the ELBO is from pr(x|φ). We can learn it as well, and denote it as q(z|θ) below:

ELBO(θ, φ) = ∫ q(z|θ) log ( pr(x, z|φ) / q(z|θ) ) dz

change θ: push up the ELBO itself
change φ: move the ELBO (and the target) up together

Another perspective of VAE: the neural network architecture built to maximize the ELBO is the VAE.

Analyzing the ELBO

1. Tightness of the bound

Expand pr(x, z|φ) = pr(z|x, φ) pr(x|φ):

ELBO(θ, φ) = ∫ q(z|θ) log ( pr(z|x, φ) pr(x|φ) / q(z|θ) ) dz

           = log pr(x|φ) − KL( q(z|θ), pr(z|x, φ) )

When the proposed distribution q(z|θ) = pr(z|x, φ), we have ELBO(θ, φ) = log pr(x|φ). However, pr(z|x, φ) = pr(z) pr(x|z, φ) / pr(x|φ) could be very complex.

2. Constructing a loss function from the ELBO

Now expand the joint the other way, pr(x, z|φ) = pr(x|z, φ) pr(z), where pr(z) is the prior z ~ N(0, I):

ELBO(θ, φ) = ∫ q(z|θ) log pr(x|z, φ) dz − KL( q(z|θ), pr(z) )
             ─────────────────────────    ──────────────────
             reconstruction error          the proposed distribution q(z|θ) will be
                                           penalized if it deviates from prior pr(z)

           = E_{z~q(z|θ)} [ log pr(x|z, φ) ]

Putting the Two Analyses Together

Combining the above two analyses, we now know that:

  1. We want the proposed distribution q(z|θ) to be close to pr(z|x, φ), so that ELBO → target.
  2. We want the proposed distribution to minimize reconstruction error, which means it should provide enough information about the observation x.
  3. We also want q(z|θ) to be close to pr(z), so it should stay simple.

Solution: we let

q(z|θ) = q(z|x, θ) = N( z; g_μ(x, θ), g_Σ(x, θ) )

where g_μ and g_Σ are neural networks that read x and output a mean and covariance. This is the variational approximation to pr(z|x, φ), and it is also the encoder. This could be very complex, so this approximation may not be good, in which case the ELBO is not close to the log marginal likelihood.

Summary

The loss function is:

L(θ, φ) = −∫ q(z|x, θ) log pr(x|z, φ) dz + KL( q(z|x, θ), pr(z) )

        = −E_{z~q(·|x,θ)} [ log pr(x|z, φ) ] + KL( q(z|x, θ), pr(z) )

        ≈ −(1/n) Σᵢ log pr(x|zᵢ, φ) + KL( q(z|x, θ), pr(z) )
                  zᵢ ~ q(z|x, θ)

Here z is also high dimension, so why will this approximation work, but ∫ pr(z) pr(x|z, φ) dz = E_{z~N(0,I)}[pr(x|z, φ)] will fail?

Reason: if z ~ N(0, I), then pr(x|z, φ) ≈ 0. If, however, z ~ q(·|x, θ), then pr(x|z, φ) > 0. The compression step (encoder) narrows down the scope in latent space to a small region:

   Latent Space N(0, I)                Sample Space
   ┌───────────────────┐              ┌──────────────────┐
   │  x x x  ┌──┐      │   decoder    │        ┌──┐      │
   │  x x    │ ∘│ ─────┼─────────────►│        │ x│      │
   │    x x  └──┘      │ decompression│  x x   └──┘      │
   │  x   x x   x      │◄─────────────┼─ x  x x   x      │
   └───────────────────┘   encoder    └──────────────────┘
     the compression step q(·|x, θ)     compression
     narrows the scope in latent
     space to a small region

Since q(z|x, θ) is Gaussian and the prior is Gaussian, the KL term has an explicit form, so no sampling is needed for that term.

Encoder and Decoder

x (image) → encoder → μ, Σ  ── z = μ + Σ^(1/2)·ε, ε ~ N(0,I) ──→ decoder → f(z; φ)
            learns pr(z|x)      (reparameterization trick)          learns the mean
                = N(μ, Σ)                                                │
                                    loss: log N( x; f(z; φ), σ²I )   ◄────┘
                                          σ normally fixed at 1 or 0.5

This Σ needs to be symmetric and semi-positive definite. Normally we assume Σ = diag(σ₁², ..., σₙ²); otherwise we use the Cholesky decomposition Σ = LLᵀ, where L is a lower-triangular matrix with positive values on its diagonal.

Why does the decoder not learn σ? If the image is hard, it could push σ → ∞; if the image is easy, it would push σ → 0. So the decoder normally just learns the mean.

Underneath this, there's a tension: we need to encode as much information about the image as possible to minimize reconstruction error, versus we need to be simple enough so that KL(q(z|x, θ), N(0, I)) is small.

A Few More Notes

1. Remember the target is to maximize pr(x|φ). The loss function of VAE is maximizing the ELBO directly. So how about the distance between ELBO and pr(x|φ)?

pr(x|φ) = ELBO(θ, φ) + KL( q(z|θ), pr(z|x, φ) )

The marginal likelihood depends on the decoder only. So for a given decoder φ, it is a constant for the encoder. As long as the encoder is pushing up ELBO, it is minimizing the distance KL(q(z|θ), pr(z|x, φ)), although we don't know what pr(z|x, φ) is. We can also think the encoder here is only trying to help the decoder learn: without an encoder, the decoder needs to evaluate the whole latent space to evaluate pr(x|φ); with an encoder, it helps to narrow down the space to q(z|x, θ).

2. To generate an image from a VAE:

z ~ N(0, I)   (independent Gaussian)   →   decoder   →   generated image

3. In order to improve the quality of the generated images from a VAE, it seems not enough to model the prior pr(z) and the latent space pr(z|x) as Gaussian. Diffusion can generate higher quality images, and can be considered a VAE with hierarchical priors.
