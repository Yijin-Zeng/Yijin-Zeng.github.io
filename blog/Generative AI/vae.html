Variational Autoencoders (VAE)

Generative AI

A concise handwritten version of this note is available as a PDF.

Variational autoencoders (VAEs) are a type of probabilistic generative model. The core idea is to write the "true" distribution over the data as an integral over a latent variable:

pr(x) = ∫ pr(z) pr(x|z) dz

pr(z)    : latent variable (something we never observe)
pr(x|z)  : conditional likelihood given the latent variable

If we can model pr(x) this way, we can generate new samples from it — new images, new molecules, new anything. VAEs were one of the first deep generative models to make this practical, and modern diffusion models can be viewed as their direct descendants. More on that at the end.

Two Examples: Averaging Simple Gaussians

What does that integral actually buy us? Two examples make it concrete.

1. Gaussian Mixture Model. The latent variable is just cluster membership: z_ij = 1 if point x_i belongs to cluster C_j, and 0 otherwise. The conditional likelihood is a plain Gaussian, pr(x_i | z_ij = 1) = N(x_i; μ_j, Σ_j). Each piece is simple, but the weighted average — say p(z=1) = 0.5 and p(z=2) = 0.5 — produces a bimodal pr(x) that no single Gaussian could describe.

2. Non-linear latent variable model. Imagine 2D data scattered along a banana-shaped curve. How to model this distribution? Put a Gaussian prior on a scalar z, map it through a non-linear function f(z; φ), and place a small Gaussian at every point along the curve:

pr(x) = ∫ pr(z) N(x; f(z; φ), Σ) dz

    z axis (latent)              x space (data)
    ────●────────►               ○ ○ ○
        │ f(z; φ)               ○     ○ ○      each circle is a
        ▼                      ○         ○ ○   Gaussian; averaging
    curve in x-space                       ○   them along f(z; φ)
                                               traces the banana

Conclusion for both: a weighted average of simple Gaussian distributions can approximate a very complicated distribution. That's the whole game.

Why We Cannot Just Maximize The Likelihood

So let's do maximum likelihood, right? Take pr(x) = ∫ N(z; 0, I) N(x; f(z; φ), σ²I) dz and maximize it. Two problems.

First, when f is a neural network, this integral has no analytical form. Fine, we can Monte-Carlo it:

pr(x) ≈ E_{z~N(0,I)} [ N(x; f(z; φ), σ²I) ]

Second — and this is the killer — z is high-dimensional. For a given image x, if we sample randomly from z ~ N(0, I), then it is very likely (>99.9% of the time) that N(x; f(z; φ), σ²I) ≈ 0. Almost every random z decodes to something that looks nothing like our image, contributing essentially zero to the estimate. We would need an absurdly large sample size to get a usable signal. So it is hard to maximize the marginal likelihood pr(x) directly.

Instead, we will try to push up a lower bound of the marginal likelihood.

Deriving The Lower Bound (ELBO)

The trick is to multiply and divide by an arbitrary proposal distribution q(z) inside the log, then apply Jensen's inequality (log of an average ≥ average of the log):

log pr(x|φ) = log ( ∫ pr(x, z|φ) dz )

            = log ( ∫ q(z) · pr(x, z|φ) / q(z) dz )

            ≥ ∫ q(z) log ( pr(x, z|φ) / q(z) ) dz     ← Jensen's inequality

This last expression is the famous evidence lower bound (ELBO). The proposal q(z) can be anything (as long as it is a valid distribution), and its choice decides how far the ELBO sits below log pr(x|φ). So why not learn it too? We give it parameters θ and write q(z|θ):

ELBO(θ, φ) = ∫ q(z|θ) log ( pr(x, z|φ) / q(z|θ) ) dz

change φ : move the ELBO (and the target) up
change θ : push the ELBO closer to the target

Another way to see it: a VAE is just the neural network architecture built to maximize the ELBO. The encoder and decoder are what fall out when you take this objective seriously.

Reading The ELBO, Twice

The ELBO can be decomposed in two different ways, and each tells us something different.

Decomposition 1: How Tight Is The Bound?

Expand pr(x, z|φ) = pr(z|x, φ) pr(x|φ) and split the log:

ELBO(θ, φ) = ∫ q(z|θ) log ( pr(z|x, φ) pr(x|φ) / q(z|θ) ) dz

           = log pr(x|φ) − KL( q(z|θ) ‖ pr(z|x, φ) )

So the gap between the ELBO and the true log-likelihood is exactly a KL divergence. When the proposal q(z|θ) = pr(z|x, φ) — the true posterior — the bound is tight: ELBO(θ, φ) = log pr(x|φ). However, pr(z|x, φ) = pr(z) pr(x|z, φ) / pr(x|φ) could be very complex (the denominator is the very integral we can't compute), so we can't just set q to it.

Decomposition 2: Turn The ELBO Into A Loss Function

Now expand the joint the other way, pr(x, z|φ) = pr(x|z, φ) pr(z), where pr(z) is the prior z ~ N(0, I):

ELBO(θ, φ) = ∫ q(z|θ) log pr(x|z, φ) dz − KL( q(z|θ) ‖ pr(z) )
             ─────────────────────────    ────────────────────
             reconstruction term          prior-matching term
             = E_{z~q(z|θ)}[log pr(x|z,φ)]

The first term is the (negative) reconstruction error: samples from q should decode back to something close to x. The second term says the proposal q(z|θ) gets penalized if it deviates from the prior pr(z).

Putting The Pieces Together

Combining the two decompositions, we want three things from q(z|θ) at once:

  • It should be close to the true posterior pr(z|x, φ), so the ELBO approaches the target (decomposition 1).
  • It should minimize reconstruction error, i.e. carry enough information about the observation x (decomposition 2, first term).
  • It should stay close to the prior pr(z), i.e. stay simple (decomposition 2, second term).

Notice the first two both point at the same idea: the good proposal depends on x. So we let:

q(z|θ) = q(z|x, θ) = N( z; g_μ(x; θ), g_Σ(x; θ) )

where g_μ and g_Σ are neural networks that read x and output the mean and covariance. This is the variational approximation — and it's also the encoder. A caveat worth being honest about: the true posterior pr(z|x, φ) could be very complex, so this Gaussian approximation may not be good, which means the ELBO is not necessarily close to the log marginal likelihood. VAEs live with this gap.

The final loss (to minimize) is:

L(θ, φ) = −E_{z~q(·|x,θ)} [ log pr(x|z, φ) ] + KL( q(z|x, θ) ‖ pr(z) )

        ≈ −(1/n) Σᵢ log pr(x|zᵢ, φ)  +  KL( q(z|x, θ) ‖ pr(z) )
                  zᵢ ~ q(z|x, θ)

Since q(z|x, θ) is Gaussian and the prior is Gaussian, the KL term has an explicit closed form — no sampling needed there.

Wait — z is still high-dimensional here, so why does this Monte-Carlo estimate work when the naive one E_{z~N(0,I)}[pr(x|z, φ)] failed? The reason: if z ~ N(0, I), then pr(x|z, φ) ≈ 0 for almost every sample. But if z ~ q(·|x, θ), then pr(x|z, φ) > 0 — the encoder narrows the search down to the small region of latent space that actually corresponds to this image:

   Latent Space N(0, I)                Sample Space
   ┌───────────────────┐              ┌──────────────────┐
   │  x x x  ┌──┐      │   decoder    │        ┌──┐      │
   │  x x    │ ∘│ ─────┼─────────────►│        │ x│      │
   │    x x  └──┘      │ decompression│  x x   └──┘      │
   │  x   x x   x      │◄─────────────┼─ x  x x   x      │
   └───────────────────┘   encoder    └──────────────────┘
     the compression step q(·|x, θ)     compression
     narrows the scope in latent
     space to a small region

The Actual Architecture

Here is the full pipeline, exactly as in the note:

x (image) → encoder → μ, Σ  ── z = μ + L·ε, ε ~ N(0,I) ──→ decoder → f(z; φ)
            learns q(z|x)       (reparameterization trick)   learns the mean
                                                                  │
                              loss: log N( x; f(z; φ), σ²I )  ◄───┘
                                    σ normally fixed at 1 or 0.5

A few practical details worth flagging:

  • Reparameterization trick: instead of sampling z directly from N(μ, Σ) (which blocks gradients), we sample ε ~ N(0, I) and compute z = μ + Σ^(1/2) ε. The randomness is pushed into an input, so gradients flow through μ and Σ.
  • The covariance Σ needs to be symmetric and semi-positive definite. Normally we just assume Σ = diag(σ₁², ..., σₙ²); otherwise use the Cholesky decomposition Σ = LLᵀ, where L is lower-triangular with positive diagonal.
  • The decoder normally only learns the mean f(z; φ), with σ fixed. Why not learn σ too? If the image is hard, training could push σ → ∞ (explain everything as noise); if the image is easy, it would push σ → 0 (likelihood blows up). Neither is what we want.

The encoder lives under a genuine tension: it needs to encode as much information about the image as possible to minimize reconstruction error, versus it needs to stay simple enough that KL(q(z|x, θ) ‖ N(0, I)) is small. The loss makes it negotiate both.

Three Consequences Worth Noting

1. The marginal likelihood doesn't depend on the encoder at all. The target is to maximize pr(x|φ), but the VAE loss maximizes the ELBO directly. What about the gap? From decomposition 1:

log pr(x|φ) = ELBO(θ, φ) + KL( q(z|x, θ) ‖ pr(z|x, φ) )

For a given decoder φ, the left side is a constant with respect to the encoder. So as long as the encoder is pushing the ELBO up, it is automatically minimizing the distance to the true posterior pr(z|x, φ) — even though we never know what that posterior is. The encoder only exists to help the decoder learn: without an encoder, the decoder would need to evaluate the whole latent space to estimate pr(x|φ); with an encoder, the search is narrowed down to q(z|x, θ).

2. Generation throws the encoder away entirely. To generate a new image, just sample from the independent Gaussian prior and decode:

z ~ N(0, I) → decoder → generated image

3. Up-weighting the KL term gives you β-VAE. If we replace the KL term with β·KL(q(z|x, θ) ‖ pr(z)) and increase β, we encourage the latent features to be disentangled — each latent dimension tends to capture one independent factor of variation. A one-character change to the loss, a qualitatively different representation.

Where The Gaussian Assumption Runs Out

To improve the quality of images generated from a VAE, it is not enough to model both the prior pr(z) and the posterior approximation pr(z|x) as Gaussian. Diffusion models generate higher-quality images, and can be viewed as VAEs with hierarchical priors — many small latent steps chained together instead of one big Gaussian leap from z to x.

Summary

  • A weighted average of simple Gaussian distributions can approximate a very complicated distribution — that's the seed idea behind a VAE.
  • Maximizing pr(x|φ) directly is intractable: the integral has no analytical form, and Monte-Carlo sampling from the prior N(0, I) almost always lands on a z that decodes to nothing like x.
  • Multiplying and dividing by a proposal q(z) and applying Jensen's inequality gives the ELBO, a tractable lower bound on log pr(x|φ).
  • Decomposition 1 shows the ELBO's gap to the true log-likelihood is exactly KL(q(z|x,θ) ‖ pr(z|x,φ)). Decomposition 2 turns the ELBO into a loss: reconstruction error plus a KL penalty against the prior.
  • Making q(z|θ) = q(z|x, θ) a Gaussian whose mean and covariance are neural networks of x gives the encoder; sampling from it and decoding gives the reconstruction term — this is the VAE architecture.
  • The reparameterization trick (z = μ + Σ^(1/2)ε) is what lets gradients flow through the sampling step.
  • The encoder exists only to help the decoder learn, and gets thrown away at generation time. Up-weighting its KL term (β-VAE) encourages disentangled latents.
  • Both the prior and posterior being Gaussian is a real restriction; diffusion models relax it with hierarchical priors.
