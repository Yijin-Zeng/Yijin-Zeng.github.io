Constrained Optimization

Mathematics

A concise handwritten version of this note is available as a PDF.

In machine learning, we constantly minimize loss functions. But what happens when there are constraints — boundaries that the solution must respect? This is the world of constrained optimization, and it shows up everywhere from SVMs to regularized models to reinforcement learning.

The Standard Form

Every constrained optimization problem can be written in this standard form:

min  f(x)
 x
s.t. g_i(x) <= 0  for all i = 1, ..., m

Any other formulation can be converted into this. For example, max f(x) becomes min -f(x). An equality constraint g(x) = 0 becomes two inequalities: g(x) <= 0 and -g(x) <= 0.

The Penalty Method (Naive Approach)

A simple (but often impractical) idea: convert it into an unconstrained problem by adding a penalty for violating constraints:

min  f(x) + sum_i I(g_i(x))
 x

where I(z) = 0     if z <= 0
             +inf  otherwise

The problem? This makes the loss landscape terrible. The infinite penalty creates walls in the loss surface — if gradient descent starts on the wrong side, it can never cross over. Even with a large finite penalty instead of infinity, the sharp discontinuity makes optimization extremely difficult.

Lagrange Multiplier Method

Instead of hard walls, we introduce Lagrange multipliers that softly penalize constraint violations. Define the Lagrangian:

L(x, lambda) = f(x) + lambda^T g(x)

where lambda = (lambda_1, ..., lambda_m)^T
      g(x) = (g_1(x), ..., g_m(x))^T

The original problem is equivalent to:

min  max  L(x, lambda)
 x  lambda>=0

Why? For a feasible x (where all g_i(x) <= 0), the max over lambda >= 0 just gives f(x) since the lambda terms are non-positive. For an infeasible x, some g_i(x) > 0, and lambda can drive the Lagrangian to infinity. So the min-max formulation naturally enforces the constraints.

The Dual Problem

Here's a key observation. For any function phi(x, y):

min phi(x,y) <= phi(x,y) <= max phi(x,y)
 x                             y

=> max min phi(x,y) <= min max phi(x,y)
    y   x              x   y

This gives us the Lagrange dual problem:

(d)  max  min  L(x, lambda)
    lambda  x
     s.t. lambda >= 0

Denote q(lambda) = min_x L(x, lambda) — this is called the inner problem. The dual problem is much easier than the original for three reasons:

  1. Simpler constraints: we go from g_i(x) <= 0 (which could be arbitrarily complex) to lambda_i >= 0 (simple box constraints, the easiest kind)
  2. Convexity: even if min f(x) is non-convex, max q(lambda) is always a convex problem
  3. Dimensionality reduction: say x is in R^10000 and we have 5 constraints — the dual reduces the problem to just 5 dimensions

Duality Gap

The difference between the original and dual solutions is the duality gap:

G = q* - d*

where q* = optimal value of original problem
      d* = optimal value of dual problem
  • G = 0 (strong duality): the dual gives the exact solution
  • G > 0 (weak duality): the dual only gives a lower bound — the x found by the dual is not in the feasible region of the original problem

When Does Strong Duality Hold?

A sufficient (not just necessary) condition is Slater's condition:

  1. Convexity: f(x) and all g_i(x) are convex
  2. Strict feasibility: there exists at least one x such that g_i(x) < 0 for all i (strictly inside the feasible region, not on the boundary)

Why might weak duality happen? In the inner problem min_x (f(x) + lambda^T g(x)), when g_i(x) > 0 (violating the constraint), we get a penalty lambda_i * g_i(x). But if f(x) is very deep (very small) at that point, the violation might be "worth it" from the Lagrangian's perspective.

KKT Conditions

While the Lagrange method gives us a simpler dual problem, it doesn't directly solve the problem. We often solve constrained optimization directly using KKT (Karush-Kuhn-Tucker) conditions. These give a local minimum (or global, if Slater's condition holds).

The four conditions are:

  1. Stationarity: grad_x f(x) + lambda^T grad_x g(x) = 0 — at the minimum, the gradient of the Lagrangian must be zero
  2. Primal feasibility: g_i(x) <= 0 for all i — the solution must satisfy the original constraints
  3. Dual feasibility: lambda_i >= 0 for all i — multipliers must be non-negative
  4. Complementary slackness: lambda_i * g_i(x) = 0 for all i — either the constraint is active (g_i = 0) or its multiplier is zero

The complementary slackness condition is the most interesting one. It says: if a constraint is not tight (g_i(x) < 0, meaning we're strictly inside the feasible region), then lambda_i = 0 — that constraint doesn't matter at the optimum. This makes intuitive sense: why would a constraint that isn't binding affect the solution?

Using KKT to Find Solutions

KKT conditions are both a checklist to verify a candidate solution and a tool to find one:

  1. Guess which constraints are active (on the boundary) — following complementary slackness, for each constraint either g_i(x) = 0 or lambda_i = 0
  2. Solve for x and lambda from the stationarity and complementary slackness equations
  3. Check feasibility — if it passes, you've found a local minimum. If not, go back to step 1 with a different guess

Different guesses in step 1 can give different local minima. With m constraints, there are 2^m possible combinations to try in the worst case.
