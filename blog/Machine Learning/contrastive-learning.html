Contrastive Learning

Machine Learning

A concise handwritten version of this note is available as a PDF.

The core idea for contrastive learning is simple: similar things should be close together in embedding space, and dissimilar things should be far apart.

The Core Idea

Contrastive learning is a self-supervised (or weakly-supervised) framework that learns representations by contrasting positive pairs against negative pairs. Rather than predicting explicit labels, the model learns an embedding space where semantically related inputs are close together and unrelated inputs are far apart.

Structure of CLIP

CLIP (Contrastive Language-Image Pre-training) is a good example of contrastive learning applied to vision-language alignment. Its architecture consists of two parallel encoders:

  • Language encoder: processes a batch of captions into text embeddings
  • Image encoder: processes a batch of images into image embeddings

Given a batch of n (image, caption) pairs, both encoders produce embeddings that live in the same shared space. The model then computes a similarity matrix S between all image-text pairs:

Each entry S_i,j in the matrix represents the dot-product similarity between image embedding i and text embedding j. The diagonal entries (where i = j) correspond to the correct image-text pairings.

Loss Function: Symmetric Cross-Entropy

CLIP uses a symmetric cross-entropy loss with a learnable temperature parameter. The loss operates in both directions: image-to-text and text-to-image.

Image-to-Text Loss

For each image i, we want to maximize the probability of selecting the correct caption i from among all captions in the batch:

L_i^(I->T) = -log( exp(S_i,i / tau) / sum_j exp(S_i,j / tau) )

The fraction inside the log can be interpreted as the probability that image i correctly identifies its paired text. Thus the loss is log-likelihood. The temperature tau is a learnable parameter which controls the sharpness of the distribution. Ideally, a good learned temperature can tune the distances to reflect the true probability. If this is not the case, we could also consider the tune this parameter on a seperate dataset, e.g. by maximizing Expected Calibration Error (ECE). This is a different topic, though.

Text-to-Image Loss

Symmetrically, for each text i, we want to maximize the probability of selecting the correct image i:

L_i^(T->I) = -log( exp(S_i,i / tau) / sum_j exp(S_j,i / tau) )

Final Loss

The overall training objective averages both directions across all pairs in the batch:

L = (1 / 2n) * sum_i [ L_i^(I->T) + L_i^(T->I) ]

This symmetric formulation ensures the model learns good representations from both the image and text perspectives simultaneously.

Other Contrastive Loss Methods

Pairwise Contrastive Loss

This method looks at one pair of samples at a time. Each pair is labeled as either positive (matching, e.g., image i with caption i) or negative (non-matching, e.g., image i with caption j).

Loss = Y * D^2 + (1 - Y) * max(0, m - D)^2

Where:

  • Y = 1 for positive pairs, Y = 0 for negative pairs
  • D is the distance between the two embeddings
  • m is a margin hyperparameter

The intuition is straightforward:

  • Positive pair (Y=1): minimize the distance D directly.
  • Negative pair (Y=0): push the distance to be at least m apart (only penalize if D < m). But if the distance is already larger than m, leave it as it is (the same idea as in support vector machine (SVM)).

Triplet Loss

Triplet loss considers three data points at a time:

  1. Anchor (a): the baseline image
  2. Positive (p): a paired caption (should be close to anchor)
  3. Negative (n): an unpaired caption (should be far from anchor)
Loss = max(0, d(a,p) - d(a,n) + m)
The distance between anchor and positive should be smaller than the distance between anchor and negative by at least a margin m.

The loss is zero when the constraint is satisfied (i.e., the negative is sufficiently farther away than the positive). Otherwise, it pushes the model to reorganize the embedding space accordingly.

Comparing the Approaches

  • Pairwise loss is simple but only sees two samples at a time, which can be slow to converge.
  • Triplet loss provides richer signal by explicitly comparing relative distances, but requires careful mining of hard negatives.
  • CLIP-style (InfoNCE) loss scales to entire batches, using all other samples as negatives simultaneously, making it highly efficient for large-scale training.
