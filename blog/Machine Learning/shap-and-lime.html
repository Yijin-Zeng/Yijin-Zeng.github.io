SHAP and LIME

Machine Learning

A concise handwritten version of this note is available as a PDF.

A question we often want to ask is "why did the model make this particular prediction?" For some models, this question might be easier to answer, such as linear regression, decision tree, or K-means. However, for more complexed models, such as a deep neural network, this question could be much very hard to answer. Model agnostic interpretation is therefore crucial for us to understand a model's behaivor. Two widely used, and often very useful such tools for explaining model's decisions are LIME, and SHAP. In short, LIME fits a local linear model around the prediction point, while SHAP uses game theory (Shapley values) to fairly distribute the prediction among features.

LIME: Local Interpretable Model-agnostic Explanations

LIME finds a local linear approximation of any model. The idea is that while a model (e.g. f(x1, x2, x3)) can be very complex globally, a linear approximate in the vicinity of a particular instance could be good. So we can fit a simple, interpretable linear model around the instance, and this linear model will behave similarly to the complex model near the point of interest.

Step 1: Create a Neighborhood

Generate perturbed samples around the instance we want to explain by introducing small perturbations to the original feature values:

Step 2: Make Predictions

Use the original (complex) model to get predictions for all perturbed instances:

y1 = f(x1), y2 = f(x2), ..., yn = f(xn)

Step 3: Measure Distance

Compute the distance between the original instance x and each perturbed instance:

d_i = d(x, x_i)
  • For continuous features: use Euclidean distance (or other suitable metric)
  • For categorical features: if the value is the same as the original, distance is 0; if different, distance is 1

Step 4: Compute Weights

Assign weights to each perturbed instance using an exponential kernel. The intuition: instances close to the original should get more weight.

w_i = exp(-d_i^2 / sigma^2)

Here sigma is the kernel width, which controls the locality of the explanation:

  • A small sigma: only instances very close to the original get attention (more local explanation)
  • A larger sigma: instances farther from the original also receive attention (broader explanation)

Step 5: Fit a Weighted Linear Regression

With the perturbed instances as input, their predictions as labels, and the distance-based weights, fit a weighted linear regression:

Input:  x1, ..., xn
Labels: y1, ..., yn

Loss = sum_{i=1}^{n} w_i * (y_i - sum_{j=1}^{d} beta_j * x_{ij})^2

The weight w_i ensures that the loss for each sample is weighted by its proximity to the original instance. The learned coefficients beta_j tell us how the model output changes locally when feature j changes.

LIME for Classification

For classification problems, suppose the model predicts probabilities for multiple classes: p(A) = 0.3, p(B) = 0.2, p(C) = 0.5. To explain why the model predicted p(A) = 0.3, run LIME with y = p(A) as the target -- that is, use the probability of class A as the label for each perturbed instance.

SHAP: SHapley Additive exPlanations

SHAP takes a game-theoretic approach to explain the output (prediction) of any machine learning model. It is grounded in Shapley values from cooperative game theory.

The Game Theory Analogy

  1. The "game" is to make one prediction
  2. The "players" are the model's features
  3. The "payout" is the final prediction minus the average prediction
  4. The "question": how to fairly distribute the "payout" among different features?

Example Setup

Consider a model that predicts the price of a flat given three features:

  • x1: location
  • x2: square footage
  • x3: number of bedrooms

The model can be anything -- linear model, tree, neural network, etc. Given specific values for x1, x2, x3, we get a prediction y_hat = f(x1, x2, x3). The question is: how does each feature contribute to this particular prediction?

Computing the SHAP Value for a Feature

To find the contribution of x1, we consider all possible coalitions (subsets) of features and measure how adding x1 changes the prediction.

First, compute predictions for all possible subsets of features. When a feature is "absent" from a coalition, we marginalize over it (take the expectation over its possible values):

  • Average prediction: E[f(x1, x2, x3)]
  • Prediction with only {x1}: E[f(x1, x2, x3) | X1 = x1]
  • Prediction with {x1, x2}: E[f(x1, x2, x3) | X1 = x1, X2 = x2]
  • ...and so on for all subsets

Marginal Contributions

For each coalition that does not contain x1, compute the marginal contribution of x1 by comparing the prediction with and without it:

Coalition {}:
  Without x1: C({}) = E[f(x1,x2,x3)]
  With x1:    C({x1}) = E[f(x1,x2,x3) | X1=x1]
  Marginal contribution: C({x1}) - C({})

Coalition {x2}:
  Without x1: C({x2}) = E[f(x1,x2,x3) | X2=x2]
  With x1:    C({x1,x2}) = E[f(x1,x2,x3) | X1=x1, X2=x2]
  Marginal contribution: C({x1,x2}) - C({x2})

Coalition {x3}:
  Without x1: C({x3}) = E[f(x1,x2,x3) | X3=x3]
  With x1:    C({x1,x3}) = E[f(x1,x2,x3) | X1=x1, X3=x3]
  Marginal contribution: C({x1,x3}) - C({x3})

Coalition {x2, x3}:
  Without x1: C({x2,x3}) = E[f(x1,x2,x3) | X2=x2, X3=x3]
  With x1:    C({x1,x2,x3}) = f(x1,x2,x3)
  Marginal contribution: C({x1,x2,x3}) - C({x2,x3})

The SHAP Value Formula

The SHAP value is the weighted average of all marginal contributions of x1 across all coalitions. The weight for each coalition of size n_i (out of d total features) is:

weight = n_i! * (d - n_i - 1)! / d!

For example, with d = 3 features and coalition {x2} (size n_i = 1):

weight = 1! * (3 - 1 - 1)! / 3! = 1 * 1 / 6 = 1/6

This weighting ensures that all possible orderings in which features could join the coalition are treated equally -- this is the fairness guarantee from Shapley value theory.

From Individual to Global Explanations

The procedure above computes the SHAP value for one feature in one prediction. We can compute SHAP values for all features across many predictions. Averaging the absolute SHAP values for one feature across many predictions gives us a measure of feature importance -- how much that feature matters globally.

Practical Considerations

Computing exact SHAP values requires evaluating 2^d marginal contributions (one for each possible coalition), which becomes impractical as the number of features grows. Approximation methods are necessary in practice.

For efficient approximation, see the SHAP KernelExplainer, which uses a weighted linear regression approach (similar in spirit to LIME) to approximate Shapley values without exhaustive enumeration.
