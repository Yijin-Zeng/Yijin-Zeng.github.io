Linear Regression

Machine Learning

A concise handwritten version of this note is available as a PDF.

Linear models are one of the simplest and most well-understood classes of models. A linear model is defined as Y = Xβ + e, where Y is the vector of observations, X is the design matrix, β is the parameter vector, and e is an error vector such that E(e) = 0.

If e ~ N(0, σ²I), the model is called a normal linear model, and we have Y|X ~ N(Xβ, σ²I). This relies on two properties of e: (1) the errors are uncorrelated, and (2) they have the same variance.

Estimation of β

We can consider estimating β from different perspectives, and they all lead to the same result.

1. Minimize MSE

Let e = Y - Ŷ = Y - Xβ. Then eTe = (Y - Xβ)T(Y - Xβ). Taking the derivative with respect to β:

∂(eᵀe)/∂β = 2(Y - Xβ)ᵀ(-X) = -2(YᵀX - βᵀXᵀX)

Setting this to zero and using YTX = βTXTX, we get βT = YTX(XTX)-1 (if X has full column rank), so

β̂ = (XᵀX)⁻¹XᵀY

2. Maximize the likelihood function

The likelihood function is

L(β, σ²; Y) = (2πσ²)^(-n/2) exp{ -1/(2σ²) (Y-Xβ)ᵀ(Y-Xβ) }

so the log-likelihood is

l(β, σ²; Y) = -n/2 log(2πσ²) - 1/(2σ²) (Y-Xβ)ᵀ(Y-Xβ)

Maximizing the likelihood function is therefore equivalent to minimizing the MSE.

3. Projection

Consider solving Y = Xβ directly. We cannot find a solution for β, because normally n ≫ m, so Y ∉ Col(X). Therefore, we choose a β̂ such that Xβ̂ is the closest vector to Y. This vector is the projection of Y onto Col(X):

X(XᵀX)⁻¹XᵀY = Xβ̂  =>  β̂ = (XᵀX)⁻¹XᵀY

which gives the same result as the first two approaches.

If (XTX)-1 does not exist — in other words, X does not have full column rank, e.g. if m > n — we have two options.

1. Ridge regression

β̂ = (XᵀX + λI)⁻¹Xᵀy

Writing XTX = UΛUT by eigendecomposition, XTX + λI = U(Λ + λI)UT, i.e. ridge regression shifts all eigenvalues up by λ, which makes the matrix invertible.

2. Pseudoinverse of X

Any matrix A has an SVD A = UΣVT. The pseudoinverse is defined as A+ = VΣ+UT, where Σ+ takes the transpose of Σ and inverts each singular value.

  1. If A-1 exists, then A+ = A-1.
  2. If (ATA)-1 exists, then A+ = (ATA)-1AT, which reduces to the same compact SVD form VΣ+UT.

If (ATA)-1 does not exist, then ATAβ = ATy has infinitely many solutions, because Col(ATA) = Col(AT). Among these solutions, β = A+y is the one with the minimum L2 norm.

Consider another solution β*. Since ATA(β̂ - β*) = 0, we have β* = β̂ + n where n ∈ Null(ATA) = Null(A). Since β̂ ⊥ n,

||β*||² = ||β̂||² + ||n||² ≥ ||β̂||²

For this reason, when solving Ax = β, we often just use x = A+β directly.

Properties of β̂

We know β̂ = (XTX)-1XTY, given that X has full column rank. Since Y|X ~ N(Xβ, σ²I) and β̂ is a linear combination of Y, β̂ must follow a normal distribution as well.

E(β̂) = E((XᵀX)⁻¹XᵀY) = (XᵀX)⁻¹XᵀE(Y) = (XᵀX)⁻¹XᵀXβ = β

so β̂ is an unbiased estimator of β.

Cov(β̂) = Cov((XᵀX)⁻¹XᵀY) = (XᵀX)⁻¹XᵀCov(Y)X(XᵀX)⁻¹ = σ²(XᵀX)⁻¹

Gauss-Markov Theorem

Assume a linear model with unknown parameter β, a design matrix with full rank, and Cov(e) = σ²I. For any fixed c ∈ Rm, let β̂ be the least squares estimator of the linear model. Then cTβ̂ has the smallest variance among all linear unbiased estimators for cTβ.

Suppose there is another linear, unbiased estimator β̃. Since it is linear, we must have β̃ = WY. Let's define W = (XTX)-1XT + D.

Since β̃ is unbiased,

E(β̃) = E(WY) = E(W(Xβ+e)) = WXβ  =>  WX = I  =>  DX = 0

Then

Var(β̃) = Var(WY) = W Var(Y) Wᵀ = σ²WWᵀ
        = σ²((XᵀX)⁻¹ + DDᵀ)
        = Var(β̂) + σ²DDᵀ

so Var(cTβ̃) = cTVar(β̂)c + σ²cTDDTc ≥ Var(cTβ̂).

Estimation of σ²

Let e = Y - Ŷ, RSS = eTe. Then σ̂² = RSS/(n-r) is an unbiased estimator of σ².

Write P = X(XTX)-1XT. Then

E(RSS) = E((Y-Ŷ)ᵀ(Y-Ŷ)) = E((Y-PY)ᵀ(Y-PY)) = E(Yᵀ(I-P)ᵀ(I-P)Y)

P is a projection matrix, so I-P is also a projection matrix, meaning (I-P)T = I-P and (I-P)² = I-P. So E(RSS) = E(YT(I-P)Y).

Since (I-P)T = I-P, we can write I-P = SΛST. Then (I-P)² = SΛ²ST, so the eigenvalues of I-P are 0 or 1. Since the sum of eigenvalues equals

trace(I-P) = n - trace(X(XᵀX)⁻¹Xᵀ) = n - trace((XᵀX)⁻¹XᵀX) = n - m

Λ has n-m ones on its diagonal.

So E(RSS) = E(YTSΛSTY). Let Z = STY. We have Cov(Z) = STCov(Y)S = σ²I, so Z consists of independent normal random variables with variance σ². This gives

ZᵀΛZ / σ² ~ χ²_(n-m)   =>   E(ZᵀΛZ / σ²) = n-m   =>   E(RSS / (n-m)) = σ²

Inference

We now consider the confidence interval for an estimation cTβ.

We know β̂ ~ N(β, σ²(XTX)-1), so cTβ̂ ~ N(cTβ, σ²cT(XTX)-1c), and

(cᵀβ̂ - cᵀβ) / √(σ²cᵀ(XᵀX)⁻¹c) ~ N(0,1)

Plugging in σ̂² = RSS/(n-p):

(cᵀβ̂ - cᵀβ) / √(σ̂²cᵀ(XᵀX)⁻¹c) ~ t_(n-p)

which gives the confidence interval

cᵀβ ∈ [ cᵀβ̂ - t_(n-p)(α/2)√(σ̂²cᵀ(XᵀX)⁻¹c) ,
        cᵀβ̂ + t_(n-p)(1-α/2)√(σ̂²cᵀ(XᵀX)⁻¹c) ]

Two notes:

  1. For the confidence interval of a single βi, let cT = (0, 0, ..., 1, 0, ..., 0), with the 1 at component i.
  2. cT can also be an input vector, in which case the confidence interval above is for cTβ, i.e. the average output given that input. For a confidence interval of a single prediction, we need to take that into account separately.
