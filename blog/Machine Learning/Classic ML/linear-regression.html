Linear Regression

Machine Learning

A concise handwritten version of this note is available as a PDF.

Linear models are one of the simplest and most well-understood classes of machine learning models. A linear model is defined as $Y = X\beta + e$, where $Y$ is the vector of observations, $X$ is the design matrix, $\beta$ is the parameter vector, and $e$ is an error vector such that $\mathbb{E}(e) = 0$. Further, if $e \sim \mathcal{N}(0, \sigma^2 I)$, the model is then known as a normal linear model, and we have $Y|X \sim \mathcal{N}(X\beta, \sigma^2 I)$. This relies on two properties of the noise $e$: (1) the errors are uncorrelated, and (2) they have the same variance.

Estimation of $\beta$

$\beta$ is the parameter vector we want to learn from the data. We can consider estimating $\beta$ from a few different perspectives. As we will show, they all lead to the same result.

1. Minimize MSE

Let us denote the estimation deviation as $e = Y - \hat{Y} = Y - X\beta$. Then $e^T e = (Y - X\beta)^T (Y - X\beta)$ is Taking the derivative with respect to $\beta$:

$$\frac{\partial (e^T e)}{\partial \beta} = 2(Y - X\beta)^T(-X) = -2(Y^T X - \beta^T X^T X)$$

Setting this to zero and using $Y^T X = \beta^T X^T X$, we get $\beta^T = Y^T X (X^T X)^{-1}$ (if $X$ has full column rank), so

$$\hat{\beta} = (X^T X)^{-1} X^T Y$$

2. Maximize the likelihood function

The likelihood function is

$$L(\beta, \sigma^2; Y) = (2\pi\sigma^2)^{-n/2} \exp\left\{ -\frac{1}{2\sigma^2} (Y - X\beta)^T (Y - X\beta) \right\}$$

so the log-likelihood is

$$l(\beta, \sigma^2; Y) = -\frac{n}{2} \log(2\pi\sigma^2) - \frac{1}{2\sigma^2} (Y - X\beta)^T (Y - X\beta)$$

Maximizing the likelihood function is therefore equivalent to minimizing the MSE.

3. Projection

Consider solving $Y = X\beta$ directly. We cannot find a solution for $\beta$, because normally $n \gg m$, so $Y \notin \mathrm{Col}(X)$. Therefore, we choose a $\hat{\beta}$ such that $X\hat{\beta}$ is the closest vector to $Y$. This vector is the projection of $Y$ onto $\mathrm{Col}(X)$:

$$X(X^T X)^{-1} X^T Y = X\hat{\beta} \quad\Rightarrow\quad \hat{\beta} = (X^T X)^{-1} X^T Y$$

which gives the same result as the first two approaches.

If $(X^T X)^{-1}$ does not exist — in other words, $X$ does not have full column rank, e.g. if $m > n$ — we have two options.

1. Ridge regression

$$\hat{\beta} = (X^T X + \lambda I)^{-1} X^T y$$

Writing $X^T X = U\Lambda U^T$ by eigendecomposition, $X^T X + \lambda I = U(\Lambda + \lambda I)U^T$, i.e. ridge regression shifts all eigenvalues up by $\lambda$, which makes the matrix invertible.

2. Pseudoinverse of X

Any matrix $A$ has an SVD $A = U\Sigma V^T$. The pseudoinverse is defined as $A^{+} = V\Sigma^{+}U^T$, where $\Sigma^{+}$ takes the transpose of $\Sigma$ and inverts each singular value.

  1. If $A^{-1}$ exists, then $A^{+} = A^{-1}$.
  2. If $(A^T A)^{-1}$ exists, then $A^{+} = (A^T A)^{-1} A^T$, which reduces to the same compact SVD form $V\Sigma^{+}U^T$.

If $(A^T A)^{-1}$ does not exist, then $A^T A\beta = A^T y$ has infinitely many solutions, because $\mathrm{Col}(A^T A) = \mathrm{Col}(A^T)$. Among these solutions, $\beta = A^{+}y$ is the one with the minimum $L_2$ norm.

Consider another solution $\beta^*$. Since $A^T A(\hat{\beta} - \beta^*) = 0$, we have $\beta^* = \hat{\beta} + n$ where $n \in \mathrm{Null}(A^T A) = \mathrm{Null}(A)$. Since $\hat{\beta} \perp n$,

$$\|\beta^*\|^2 = \|\hat{\beta}\|^2 + \|n\|^2 \geq \|\hat{\beta}\|^2$$

For this reason, when solving $Ax = \beta$, we often just use $x = A^{+}\beta$ directly.

Properties of $\hat{\beta}$

We know $\hat{\beta} = (X^T X)^{-1} X^T Y$, given that $X$ has full column rank. Since $Y|X \sim \mathcal{N}(X\beta, \sigma^2 I)$ and $\hat{\beta}$ is a linear combination of $Y$, $\hat{\beta}$ must follow a normal distribution as well.

$$\mathbb{E}(\hat{\beta}) = \mathbb{E}\left((X^T X)^{-1} X^T Y\right) = (X^T X)^{-1} X^T \mathbb{E}(Y) = (X^T X)^{-1} X^T X\beta = \beta$$

so $\hat{\beta}$ is an unbiased estimator of $\beta$.

$$\mathrm{Cov}(\hat{\beta}) = \mathrm{Cov}\left((X^T X)^{-1} X^T Y\right) = (X^T X)^{-1} X^T \,\mathrm{Cov}(Y)\, X(X^T X)^{-1} = \sigma^2 (X^T X)^{-1}$$

Gauss-Markov Theorem

Assume a linear model with unknown parameter $\beta$, a design matrix with full rank, and $\mathrm{Cov}(e) = \sigma^2 I$. For any fixed $c \in \mathbb{R}^m$, let $\hat{\beta}$ be the least squares estimator of the linear model. Then $c^T\hat{\beta}$ has the smallest variance among all linear unbiased estimators for $c^T\beta$.

Suppose there is another linear, unbiased estimator $\tilde{\beta}$. Since it is linear, we must have $\tilde{\beta} = WY$. Let's define $W = (X^T X)^{-1} X^T + D$.

Since $\tilde{\beta}$ is unbiased,

$$\mathbb{E}(\tilde{\beta}) = \mathbb{E}(WY) = \mathbb{E}(W(X\beta + e)) = WX\beta \quad\Rightarrow\quad WX = I \quad\Rightarrow\quad DX = 0$$

Then

$$\begin{aligned} \mathrm{Var}(\tilde{\beta}) &= \mathrm{Var}(WY) = W\,\mathrm{Var}(Y)\,W^T = \sigma^2 WW^T \\ &= \sigma^2\left((X^T X)^{-1} + DD^T\right) \\ &= \mathrm{Var}(\hat{\beta}) + \sigma^2 DD^T \end{aligned}$$

so $\mathrm{Var}(c^T\tilde{\beta}) = c^T\mathrm{Var}(\hat{\beta})c + \sigma^2 c^T DD^T c \geq \mathrm{Var}(c^T\hat{\beta})$.

Estimation of $\sigma^2$

Let $e = Y - \hat{Y}$, $\mathrm{RSS} = e^T e$. Then $\hat{\sigma}^2 = \mathrm{RSS}/(n-r)$ is an unbiased estimator of $\sigma^2$.

Write $P = X(X^T X)^{-1} X^T$. Then

$$\mathbb{E}(\mathrm{RSS}) = \mathbb{E}\left((Y - \hat{Y})^T (Y - \hat{Y})\right) = \mathbb{E}\left((Y - PY)^T (Y - PY)\right) = \mathbb{E}\left(Y^T (I-P)^T (I-P) Y\right)$$

$P$ is a projection matrix, so $I-P$ is also a projection matrix, meaning $(I-P)^T = I-P$ and $(I-P)^2 = I-P$. So $\mathbb{E}(\mathrm{RSS}) = \mathbb{E}(Y^T (I-P) Y)$.

Since $(I-P)^T = I-P$, we can write $I-P = S\Lambda S^T$. Then $(I-P)^2 = S\Lambda^2 S^T$, so the eigenvalues of $I-P$ are 0 or 1. Since the sum of eigenvalues equals

$$\mathrm{trace}(I-P) = n - \mathrm{trace}\left(X(X^T X)^{-1} X^T\right) = n - \mathrm{trace}\left((X^T X)^{-1} X^T X\right) = n - m$$

$\Lambda$ has $n-m$ ones on its diagonal.

So $\mathbb{E}(\mathrm{RSS}) = \mathbb{E}(Y^T S\Lambda S^T Y)$. Let $Z = S^T Y$. We have $\mathrm{Cov}(Z) = S^T \mathrm{Cov}(Y) S = \sigma^2 I$, so $Z$ consists of independent normal random variables with variance $\sigma^2$. This gives

$$\frac{Z^T \Lambda Z}{\sigma^2} \sim \chi^2_{n-m} \quad\Rightarrow\quad \mathbb{E}\left(\frac{Z^T \Lambda Z}{\sigma^2}\right) = n-m \quad\Rightarrow\quad \mathbb{E}\left(\frac{\mathrm{RSS}}{n-m}\right) = \sigma^2$$

Inference

We now consider the confidence interval for an estimation $c^T\beta$.

We know $\hat{\beta} \sim \mathcal{N}(\beta, \sigma^2 (X^T X)^{-1})$, so $c^T\hat{\beta} \sim \mathcal{N}(c^T\beta, \sigma^2 c^T (X^T X)^{-1} c)$, and

$$\frac{c^T\hat{\beta} - c^T\beta}{\sqrt{\sigma^2 c^T (X^T X)^{-1} c}} \sim \mathcal{N}(0,1)$$

Plugging in $\hat{\sigma}^2 = \mathrm{RSS}/(n-p)$:

$$\frac{c^T\hat{\beta} - c^T\beta}{\sqrt{\hat{\sigma}^2 c^T (X^T X)^{-1} c}} \sim t_{n-p}$$

which gives the confidence interval

$$c^T\beta \in \left[\, c^T\hat{\beta} - t_{n-p}(\alpha/2)\sqrt{\hat{\sigma}^2 c^T (X^T X)^{-1} c} \,,\;\; c^T\hat{\beta} + t_{n-p}(1-\alpha/2)\sqrt{\hat{\sigma}^2 c^T (X^T X)^{-1} c} \,\right]$$

Two notes:

  1. For the confidence interval of a single $\beta_i$, let $c^T = (0, 0, ..., 1, 0, ..., 0)$, with the 1 at component $i$.
  2. $c^T$ can also be an input vector, in which case the confidence interval above is for $c^T\beta$, i.e. the average output given that input. For a confidence interval of a single prediction, we need to take that into account separately.
