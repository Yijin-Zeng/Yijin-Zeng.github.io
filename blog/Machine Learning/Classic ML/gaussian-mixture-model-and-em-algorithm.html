Gaussian Mixture Model and EM Algorithm

Machine Learning

A concise handwritten version of this note is available as a PDF.

Gaussian mixture model (GMM) is a type of clustering model that assumes the instances are generated from a mixture of Gaussian distributions.

Compare with K-means

Naive K-means method cannot cluster elliptical clusters well, because it creates circles or balls around its centers. It also cannot deal with clusters with different variance well, because it uses the same distance measure (normally L2) for different clusters. GMM handles both well, since each cluster gets its own mean μ_j and its own covariance Σ_j.

Assumptions of Gaussian Mixture Model

Start from the likelihood of the observations:

pr(x_1, ..., x_n) = pr(x_1) ⋯ pr(x_n)                           (independence assumption)

                  = ∏_{i=1}^{n} Σ_{j=1}^{K} p(x_i ∈ cluster j) p(x_i | x_i ∈ cluster j)
                                                                  (law of total probability)

                  = ∏_{i=1}^{n} Σ_{j=1}^{K} λ_j N(x_i ; μ_j, Σ_j)
                                                                  (Gaussian assumption)

Generation process: the latent variable z is a discrete variable equal to z_i (where z_i = 1, ..., K) with probability λ_i. Given this latent variable, the likelihood of the data x is normally distributed with mean = μ_i, variance = Σ_j². In other words: z goes to each cluster with probability λ_i, and within each cluster the data is generated from the corresponding Gaussian distribution N(μ_i, Σ_i²), giving the observation x.

The difficulty to maximize the Likelihood Function Directly

The likelihood function for GMM equals to: 
pr(x_1, ..., x_n) = ∏_{i=1}^n Σ_{j=1}^K λ_j N(x_i ; μ_j, Σ_j)

If we minimize the negative log-likelihood, we need to solve

min_{λ,μ,Σ}  ( -l(λ, μ, Σ; x_1, ..., x_n) ) = min_{λ,μ,Σ}  -Σ_i log( Σ_j λ_j N(x_i ; μ_j, Σ_j) )

    = min_{λ,μ,Σ}  -Σ_i log( Σ_j λ_j (1 / ((2π)^{d/2} |Σ_j|^{1/2})) exp{ -1/2 (x_i-μ_j)ᵀ Σ_j⁻¹ (x_i-μ_j) } )

s.t.  Σ_j λ_j = 1,   Σ_j symmetric and positive semi-definite

Because of the sum within the log, we cannot use log to cancel out exp. There is no analytical form for the gradient w.r.t. λ, μ, Σ as well. We also need to satisfy the constraints, so directly using gradient descent is not ideal.

Notice that the problem is also ill-defined. If μ_j → x_i, Σ_j → 0, then pr(x_1, ..., x_n) → infty.

Below we consider how to use the E-M algorithm to solve these issues.

EM Algorithm

Problem: solving argmax_θ l(θ; x) directly is hard.

Observation: if we introduce some latent variables z, then argmax_θ l(θ; x, z) — this is easy.

EM algorithm:

θ^(t+1) = argmax_θ  E_{z~p(·|x, θ^(t))} [ l(θ; x, z) ]
          ────────  ────────────────────────────────────
           M-step                E-step

Why Does EM Algorithm Work?

Notice that p(x, z, θ) = p(x; θ) p(z|x; θ):

=> l(θ; x, z) = l(θ; x) + l(θ; z|x)

=> l(θ; x) = l(θ; x, z) - l(θ; z|x)
    ────────    ─────────
    target      the one we can maximize easily

Take expectation on both sides w.r.t. z ~ p(·|x, θ^(t)):

l(θ; x) = E_{z~p(·|x,θ^(t))}[ l(θ; x, z) ] - E_{z~p(·|x,θ^(t))}[ l(θ; z|x) ]

=> l(θ^(t); x) = E_{z~p(·|x,θ^(t))}[ l(θ^(t); x, z) ] - E_{z~p(·|x,θ^(t))}[ l(θ^(t); z|x) ]

=> l(θ; x) - l(θ^(t); x) = E_{z~p(·|x,θ^(t))}[ l(θ; x, z) ] - E_{z~p(·|x,θ^(t))}[ l(θ^(t); x, z) ]

                          - E_{z~p(·|x,θ^(t))}[ l(θ; z|x) ] + E_{z~p(·|x,θ^(t))}[ l(θ^(t); z|x) ]

                          = E_{z~p(·|x,θ^(t))}[ l(θ; x, z) ] - E_{z~p(·|x,θ^(t))}[ l(θ^(t); x, z) ]

                          + KL( p(z|x, θ^(t)), p(z|x, θ) )
                            ─────────────────────────────
                                        ≥ 0

Since θ^(t+1) = argmax_θ E_{z~p(·|x,θ^(t))}[ l(θ; x, z) ], we have

E_{z~p(·|x,θ^(t))}[ l(θ^(t+1); x, z) ]  ≥  E_{z~p(·|x,θ^(t))}[ l(θ^(t); x, z) ]

So l(θ^(t+1); x) ≥ l(θ^(t); x), i.e. the EM algorithm leads to a non-decreasing likelihood function at each step.

EM Algorithm for Gaussian Mixture Model

Introduce latent variables:

z_ij = 1  if x_i ∈ C_j
     = 0  otherwise

In order to use the EM algorithm, we need the joint distribution p(x, z; θ^(t)) and the conditional distribution p(z|x; θ^(t)).

E-Step

Joint distribution:

p(x, z; λ, μ, Σ) = ∏_{i=1}^n ∏_{j=1}^K ( λ_j N(x_i; μ_j, Σ_j) )^{z_ij}

=> l(λ, μ, Σ; x, z) = Σ_i Σ_j z_ij ( log λ_j + log N(x_i; μ_j, Σ_j) )

Conditional distribution, by Bayes' theorem:

p(z_ij=1 | x; λ^(t), μ^(t), Σ^(t)) = p(z_ij=1 | x_i, λ^(t), μ^(t), Σ^(t))

    = [ p(z_ij=1; λ^(t)) p(x_i | z_ij=1; λ^(t), μ^(t), Σ^(t)) ]
      ────────────────────────────────────────────────────────
      Σ_{j'=1}^K p(z_ij'=1; λ^(t)) p(x_i | z_ij'=1; λ^(t), μ^(t), Σ^(t))

    = [ λ_j^(t) N(x_i; μ_j^(t), Σ_j^(t)) ]
      ─────────────────────────────────────────────
      Σ_{j'=1}^K λ_j'^(t) N(x_i; μ_j'^(t), Σ_j'^(t))

    = p_ij^(t)

So we have:

E_{z~p(·|x,λ^(t),μ^(t),Σ^(t))}[ l(λ, μ, Σ; x, z) ] = Σ_i Σ_j p_ij^(t) ( log λ_j + log N(x_i; μ_j, Σ_j) )

Notice that we can maximize the log λ_j term and the log N term independently.

M-Step, Part 1: Maximize λ

argmax_{λ_1,...,λ_K}  Σ_i Σ_j p_ij^(t) ln λ_j

s.t.  0 ≤ λ_j ≤ 1

This constraint is not necessary. Since we are dealing with logs, λ_j > 0, and λ_1 + ... + λ_K = 1, so λ_j ≤ 1. The result will satisfy this automatically if it exists.

Lagrange form (using ℓ for the Lagrange multiplier, to keep it distinct from λ_j):

𝓛(λ_1, ..., λ_K, ℓ) = Σ_i Σ_j p_ij^(t) ln λ_j + ℓ(λ_1 + ... + λ_K - 1)

∂𝓛/∂λ_j = Σ_i p_ij^(t) / λ_j + ℓ = 0

=> λ_j = Σ_i p_ij^(t) / (-ℓ) = Σ_i p_ij^(t) / Σ_i Σ_j p_ij^(t)

(putting λ_1 + ... + λ_K = 1 gives Σ_i Σ_j p_ij^(t) / (-ℓ) = 1.)

M-Step, Part 2: Maximize μ and Σ

argmax_{μ_j, Σ_j}  Σ_i Σ_j p_ij^(t) ln N(x_i; μ_j, Σ_j)

⟺ argmax_{μ_j, Σ_j}  Σ_i Σ_j p_ij^(t) ( -d/2 ln(2π) - ½ ln(det Σ_j) - ½ (x_i-μ_j)ᵀ Σ_j⁻¹ (x_i-μ_j) )

Take the derivative w.r.t. μ_j (using ∂/∂x (xᵀAx) = (A + Aᵀ)x):

Σ_i p_ij^(t) 2 Σ_j⁻¹ (x_i - μ_j) = 0

=> Σ_i p_ij^(t) Σ_j⁻¹ x_i = Σ_i p_ij^(t) Σ_j⁻¹ μ_j

=> μ_j = Σ_i p_ij^(t) x_i / Σ_i p_ij^(t)

For the covariance, let Λ_j = Σ_j⁻¹ (the precision matrix), and take the derivative w.r.t. Λ_j instead — if you take it w.r.t. Σ_j you will get the same result, but it is much harder. Using ∂/∂A ln(det A) = (A⁻¹)ᵀ and ∂/∂A (xᵀAx) = xxᵀ:

Σ_i p_ij^(t) ( Σ_j - (x_i-μ_j)(x_i-μ_j)ᵀ ) = 0     (up to a factor of ½)

=> Σ_j = Σ_i p_ij^(t) (x_i-μ_j)(x_i-μ_j)ᵀ / Σ_i p_ij^(t)

Note: the variance collapses to 0 when p_ij^(t) = 1 for a single point i.
