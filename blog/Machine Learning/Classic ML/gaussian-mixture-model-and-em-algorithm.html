Gaussian Mixture Model and EM Algorithm

Machine Learning

A concise handwritten version of this note is available as a PDF.

If you have ever run K-means on real data, you have probably seen it fail in a very particular way: an elongated, elliptical cluster gets sliced in half, or a small tight cluster gets swallowed by a big diffuse one nearby. Why? Because K-means draws circles (or balls) around its centers, and it uses the same distance measure (normally L2) for every cluster. It has no notion of a cluster's shape or spread.

Gaussian Mixture Model (GMM) fixes exactly this. It is a clustering model that assumes the instances are generated from a mixture of Gaussian distributions — each cluster gets its own mean μ_j and its own covariance Σ_j, so elliptical clusters and clusters with different variances are handled naturally. The price we pay is that fitting it is genuinely harder, and that is where the EM algorithm comes in.

The Assumptions Behind GMM

Start from the likelihood of the observations x_1, ..., x_n. Three assumptions get us to the mixture form:

pr(x_1, ..., x_n) = pr(x_1) ⋯ pr(x_n)                       (independence)

                  = ∏_{i=1}^{n} Σ_j p(x_i ∈ cluster j) · p(x_i | x_i ∈ cluster j)
                                                              (law of total probability)

                  = ∏_{i=1}^{n} Σ_{j=1}^{K} π_j · N(x_i ; μ_j, Σ_j)
                                                              (Gaussian assumption)

There is a nice generative story behind this. To generate one observation: first a latent variable z picks a cluster, i.e. z = j with probability π_j; then, within that cluster, the observation is drawn from the corresponding Gaussian N(μ_j, Σ_j). So z is a discrete variable telling us which component produced the point — we just never get to observe it.

Why We Cannot Just Maximize the Likelihood

The obvious move is to minimize the negative log-likelihood over π, μ, Σ:

min  - Σ_{i=1}^{n} log( Σ_{j=1}^{K} π_j · N(x_i ; μ_j, Σ_j) )

s.t. Σ_j π_j = 1,   Σ_j symmetric and positive semi-definite

And here everything goes wrong at once:

  • Because of the sum inside the log, the log cannot cancel out the exp in the Gaussian density. There is no analytical form if we take gradients w.r.t. π, μ, Σ and set them to zero.
  • The parameters need to satisfy constraints (π sums to one, Σ_j must stay positive semi-definite), so directly running gradient descent is not ideal either.
  • The problem is also ill-defined: if we let μ_j → x_i and Σ_j → 0, then pr(x_1, ..., x_n) → ∞. A component can "cheat" by collapsing onto a single data point and claiming infinite likelihood. It is quite surprising to me when I first realized the global maximum of this likelihood is literally useless.

The EM Algorithm

So argmax_θ L(θ; x) is hard. The key observation: if we introduce some latent variables z, then argmax_θ L(θ; x, z) — the complete-data log-likelihood — is easy. If someone told us which cluster each point belongs to, fitting the Gaussians would be trivial.

EM exploits this by iterating:

θ^(t+1) = argmax_θ  E_{z ~ p(·|x, θ^(t))} [ L(θ; x, z) ]
          ────────  ─────────────────────────────────────
           M-step                  E-step

In words: guess the latent variables using the current parameters (E-step), then maximize the complete-data log-likelihood as if that guess were the truth (M-step), and repeat.

Why Does EM Actually Work?

This is my favorite part of the note. Notice that p(x, z; θ) = p(x; θ) · p(z|x; θ), which in log form gives

L(θ; x) = L(θ; x, z) - L(θ; z|x)
  target    the one we can maximize easily

Take expectation on both sides w.r.t. z ~ p(·|x, θ^(t)) — the left side does not depend on z, so it is unchanged. Do the same at θ = θ^(t) and subtract:

L(θ; x) - L(θ^(t); x) = E[L(θ; x, z)] - E[L(θ^(t); x, z)]
                        + KL( p(z|x, θ^(t)) ‖ p(z|x, θ) )
                          ────────────────────────────────
                                       ≥ 0

The KL divergence is always non-negative. And since θ^(t+1) is chosen to maximize E[L(θ; x, z)], the first difference is non-negative at θ = θ^(t+1) too. So:

L(θ^(t+1); x) ≥ L(θ^(t); x)

i.e. EM leads to a non-decreasing likelihood at each step. Two caveats worth being honest about: non-decreasing does not mean it converges to the global maximum (it can happily sit at a local optimum, so initialization matters), and the expected complete log-likelihood is exactly the ELBO-style lower bound that shows up later in variational inference — same trick, bigger stage.

EM for GMM

Now apply this machinery to the mixture model. Introduce latent variables z_ij = 1 if x_i ∈ C_j, and 0 otherwise. To run EM we need two things: the joint distribution p(x, z; θ) and the conditional distribution p(z|x; θ^(t)).

E-Step: Compute the Responsibilities

The joint distribution has a clean product form (each point picks exactly one component):

p(x, z; π, μ, Σ) = ∏_{i=1}^{n} ∏_{j=1}^{K} ( π_j · N(x_i ; μ_j, Σ_j) )^{z_ij}

=> L(π, μ, Σ; x, z) = Σ_i Σ_j z_ij · ( log π_j + log N(x_i ; μ_j, Σ_j) )

For the conditional distribution, Bayes' theorem gives us the responsibility — the posterior probability that point i came from component j:

p_ij^(t) = p(z_ij = 1 | x_i ; θ^(t))

         =        π_j^(t) · N(x_i ; μ_j^(t), Σ_j^(t))
           ─────────────────────────────────────────────
            Σ_{j'=1}^{K} π_j'^(t) · N(x_i ; μ_j'^(t), Σ_j'^(t))

This is just "prior times likelihood, normalized". Plugging it in, the expected complete-data log-likelihood becomes

E_{z ~ p(·|x, θ^(t))}[ L(π, μ, Σ; x, z) ]
    = Σ_i Σ_j p_ij^(t) · ( log π_j + log N(x_i ; μ_j, Σ_j) )

Notice that the log π_j term and the log N term can be maximized independently — that is exactly why introducing z made the problem easy. Compare this with the original objective: the log now sits directly on the Gaussian density, so exp gets cancelled and everything becomes tractable.

M-Step, Part 1: Maximize π

Maximize Σ_i Σ_j p_ij^(t) ln π_j subject to π_1 + ... + π_K = 1. (The constraint 0 ≤ π_j ≤ 1 is not necessary to enforce — since we are dealing with logs, π_j > 0 automatically, and the sum-to-one constraint takes care of the rest.) Use a Lagrange multiplier:

𝓛(π_1, ..., π_K, λ) = Σ_i Σ_j p_ij^(t) ln π_j + λ(π_1 + ... + π_K - 1)

∂𝓛/∂π_j = ( Σ_i p_ij^(t) ) / π_j + λ = 0

=> π_j = Σ_i p_ij^(t) / Σ_i Σ_j' p_ij'^(t)   =   Σ_i p_ij^(t) / n

So the new mixture weight is simply the average responsibility that component claims. Intuitive.

M-Step, Part 2: Maximize μ and Σ

Now maximize Σ_i Σ_j p_ij^(t) ln N(x_i ; μ_j, Σ_j). Expanding the log-density, this is equivalent to maximizing

Σ_i Σ_j p_ij^(t) · ( -d/2 · ln(2π) - ½ ln(det Σ_j) - ½ (x_i - μ_j)ᵀ Σ_j⁻¹ (x_i - μ_j) )

Taking the derivative w.r.t. μ_j (using the identity ∂/∂x (xᵀAx) = (A + Aᵀ)x) and setting it to zero:

Σ_i p_ij^(t) · 2 Σ_j⁻¹ (x_i - μ_j) = 0

=> μ_j = Σ_i p_ij^(t) x_i / Σ_i p_ij^(t)

A responsibility-weighted average of the data — the soft version of the K-means centroid update.

For the covariance, a neat trick from the note: differentiate w.r.t. the precision matrix Λ_j = Σ_j⁻¹ rather than Σ_j itself (if you go w.r.t. Σ_j you get the same result, but it is much harder). Using ∂/∂A ln(det A) = (A⁻¹)ᵀ and ∂/∂A (xᵀAx) = xxᵀ:

Σ_i p_ij^(t) · ( Σ_j - (x_i - μ_j)(x_i - μ_j)ᵀ ) = 0     (up to a factor of ½)

=> Σ_j = Σ_i p_ij^(t) (x_i - μ_j)(x_i - μ_j)ᵀ / Σ_i p_ij^(t)

A responsibility-weighted covariance. One caveat flagged in the note: the variance collapses to 0 when p_ij^(t) = 1 for a single point i — this is the ill-defined singularity from earlier sneaking back in. EM does not magically remove it; in practice you handle it with covariance regularization (e.g. adding a small ridge to Σ_j) or by restarting components that collapse.

GMM vs K-means, Revisited

After the derivation, the relationship becomes clear. K-means is essentially a hard, degenerate special case of GMM:

Aspect K-means GMM
Assignment Hard (each point belongs to one cluster) Soft (responsibilities p_ij)
Cluster shape Circles/balls, same scale everywhere Ellipses via per-cluster Σ_j
Cluster size/variance Implicitly equal Each cluster has its own π_j and Σ_j
Output Cluster labels A full generative probability model

Summary

  • GMM assumes data comes from a mixture of Gaussians — each cluster gets its own mean, covariance, and weight, which is exactly what K-means lacks.
  • Direct maximum likelihood fails three ways: no closed form (sum inside the log), awkward constraints, and an ill-defined objective that blows up when a component collapses onto a point.
  • EM alternates between guessing the latent variables (E-step) and maximizing the complete-data log-likelihood (M-step), and a short KL argument shows the likelihood never decreases.
  • For GMM the updates are pleasantly interpretable: responsibilities from Bayes' theorem, then responsibility-weighted averages for π_j, μ_j, and Σ_j.
  • EM guarantees monotone improvement, not the global optimum — and the collapse singularity still lurks, so regularize your covariances.

My Take

What I like most about this derivation is how honest it is about failure modes. Most textbook treatments jump straight to "here are the EM updates", but the interesting part for me is why the naive approach breaks: the sum trapped inside the log, and that sneaky singularity where a Gaussian collapses onto one point and the likelihood shoots to infinity. Once you have seen that, EM stops feeling like a magic recipe and starts feeling like the obvious workaround — move the log inside by conditioning on the latent labels, and pay for it with an expectation.

The other thing that stuck with me: the "why does EM work" proof is only about half a page, and the same decomposition (expected complete log-likelihood plus a KL term) is the seed of the ELBO in variational inference and VAEs. Learning this one derivation properly buys you a surprising amount elsewhere. Also, differentiating w.r.t. the precision matrix instead of the covariance is one of those small tricks that saves you twenty minutes of matrix calculus pain — worth remembering.
