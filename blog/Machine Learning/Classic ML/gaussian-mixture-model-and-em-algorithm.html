Gaussian Mixture Model and EM Algorithm

Machine Learning

A concise handwritten version of this note is available as a PDF.

Gaussian mixture model (GMM) is a type of clustering model that assumes the instances are generated from a mixture of Gaussian distributions.

Compare with K-means

Naive K-means method cannot cluster elliptical clusters well, because it creates circles or balls around its centers. It also cannot deal with clusters with different variance well, because it uses the same distance measure (normally L2) for different clusters. GMM handles both well, since each cluster gets its own mean $\mu_j$ and its own covariance $\Sigma_j$.

Assumptions of Gaussian Mixture Model

Start from the likelihood of the observations:

$$\begin{aligned} \mathrm{pr}(x_1, \ldots, x_n) &= \mathrm{pr}(x_1) \cdots \mathrm{pr}(x_n) && (\text{independence assumption}) \\[6pt] &= \prod_{i=1}^{n} \sum_{j=1}^{K} p(x_i \in \text{cluster } j)\, p(x_i \mid x_i \in \text{cluster } j) && (\text{law of total probability}) \\[6pt] &= \prod_{i=1}^{n} \sum_{j=1}^{K} \lambda_j \mathcal{N}(x_i ; \mu_j, \Sigma_j) && (\text{Gaussian assumption}) \end{aligned}$$

Generation process: the latent variable $z$ is a discrete variable equal to $z_i$ (where $z_i = 1, ..., K$) with probability $\lambda_i$. Given this latent variable, the likelihood of the data $x$ is normally distributed with mean $= \mu_i$, variance $= \Sigma_j^2$. In other words: $z$ goes to each cluster with probability $\lambda_i$, and within each cluster the data is generated from the corresponding Gaussian distribution $\mathcal{N}(\mu_i, \Sigma_i^2)$, giving the observation $x$.

The difficulty to maximize the Likelihood Function Directly

The likelihood function for GMM equals to: $$\mathrm{pr}(x_1, \ldots, x_n) = \prod_{i=1}^{n} \sum_{j=1}^{K} \lambda_j \mathcal{N}(x_i ; \mu_j, \Sigma_j)$$

If we minimize the negative log-likelihood, we need to solve

$$\begin{aligned} \min_{\lambda,\mu,\Sigma} \left( -l(\lambda, \mu, \Sigma; x_1, \ldots, x_n) \right) &= \min_{\lambda,\mu,\Sigma} -\sum_i \log\left( \sum_j \lambda_j \mathcal{N}(x_i ; \mu_j, \Sigma_j) \right) \\[6pt] &= \min_{\lambda,\mu,\Sigma} -\sum_i \log\left( \sum_j \lambda_j \frac{1}{(2\pi)^{d/2} |\Sigma_j|^{1/2}} \exp\left\{ -\frac{1}{2} (x_i-\mu_j)^T \Sigma_j^{-1} (x_i-\mu_j) \right\} \right) \\[6pt] &\text{s.t.} \quad \sum_j \lambda_j = 1, \quad \Sigma_j \text{ symmetric and positive semi-definite} \end{aligned}$$

Because of the sum within the log, we cannot use log to cancel out exp. There is no analytical form for the gradient w.r.t. $\lambda, \mu, \Sigma$ as well. We also need to satisfy the constraints, so directly using gradient descent is not ideal.

Notice that the problem is also ill-defined. If $\mu_j \to x_i$, $\Sigma_j \to 0$, then $\mathrm{pr}(x_1, \ldots, x_n) \to \text{infty}$.

Below we consider how to use the E-M algorithm to solve these issues.

EM Algorithm

Problem: solving $\arg\max_\theta l(\theta; x)$ directly is hard.

Observation: if we introduce some latent variables $z$, then $\arg\max_\theta l(\theta; x, z)$ — this is easy.

EM algorithm:

$$\theta^{(t+1)} = \underbrace{\arg\max_\theta}_{\text{M-step}} \; \underbrace{\mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})} \left[ l(\theta; x, z) \right]}_{\text{E-step}}$$

Why Does EM Algorithm Work?

Notice that $p(x, z, \theta) = p(x; \theta) p(z|x; \theta)$:

$$\Rightarrow\; l(\theta; x, z) = l(\theta; x) + l(\theta; z|x)$$ $$\Rightarrow\; \underbrace{l(\theta; x)}_{\text{target}} = \underbrace{l(\theta; x, z)}_{\text{the one we can maximize easily}} - l(\theta; z|x)$$

Take expectation on both sides w.r.t. $z \sim p(\cdot|x, \theta^{(t)})$:

$$l(\theta; x) = \mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})}\left[ l(\theta; x, z) \right] - \mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})}\left[ l(\theta; z|x) \right]$$ $$\Rightarrow\; l(\theta^{(t)}; x) = \mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})}\left[ l(\theta^{(t)}; x, z) \right] - \mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})}\left[ l(\theta^{(t)}; z|x) \right]$$ $$\begin{aligned} \Rightarrow\; l(\theta; x) - l(\theta^{(t)}; x) &= \mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})}\left[ l(\theta; x, z) \right] - \mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})}\left[ l(\theta^{(t)}; x, z) \right] \\[6pt] &\quad - \mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})}\left[ l(\theta; z|x) \right] + \mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})}\left[ l(\theta^{(t)}; z|x) \right] \\[6pt] &= \mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})}\left[ l(\theta; x, z) \right] - \mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})}\left[ l(\theta^{(t)}; x, z) \right] \\[6pt] &\quad + \underbrace{\mathrm{KL}\left( p(z|x, \theta^{(t)}), p(z|x, \theta) \right)}_{\geq\, 0} \end{aligned}$$

Since $\theta^{(t+1)} = \arg\max_\theta \mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})}\left[ l(\theta; x, z) \right]$, we have

$$\mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})}\left[ l(\theta^{(t+1)}; x, z) \right] \;\geq\; \mathbb{E}_{z\sim p(\cdot|x,\theta^{(t)})}\left[ l(\theta^{(t)}; x, z) \right]$$

So $l(\theta^{(t+1)}; x) \geq l(\theta^{(t)}; x)$, i.e. the EM algorithm leads to a non-decreasing likelihood function at each step.

EM Algorithm for Gaussian Mixture Model

Introduce latent variables:

$$z_{ij} = \begin{cases} 1 & \text{if } x_i \in C_j \\ 0 & \text{otherwise} \end{cases}$$

In order to use the EM algorithm, we need the joint distribution $p(x, z; \theta^{(t)})$ and the conditional distribution $p(z|x; \theta^{(t)})$.

E-Step

Joint distribution:

$$p(x, z; \lambda, \mu, \Sigma) = \prod_{i=1}^{n} \prod_{j=1}^{K} \left( \lambda_j \mathcal{N}(x_i; \mu_j, \Sigma_j) \right)^{z_{ij}}$$ $$\Rightarrow\; l(\lambda, \mu, \Sigma; x, z) = \sum_i \sum_j z_{ij} \left( \log \lambda_j + \log \mathcal{N}(x_i; \mu_j, \Sigma_j) \right)$$

Conditional distribution, by Bayes' theorem:

$$\begin{aligned} p(z_{ij}=1 \mid x; \lambda^{(t)}, \mu^{(t)}, \Sigma^{(t)}) &= p(z_{ij}=1 \mid x_i, \lambda^{(t)}, \mu^{(t)}, \Sigma^{(t)}) \\[6pt] &= \frac{p(z_{ij}=1; \lambda^{(t)})\, p(x_i \mid z_{ij}=1; \lambda^{(t)}, \mu^{(t)}, \Sigma^{(t)})}{\sum_{j'=1}^{K} p(z_{ij'}=1; \lambda^{(t)})\, p(x_i \mid z_{ij'}=1; \lambda^{(t)}, \mu^{(t)}, \Sigma^{(t)})} \\[6pt] &= \frac{\lambda_j^{(t)} \mathcal{N}(x_i; \mu_j^{(t)}, \Sigma_j^{(t)})}{\sum_{j'=1}^{K} \lambda_{j'}^{(t)} \mathcal{N}(x_i; \mu_{j'}^{(t)}, \Sigma_{j'}^{(t)})} \\[6pt] &= p_{ij}^{(t)} \end{aligned}$$

So we have:

$$\mathbb{E}_{z\sim p(\cdot|x,\lambda^{(t)},\mu^{(t)},\Sigma^{(t)})}\left[ l(\lambda, \mu, \Sigma; x, z) \right] = \sum_i \sum_j p_{ij}^{(t)} \left( \log \lambda_j + \log \mathcal{N}(x_i; \mu_j, \Sigma_j) \right)$$

Notice that we can maximize the $\log \lambda_j$ term and the $\log \mathcal{N}$ term independently.

M-Step, Part 1: Maximize $\lambda$

$$\underset{\lambda_1,\ldots,\lambda_K}{\arg\max} \sum_i \sum_j p_{ij}^{(t)} \ln \lambda_j \qquad \text{s.t.} \quad 0 \le \lambda_j \le 1$$

This constraint is not necessary. Since we are dealing with logs, $\lambda_j > 0$, and $\lambda_1 + ... + \lambda_K = 1$, so $\lambda_j \le 1$. The result will satisfy this automatically if it exists.

Lagrange form (using $\ell$ for the Lagrange multiplier, to keep it distinct from $\lambda_j$):

$$\mathcal{L}(\lambda_1, \ldots, \lambda_K, \ell) = \sum_i \sum_j p_{ij}^{(t)} \ln \lambda_j + \ell(\lambda_1 + \cdots + \lambda_K - 1)$$ $$\frac{\partial \mathcal{L}}{\partial \lambda_j} = \frac{\sum_i p_{ij}^{(t)}}{\lambda_j} + \ell = 0$$ $$\Rightarrow\; \lambda_j = \frac{\sum_i p_{ij}^{(t)}}{-\ell} = \frac{\sum_i p_{ij}^{(t)}}{\sum_i \sum_j p_{ij}^{(t)}}$$

(putting $\lambda_1 + ... + \lambda_K = 1$ gives $\sum_i \sum_j p_{ij}^{(t)} / (-\ell) = 1$.)

M-Step, Part 2: Maximize $\mu$ and $\Sigma$

$$\underset{\mu_j, \Sigma_j}{\arg\max} \sum_i \sum_j p_{ij}^{(t)} \ln \mathcal{N}(x_i; \mu_j, \Sigma_j)$$ $$\Longleftrightarrow\; \underset{\mu_j, \Sigma_j}{\arg\max} \sum_i \sum_j p_{ij}^{(t)} \left( -\frac{d}{2} \ln(2\pi) - \frac{1}{2} \ln(\det \Sigma_j) - \frac{1}{2} (x_i-\mu_j)^T \Sigma_j^{-1} (x_i-\mu_j) \right)$$

Take the derivative w.r.t. $\mu_j$ (using $\frac{\partial}{\partial x} (x^T A x) = (A + A^T)x$):

$$\sum_i p_{ij}^{(t)}\, 2 \Sigma_j^{-1} (x_i - \mu_j) = 0$$ $$\Rightarrow\; \sum_i p_{ij}^{(t)} \Sigma_j^{-1} x_i = \sum_i p_{ij}^{(t)} \Sigma_j^{-1} \mu_j$$ $$\Rightarrow\; \mu_j = \frac{\sum_i p_{ij}^{(t)} x_i}{\sum_i p_{ij}^{(t)}}$$

For the covariance, let $\Lambda_j = \Sigma_j^{-1}$ (the precision matrix), and take the derivative w.r.t. $\Lambda_j$ instead — if you take it w.r.t. $\Sigma_j$ you will get the same result, but it is much harder. Using $\frac{\partial}{\partial A} \ln(\det A) = (A^{-1})^T$ and $\frac{\partial}{\partial A} (x^T A x) = x x^T$:

$$\sum_i p_{ij}^{(t)} \left( \Sigma_j - (x_i-\mu_j)(x_i-\mu_j)^T \right) = 0 \qquad (\text{up to a factor of } \tfrac{1}{2})$$ $$\Rightarrow\; \Sigma_j = \frac{\sum_i p_{ij}^{(t)} (x_i-\mu_j)(x_i-\mu_j)^T}{\sum_i p_{ij}^{(t)}}$$

Note: the variance collapses to 0 when $p_{ij}^{(t)} = 1$ for a single point $i$.
