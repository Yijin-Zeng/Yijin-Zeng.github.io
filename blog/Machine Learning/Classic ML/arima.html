White Noise Process

$\{X_t\}$ is a white noise process if it is a sequence of uncorrelated random variables such that $E(X_t) = \mu$, $V(X_t) = \sigma^2$, for all $t$. The autocovariance is

$$S_\tau = \mathrm{Cov}(X_t, X_{t+\tau}) = \begin{cases} \sigma^2 & \text{if } \tau = 0 \\ 0 & \text{otherwise} \end{cases}$$

Note: white noise does not imply iid. Consider $\{X_i\}$ an independent sequence with

$$X_i = \begin{cases} \mathcal{N}(0,1) & \text{if } i \text{ is even} \\ \mathrm{Uniform}(-\sqrt{3}, \sqrt{3}) & \text{if } i \text{ is odd} \end{cases}$$

When $i$ is odd, we check $E(X) = 0$ and compute $V(X)$ directly from the uniform density on $(-\sqrt{3}, \sqrt{3})$:

$$\begin{aligned} E(X^2) &= \int_a^b \frac{1}{b-a} x^2 \, dx \\ &= \frac{1}{b-a} \left[\frac{x^3}{3}\right]_a^b \\ &= \frac{1}{b-a} \cdot \frac{b^3-a^3}{3} \\ &= \frac{1}{2\sqrt{3}} \cdot \frac{2\sqrt{3} + 2\sqrt{3}}{3} \qquad (\text{with } a=-\sqrt{3},\ b=\sqrt{3}) \\ &= 1 \end{aligned}$$

So $V(X) = 1$ in this case as well. So the process is white noise, however not iid.

Moving Average Process MA(q)

A moving average process is defined as

$$X_t = \mu - \sum_{i=0}^{\ell} \theta_i e_{t-i}$$

where $\{e_t\}$ is a white noise process with mean $\mu = 0$.

$X_t$ is a stationary process. Computing $\mathrm{Cov}(X_t, X_{t+\tau})$:

$$\begin{aligned} \mathrm{Cov}(X_t, X_{t+\tau}) &= E(X_t X_{t+\tau}) - E(X_t)E(X_{t+\tau}) \\[6pt] &= E\left[ \left(\mu - \sum_{i=0}^{\ell} \theta_i e_{t-i}\right)\left(\mu - \sum_{i=0}^{\ell} \theta_i e_{t+\tau-i}\right) \right] - \mu^2 \\[6pt] &= E\left[ \left(\sum_{i=0}^{\ell} \theta_i e_{t-i}\right)\left(\sum_{i=0}^{\ell} \theta_i e_{t+\tau-i}\right) \right] \\[6pt] &= \begin{cases} \sigma^2 \displaystyle\sum_{i=0}^{\ell} \theta_i \theta_{i+\tau} & \text{if } \tau \le q \\ 0 & \text{if } \tau > q \end{cases} \end{aligned}$$

This depends on $\tau$ only, which is why the process is stationary.

Estimating the Parameters

Assuming $\theta_{-i} = 0$, we estimate $\hat{e}_t$ with the recursive scheme

$$\begin{aligned} \theta_0 \hat{e}_1 &= (X_1 - \mu) \\ \theta_0 \hat{e}_2 &= (X_2 - \mu) - \theta_1 \hat{e}_1 \\ &\;\;\vdots \\ \theta_0 \hat{e}_t &= (X_t - \mu) - \sum_{j=1}^{t-1} \theta_j \hat{e}_{t-j} \end{aligned}$$

and then solve

$$\underset{\mu,\, \theta}{\arg\min} \sum_{t=1}^{n} \hat{e}_t^2$$

Making Predictions

To predict $X_{t+\ell}$ given $X_1, ..., X_t$:

$$\begin{aligned} E(X_{t+\ell} \mid X_1,\ldots,X_t) &= E\left(\mu - \sum_{i=0}^{\ell} \theta_i e_{t+\ell-i} \,\middle|\, X_1,\ldots,X_t\right) \\[6pt] &= \mu - \sum_{i=1}^{\ell} \theta_i E(e_{t+\ell-i} \mid X_1,\ldots,X_t) - \theta_0 E(e_{t+\ell}) \end{aligned}$$

So we need to estimate $e_{t+\ell-i}$ given all the observations.

Forward Recursion

Given the observed data sequence $X_{1:t}$, we predict

$$\hat{e}_t = \frac{X_t - \hat{X}_t}{\hat{\theta}_0}$$

where $X_t$ is the real value and $\hat{X}_t$ is the predicted value. Substituting the model for $X_t$ and the predicted $\hat{X}_t$, and letting $\hat{\theta}_i \to \theta_i$, $\hat{\mu} \to \mu$, the estimation error $e_t$ (the difference between $\hat{e}_t$ and the true $e_t$) satisfies

$$\theta_0 e_t = \sum_{i=1}^{p} \theta_i e_{t-i}$$

For $p = 1$, this reduces to

$$\begin{aligned} \theta_0 e_t &= \theta_1 e_{t-1} \\ \Rightarrow\; e_t &= \frac{\theta_1}{\theta_0} e_{t-1} \\ \Rightarrow\; e_t &= \left(\frac{\theta_1}{\theta_0}\right)^t e_0 \end{aligned}$$

When $\theta_1/\theta_0 < 1$, this converges to 0, so the estimation gets better and better as $t$ increases. When $\theta_1/\theta_0 > 1$, the estimate error accumulates to infinity.

Autoregressive Process AR(p)

An autoregressive process is defined as

$$X_t = \phi_1 X_{t-1} + \cdots + \phi_p X_{t-p} + e_t$$

Note: not all AR processes are stationary.

Consider $\mathrm{AR}(1)$, where $X_t = \phi X_{t-1} + e_t$. Unrolling the recursion (assuming $X_0 = 0$):

$$\begin{aligned} X_t &= \phi(\phi X_{t-2} + e_{t-1}) + e_t \\ &= \phi^2 X_{t-2} + \phi e_{t-1} + e_t \\ &= e_t + \phi e_{t-1} + \phi^2 e_{t-2} + \cdots \\ &= \sum_{k=0}^{t-1} \phi^k e_{t-k} + \phi^t X_0 \\ &= \sum_{k=0}^{t-1} \phi^k e_{t-k} \end{aligned}$$

So

$$E(X_t) = 0$$ $$\begin{aligned} V(X_t) = E(X_t^2) &= E\left[ \left(\sum_{k=0}^{t-1} \phi^k e_{t-k}\right)^2 \right] \\ &= \sum_{k=0}^{t-1} \phi^{2k} \sigma^2 \\ &= \sigma^2 \, \frac{1-\phi^{2t}}{1-\phi^2} \end{aligned}$$

So for $V(X_t) < \infty$, we must have $|\phi| < 1$, giving

$$V(X_t) \approx \frac{\sigma^2}{1-\phi^2} \qquad (\text{when } t \text{ is large enough})$$

There are three cases:

  • If $|\phi| < 1$ (stationary), the influence of past $e$ decays exponentially.
  • If $|\phi| = 1$ (non-stationary), this is a random walk, and the effect of $e$ stays.
  • If $|\phi| > 1$ (non-stationary), the effect of past $e$ increases exponentially.

ARMA and ARIMA

An ARMA(q,p) process combines the AR(p) and MA(q) parts:

$$X_t = \underbrace{\sum_{k=1}^{p} \phi_k X_{t-k}}_{\mathrm{AR}(p)} + e_t - \underbrace{\sum_{k=1}^{q} \theta_k e_{t-k}}_{\mathrm{MA}(q)}$$

Define the difference operator $\Delta = (1-B)$, where $B X_t = X_{t-1}$ is the backward shift operator.

We can rewrite ARMA(q,p) as

$$X_t - \sum_{k=1}^{p} \phi_k B^k X_t = e_t - \sum_{k=1}^{q} \theta_k B^k e_t$$ $$\underbrace{\left(1 - \sum_{k=1}^{p} \phi_k B^k\right)}_{\Phi(B)} X_t = \underbrace{\left(1 - \sum_{k=1}^{q} \theta_k B^k\right)}_{\Theta(B)} e_t$$ $$\mathrm{ARMA}: \quad \Phi(B) X_t = \Theta(B) e_t$$

and ARIMA(q,d,p) as

$$\Phi(B) (1-B)^d X_t = \Theta(B) e_t$$

or equivalently

$$\Phi(B) \Delta^d X_t = \Theta(B) e_t$$
