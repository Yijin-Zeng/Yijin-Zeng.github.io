White Noise Process

{X_t} is a white noise process if it is a sequence of uncorrelated random variables such that E(X_t) = μ, V(X_t) = σ², for all t. The autocovariance is

S_τ = Cov(X_t, X_{t+τ}) = σ²   if τ = 0
                          = 0    otherwise

Note: white noise does not imply iid. Consider {X_i} an independent sequence with

X_i = N(0,1)                if i is even
X_i = Uniform(-√3, √3)       if i is odd

When i is odd, we check E(X) = 0 and compute V(X) directly from the uniform density on (-√3, √3):

E(X²) = ∫_a^b (1/(b-a)) x² dx
      = (1/(b-a)) [x³/3]_a^b
      = (1/(b-a)) (b³-a³)/3
      = (1/(2√3)) (2√3 + 2√3)/3     (with a=-√3, b=√3)
      = 1

So V(X) = 1 in this case as well. So the process is white noise, however not iid.

Moving Average Process MA(q)

A moving average process is defined as

X_t = μ - Σ_{i=0}^ℓ θ_i e_{t-i}

where {e_t} is a white noise process with mean μ = 0.

X_t is a stationary process. Computing Cov(X_t, X_{t+τ}):

Cov(X_t, X_{t+τ}) = E(X_t X_{t+τ}) - E(X_t)E(X_{t+τ})

= E[ (μ - Σ_{i=0}^ℓ θ_i e_{t-i})(μ - Σ_{i=0}^ℓ θ_i e_{t+τ-i}) ] - μ²

= E[ (Σ_{i=0}^ℓ θ_i e_{t-i})(Σ_{i=0}^ℓ θ_i e_{t+τ-i}) ]

= σ² Σ_{i=0}^ℓ θ_i θ_{i+τ}     if τ ≤ q
= 0                            if τ > q

This depends on τ only, which is why the process is stationary.

Estimating the Parameters

Assuming θ_{-i} = 0, we estimate ê_t with the recursive scheme

θ_0 ê_1 = (X_1 - μ)
θ_0 ê_2 = (X_2 - μ) - θ_1 ê_1
   ⋮
θ_0 ê_t = (X_t - μ) - Σ_{j=1}^{t-1} θ_j ê_{t-j}

and then solve

argmin_{μ, θ} Σ_{t=1}^n ê_t²

Making Predictions

To predict X_{t+ℓ} given X_1, ..., X_t:

E(X_{t+ℓ} | X_1,...,X_t) = E(μ - Σ_{i=0}^ℓ θ_i e_{t+ℓ-i} | X_1,...,X_t)

= μ - Σ_{i=1}^ℓ θ_i E(e_{t+ℓ-i} | X_1,...,X_t) - θ_0 E(e_{t+ℓ})

So we need to estimate e_{t+ℓ-i} given all the observations.

Forward Recursion

Given the observed data sequence X_{1:t}, we predict

ê_t = (X_t - X̂_t) / θ̂_0

where X_t is the real value and X̂_t is the predicted value. Substituting the model for X_t and the predicted X̂_t, and letting θ̂_i → θ_i, μ̂ → μ, the estimation error e_t (the difference between ê_t and the true e_t) satisfies

θ_0 e_t = Σ_{i=1}^p θ_i e_{t-i}

For p = 1, this reduces to

θ_0 e_t = θ_1 e_{t-1}
=> e_t = (θ_1/θ_0) e_{t-1}
=> e_t = (θ_1/θ_0)^t e_0

When θ_1/θ_0 < 1, this converges to 0, so the estimation gets better and better as t increases. When θ_1/θ_0 > 1, the estimate error accumulates to infinity.

Autoregressive Process AR(p)

An autoregressive process is defined as

X_t = φ_1 X_{t-1} + ... + φ_p X_{t-p} + e_t

Note: not all AR processes are stationary.

Consider AR(1), where X_t = φ X_{t-1} + e_t. Unrolling the recursion (assuming X_0 = 0):

X_t = φ(φ X_{t-2} + e_{t-1}) + e_t
    = φ² X_{t-2} + φ e_{t-1} + e_t
    = e_t + φ e_{t-1} + φ² e_{t-2} + ...
    = Σ_{k=0}^{t-1} φ^k e_{t-k} + φ^t X_0
    = Σ_{k=0}^{t-1} φ^k e_{t-k}

So

E(X_t) = 0

V(X_t) = E(X_t²) = E[ (Σ_{k=0}^{t-1} φ^k e_{t-k})² ]
       = Σ_{k=0}^{t-1} φ^{2k} σ²
       = σ² (1-φ^{2t}) / (1-φ²)

So for V(X_t) < ∞, we must have |φ| < 1, giving

V(X_t) ≈ σ² / (1-φ²)   when t is large enough

There are three cases:

  • If |φ| < 1 (stationary), the influence of past e decays exponentially.
  • If |φ| = 1 (non-stationary), this is a random walk, and the effect of e stays.
  • If |φ| > 1 (non-stationary), the effect of past e increases exponentially.

ARMA and ARIMA

An ARMA(q,p) process combines the AR(p) and MA(q) parts:

X_t = Σ_{k=1}^p φ_k X_{t-k} + e_t - Σ_{k=1}^q θ_k e_{t-k}
      └──────────────────┘         └──────────────────┘
             AR(p)                        MA(q)

Define the difference operator Δ = (1-B), where B X_t = X_{t-1} is the backward shift operator.

We can rewrite ARMA(q,p) as

X_t - Σ_{k=1}^p φ_k B^k X_t = e_t - Σ_{k=1}^q θ_k B^k e_t

(1 - Σ_{k=1}^p φ_k B^k) X_t = (1 - Σ_{k=1}^q θ_k B^k) e_t
        Φ(B)                          Θ(B)

ARMA:  Φ(B) X_t = Θ(B) e_t

and ARIMA(q,d,p) as

Φ(B) (1-B)^d X_t = Θ(B) e_t

or equivalently

Φ(B) Δ^d X_t = Θ(B) e_t
