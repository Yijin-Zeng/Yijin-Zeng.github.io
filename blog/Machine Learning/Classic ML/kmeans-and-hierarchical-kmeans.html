K-means and Hierarchical K-means

Machine Learning

A concise handwritten version of this note is available as a PDF.

K-means is a simple and efficient clustering method.

Formulation

Suppose we have data points x_1, ..., x_n, where each x_i is in R^d. For each data point, we introduce p_i in {1, ..., k} to indicate which cluster point i should be assigned to. The target is:

argmin_{p_1, ..., p_n}  sum_{j=1}^k sum_{i=1}^n I(p_i = j) * ||x_i - mu_j||^2

where mu_j = sum_i I(p_i = j) * x_i / sum_i I(p_i = j).

In another words, mu_j is the centroid (the mean) of cluster j, and we want the assignments that make every point as close as possible to the centroid of its own cluster.

Algorithm

  1. Initialize: randomly initialize the centroids mu_1, ..., mu_k.
  2. E-step: compute the distance from each point to each centroid, and assign the point to the closest one: p_i = argmin_j ||x_i - mu_j||^2.
  3. M-step: recompute each centroid as the mean of the points assigned to it: mu_j = sum_i I(p_i = j) * x_i / sum_i I(p_i = j).

Repeat the E-step and M-step until the assignments stop changing.

Two notes about the algorithm:

  • The algorithm is guaranteed to converge, since both the E-step and the M-step are guaranteed to lead to a lower loss (it is a greedy algorithm).
  • The final result relies on the initialization. Therefore, the algorithm might not converge to the true result, only to a local one.

Initialization: K-means++

The results of K-means could be affected by the initialization of the centroids. In practice, we could initialize the centroids multiple times (e.g. 1000 times), run the algorithm for each, and pick the one with the smallest loss. However, this is not very computationally efficient. A better approach is to carefully initialize the centroids, which is what K-means++ does:

  1. Choose the first centroid mu_1 randomly from x_1, ..., x_n.
  2. Choose the next centroid from x_1, ..., x_n with probability D(x_i)^2 / sum_i D(x_i)^2, where D(x_i) is the distance between x_i and the closest centroid that has been chosen.
  3. Repeat step 2 until all k centroids are chosen.

The idea is that points far from the existing centroids are more likely to be picked, so the initial centroids tend to be spread out.

Evaluating K-means and Choosing k

For evaluating the results of K-means, we obviously could use the loss function directly (called inertia). However, it is not good for choosing k. In fact, if we increase k, the inertia always goes down, since the solution for k is only a special case of the solution for k+1.

A common trick is the elbow method. Plot the inertia against k: it drops quickly at first and then drops slowly. The point where the drop slows down (the elbow) can be picked as the best k. However, the elbow is not always so obvious.

A better metric is the silhouette coefficient. For a single data point, the silhouette score is computed as:

s = (b - a) / max(a, b)

Where:

  • a is the average distance to the points in its own cluster
  • b is the average distance to the points in the nearest other cluster

The larger the better. Then we only need to choose the k with the largest average silhouette score.

Pros and Cons of K-means

Pros:

  • Simple and efficient
  • Guaranteed convergence

Cons:

  • Requires manually choosing k
  • Sensitive to initialization
  • (Implicitly) Assumes spherical clusters with the same variance
  • Sensitive to outliers

The third one deserves a bit more explanation, because it is really two problems:

  • K-means cannot handle elliptical clusters well, because it creates circles (balls) around its centers.
  • K-means cannot handle clusters with different variances well, because it uses the same distance measure (normally L2) for every cluster. A big, spread-out cluster next to a small, tight one can get cut in the wrong place, since the boundary is just halfway between the two centers.

Hierarchical K-means

Hierarchical K-means fixes some of the above problems by splitting the data step by step, using K-means with only k = 2 each time:

  1. Start with all the data points as one cluster, and perform K-means with k = 2. This gives two sub-datasets.
  2. Choose one leaf to split, e.g. the one with the largest variance, and perform K-means with k = 2 on it.
  3. Repeat until we reach a given k, or a maximum tree depth, a minimum cluster size, a variance threshold, etc.

Compared with standard K-means, hierarchical K-means has the following advantages:

  1. Less sensitive to the initialization of centroids. At every step it only needs to solve k = 2, which is simpler.
  2. It works better with unequal variance clusters. Take three clusters where one has a much bigger variance than the other two. Standard K-means with k = 3 can end up splitting the big cluster, because that lowers the loss. Hierarchical K-means makes the first split between the big cluster and the rest, and by the second split the impact of the bigger variance cluster has been removed, so the two small clusters are separated properly.
