Adam and AdamW

Machine Learning

A concise handwritten version of this note is available as a PDF.

Adam is one of the reasons deep neural networks can be trained (relatively) easily. However, it has a critical issue when combined with L2 loss, one of the most common regularization methods.

(For the build-up of how Adam itself works -- momentum, adaptive learning rates and so on -- see From SGD to Adam. This note takes Adam as given and focuses on what happens when you add L2 regularization on top of it.)

Observation 1: L2 loss in SGD is equivalent to weight decay

Suppose we add an L2 penalty to the loss:

$$L^*(\theta) = L(\theta) + \frac{\lambda}{2}\|\theta\|^2$$

where $L(\theta)$ is the original loss and the second term is the L2 regularization. Taking the gradient:

$$\nabla L^*(\theta) = \nabla L(\theta) + \lambda\theta$$

Plugging this into the SGD update:

$$\begin{aligned} \theta^{(t+1)} &\leftarrow \theta^{(t)} - \eta\nabla L^*(\theta^{(t)}) \\ &= \theta^{(t)} - \eta\nabla L(\theta^{(t)}) - \eta\lambda\theta^{(t)} \\ &= (1 - \eta\lambda)\theta^{(t)} - \eta\nabla L(\theta^{(t)}) \end{aligned}$$

The L2 penalty has turned into the factor $(1 - \eta\lambda)$ multiplying $\theta^{(t)}$ -- every step, the weights get shrunk slightly towards zero before the gradient update is applied. This is weight decay. In SGD, adding L2 loss and decaying the weights each step are the same operation.

Observation 2: L2 loss in Adam does not result in a weight decay effect

Now feed the regularized gradient $\nabla L^*(\theta)$ into the Adam algorithm directly:

$$\begin{aligned} &\textbf{Adam + L2 loss} \\ &\text{1.}\quad m^{(t+1)} \leftarrow \beta_1 m^{(t)} + (1-\beta_1)\, \nabla L^*(\theta^{(t)}) \\ &\text{2.}\quad s^{(t+1)} \leftarrow \beta_2 s^{(t)} + (1-\beta_2)\, \nabla L^*(\theta^{(t)}) \odot \nabla L^*(\theta^{(t)}) \\ &\text{3.}\quad \hat{m}^{(t+1)} \leftarrow m^{(t+1)} / (1 - \beta_1^t) \\ &\text{4.}\quad \hat{s}^{(t+1)} \leftarrow s^{(t+1)} / (1 - \beta_2^t) \\ &\text{5.}\quad \theta^{(t+1)} \leftarrow \theta^{(t)} - \eta\, \hat{m}^{(t+1)} \oslash (\sqrt{\hat{s}^{(t+1)}} + \epsilon) \end{aligned}$$

The $\lambda\theta$ term now sits inside both $m$ and $s$, and step 5 divides by $\sqrt{\hat{s}}$ -- this is the part of Adam that scales the gradient of each parameter down.

Here is the effect: when we apply L2 regularization, we expect the gradient of a parameter with a large value to be large, pulling it back towards zero. But that large gradient also inflates $\hat{s}$ for that same parameter, and dividing by $\sqrt{\hat{s}}$ scales the update back down. Adam scales down exactly the gradients that the regularizer made large. So the weight decay effect that L2 regularization is supposed to produce does not actually show up.

The fix: AdamW separates Adam from the L2 loss

The idea is simple: instead of using $\nabla L^*(\theta)$ in steps 1 and 2, keep using the plain gradient $\nabla L(\theta)$ there, so the L2 term has no effect on the moment estimates. Then subtract $\lambda\theta$ directly in step 5, applying the L2 regularization directly to the parameter update instead.

$$\begin{aligned} &\textbf{AdamW} \\ &\text{1.}\quad m^{(t+1)} \leftarrow \beta_1 m^{(t)} + (1-\beta_1)\, \nabla L(\theta^{(t)}) \\ &\text{2.}\quad s^{(t+1)} \leftarrow \beta_2 s^{(t)} + (1-\beta_2)\, \nabla L(\theta^{(t)}) \odot \nabla L(\theta^{(t)}) \\ &\text{3.}\quad \hat{m}^{(t+1)} \leftarrow m^{(t+1)} / (1 - \beta_1^t) \\ &\text{4.}\quad \hat{s}^{(t+1)} \leftarrow s^{(t+1)} / (1 - \beta_2^t) \\ &\text{5.}\quad \theta^{(t+1)} \leftarrow \theta^{(t)} - \eta\, \hat{m}^{(t+1)} \oslash (\sqrt{\hat{s}^{(t+1)}} + \epsilon) - \lambda\theta^{(t)} \end{aligned}$$

Steps 1-4 are just Adam on the unregularized loss $L$; only step 5 changed. It is then trivial to show that AdamW has the weight decay effect: the $-\lambda\theta^{(t)}$ term shrinks every parameter directly, with no $\sqrt{\hat{s}}$ in the way to cancel it out, exactly as in the SGD case above.

Summary

  • In SGD, adding L2 loss gives $\theta^{(t+1)} \leftarrow (1-\eta\lambda)\theta^{(t)} - \eta\nabla L(\theta^{(t)})$ -- L2 regularization and weight decay are equivalent.
  • In Adam, the $\lambda\theta$ term passes through the second-moment scaling in step 5, which scales down exactly the gradients that L2 regularization made large -- so the weight decay effect does not appear.
  • AdamW fixes this by keeping the moment estimates (steps 1-2) on the plain gradient $\nabla L(\theta)$, and subtracting $\lambda\theta$ directly in the parameter update (step 5) instead.
