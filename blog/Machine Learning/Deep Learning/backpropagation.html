Backpropagation: From Scratch to Batch

Machine Learning

A concise handwritten version of this note is available as a PDF.

Backpropagation is the algorithm that makes neural networks work. It's how we compute gradients efficiently through the chain rule -- without it, training deep networks would be impossibly slow. Let's implement it from scratch, starting with a single training example and then extending to batches.

Setup: Numerator Layout

Before we dive in, let's establish a convention. We'll stick to numerator layout for derivatives, which means if $z = x^T y$, then:

$$\frac{\partial z}{\partial x} = y^T \quad\text{and}\quad \frac{\partial z}{\partial y} = x^T$$

This convention is crucial because it keeps dimensions consistent and makes the chain rule cleaner. More importantly: always use columns ONLY in the denominator to preserve the chain rule. This will become clear as we derive the gradients.

A Simple Neural Network

Let's build a simple two-layer network:

  • Input: $x \in \mathbb{R}^n$ (a column vector)
  • Intermediate layer: $m = x\Delta_1 + b_1$, then $z = \mathrm{ReLU}(m)$
  • Output: $\hat{y} = z\Delta_2 + b_2$
  • Loss: $L(y, \hat{y}) = (\hat{y} - y)^2$

Here's the architecture visually:

x₁ ──┐
x₂ ──┤
 ⋮   ├──→ m ──→ ReLU ──→ z ──→ ŷ
xₙ ──┘

The dimensions work out like this:

  • $x \in \mathbb{R}^{n \times 1}$
  • $\Delta_1 \in \mathbb{R}^{n \times m}$ (transforms $n$-dimensional input to $m$-dimensional hidden layer)
  • $m, z \in \mathbb{R}^{m \times 1}$
  • $\Delta_2 \in \mathbb{R}^{m \times 1}$ (transforms $m$-dimensional hidden to scalar output)
  • $\hat{y}, y \in \mathbb{R}$ (scalar output)

Forward Pass

The forward pass computes the prediction step by step:

$$\begin{aligned} m &= x\Delta_1 + b_1 \\ z &= \mathrm{ReLU}(m) = \max(0, m) \\ \hat{y} &= z\Delta_2 + b_2 \\ L &= (\hat{y} - y)^2 \end{aligned}$$

Straightforward. Now comes the interesting part -- computing gradients.

Backward Pass: Deriving Gradients

To train the network with gradient descent, we need $\frac{\partial L}{\partial \Delta_2}$, $\frac{\partial L}{\partial b_2}$, $\frac{\partial L}{\partial \Delta_1}$, and $\frac{\partial L}{\partial b_1}$. Let's derive each one using the chain rule.

Gradient w.r.t. $\Delta_2$

Start with the loss and apply the chain rule:

$$\begin{aligned} \frac{\partial L}{\partial \Delta_2} &= \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial \Delta_2} \\ &= 2(\hat{y} - y) \cdot z^T \end{aligned}$$

The second term comes from $\hat{y} = z\Delta_2 + b_2$. When we take $\frac{\partial \hat{y}}{\partial \Delta_2}$, we get $z^T$ (remember: denominator layout means $\Delta_2$ is a column in the denominator, so we transpose $z$).

Gradient w.r.t. $b_2$

Similarly:

$$\begin{aligned} \frac{\partial L}{\partial b_2} &= \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial b_2} \\ &= 2(\hat{y} - y) \cdot 1 \\ &= 2(\hat{y} - y) \end{aligned}$$

This one's easier since $\frac{\partial \hat{y}}{\partial b_2} = 1$.

Gradient w.r.t. $\Delta_1$

Now it gets more interesting. The chain rule needs to go through multiple layers:

$$\frac{\partial L}{\partial \Delta_1} = \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} \cdot \frac{\partial z}{\partial m} \cdot \frac{\partial m}{\partial \Delta_1}$$

Let's break this down:

  • $\frac{\partial L}{\partial \hat{y}} = 2(\hat{y} - y)$ (scalar)
  • $\frac{\partial \hat{y}}{\partial z} = \Delta_2^T \in \mathbb{R}^{1 \times m}$ (since $\hat{y} = z\Delta_2 + b_2$)
  • $\frac{\partial z}{\partial m} = \mathrm{diag}(\mathbf{1}\{M_j > 0\}) \in \mathbb{R}^{m \times m}$ (ReLU derivative)
  • $\frac{\partial m}{\partial \Delta_1}$: here's where dimensions matter!

Since $m = x\Delta_1 + b_1$, we have $M_j = \sum_i x_i \Delta_1(i,j)$. Taking the derivative:

$$\frac{\partial M_j}{\partial \Delta_1} = (0^T, 0^T, \ldots, x^T, \ldots, 0^T) \qquad (\text{where } x^T \text{ is in column } j)$$

This gives us:

$$\frac{\partial m}{\partial \Delta_1} = \begin{pmatrix} x^T & & \\ & \ddots & \\ & & x^T \end{pmatrix} \in \mathbb{R}^{m \times nm}$$

Putting it all together (this is where the magic happens):

$$\frac{\partial L}{\partial \Delta_1} = 2(\hat{y} - y) \cdot \Delta_2^T \cdot \mathrm{diag}(\mathbf{1}\{M_j > 0\}) \cdot (\text{block diagonal of } x^T)$$

After matrix multiplication, this simplifies to:

$$\frac{\partial L}{\partial \Delta_1(i,k)} = 2(\hat{y} - y) \cdot x_i \cdot \Delta_2(k) \cdot \mathbf{1}\{M_k > 0\}$$

Or in matrix form:

$$\frac{\partial L}{\partial \Delta_1} = 2(\hat{y} - y) \cdot x \cdot (\Delta_2 \odot \mathbf{1}\{M > 0\})^T$$

where $\odot$ denotes element-wise multiplication.

Gradient w.r.t. $b_1$

Finally:

$$\begin{aligned} \frac{\partial L}{\partial b_1} &= \frac{\partial L}{\partial \hat{y}} \cdot \frac{\partial \hat{y}}{\partial z} \cdot \frac{\partial z}{\partial m} \cdot \frac{\partial m}{\partial b_1} \\ &= 2(\hat{y} - y) \cdot \Delta_2^T \cdot \mathrm{diag}(\mathbf{1}\{M > 0\}) \cdot I \\ &= 2(\hat{y} - y) \cdot (\Delta_2 \odot \mathbf{1}\{M > 0\}) \end{aligned}$$

The Chain Rule in Practice

Here's the key insight: the chain rule flows backwards through the network. We start from the loss and propagate gradients layer by layer:

  1. Compute $\frac{\partial L}{\partial \hat{y}}$ at the output
  2. Multiply by $\frac{\partial \hat{y}}{\partial z}$ to get gradients w.r.t. the hidden layer
  3. Pass through the ReLU derivative
  4. Multiply by $\frac{\partial m}{\partial \Delta_1}$ to get gradients w.r.t. the first layer weights

This is backpropagation -- literally propagating errors backward through the network.

Extending to Batches

Training on single examples is inefficient. In practice, we process batches of $B$ examples at once. How do we extend our gradients?

Option 1: 3D Tensors

Make $X \in \mathbb{R}^{1 \times n}$ into $X \in \mathbb{R}^{B \times 1 \times n}$, a 3D tensor. NumPy would return tensors for all operations. This works but can be awkward to implement.

Option 2: Matrix Batches (Cleaner)

Make $X \in \mathbb{R}^{1 \times n}$ into $X \in \mathbb{R}^{B \times n}$. Now each row is one training example. We need to update our chain rule accordingly.

The forward pass becomes:

$$\begin{aligned} M &= X\Delta_1 + 1_B b_1^T \qquad (M \in \mathbb{R}^{B \times m}) \\ Z &= \mathrm{ReLU}(M) \\ \hat{Y} &= Z\Delta_2 + b_2 1_{B \times 1} \qquad (\hat{Y} \in \mathbb{R}^{B \times 1}) \end{aligned}$$

The loss is now summed over all examples:

$$L(Y, \hat{Y}) = (Y - \hat{Y})^T (Y - \hat{Y})$$

Batch Gradients

The gradients now involve sums over the batch:

For $\Delta_2$:

$$\begin{aligned} \frac{\partial L}{\partial \Delta_2} &= \frac{\partial L}{\partial \hat{Y}} \cdot \frac{\partial \hat{Y}}{\partial \Delta_2} \\ &= 2(\hat{Y} - Y)^T \cdot Z \qquad \in \mathbb{R}^{m \times 1} \end{aligned}$$

For $b_2$:

$$\begin{aligned} \frac{\partial L}{\partial b_2} &= \frac{\partial L}{\partial \hat{Y}} \cdot \frac{\partial \hat{Y}}{\partial b_2} \\ &= 2(\hat{Y} - Y)^T \cdot 1_{m \times 1} \qquad (\text{sum over batch}) \end{aligned}$$

Note that $\frac{\partial \hat{Y}}{\partial b_2} = 1_{B \times 1}$ (each example contributes 1), so we sum across the batch.

For $\Delta_1$:

$$\frac{\partial L}{\partial \Delta_1} = \frac{\partial L}{\partial \hat{Y}} \cdot \frac{\partial \hat{Y}}{\partial Z} \cdot \frac{\partial Z}{\partial M} \cdot \frac{\partial M}{\partial \Delta_1}$$

The key difference is in $\frac{\partial M}{\partial \Delta_1}$. For each example $k$ in the batch:

$$\frac{\partial M_{kj}}{\partial \Delta_1(i,k)} = \begin{cases} 0 & \text{if } i \neq j \\ X_{k,i} & \text{if } i = j \end{cases}$$

After working through the chain rule (which involves some careful index juggling), we get:

$$\frac{\partial L}{\partial \Delta_1} = \sum_{k=1}^{B} X_{ki} \cdot \Delta_2(l_k, j) \cdot \mathbf{1}\{M_{kj} > 0\}$$

Or more compactly:

$$\frac{\partial L}{\partial \Delta_1} = X^T \cdot \left[2(\hat{Y} - Y) \cdot \Delta_2^T \odot \mathbf{1}\{M > 0\}\right]$$

For $b_1$:

$$\frac{\partial L}{\partial b_1} = \sum_k \left[2(\hat{Y}_k - Y_k) \cdot (\Delta_2 \odot \mathbf{1}\{M_k > 0\})\right]$$

Implementation Tips

When implementing this in NumPy:

  • Always check dimensions. If something doesn't match, you've probably made a transpose error or forgotten to sum over the batch dimension.
  • Use broadcasting carefully. Adding biases to batches relies on NumPy's broadcasting rules -- make sure you understand when $b$ gets added to each row vs each column.
  • Vectorize everything. Avoid loops over the batch dimension -- matrix operations handle this automatically.
  • Test with numerical gradients. Compute $(f(x + \epsilon) - f(x - \epsilon)) / (2\epsilon)$ and compare to your analytical gradients. They should match to high precision.

Why This Matters

Understanding backpropagation at this level is crucial because:

  • It's the foundation of all modern deep learning frameworks (PyTorch, TensorFlow, JAX)
  • Debugging gradient issues requires knowing exactly how gradients flow
  • Custom loss functions, architectures, and layers all need correct gradient implementations
  • Efficiency tricks (gradient accumulation, mixed precision training) manipulate these gradients

Once you understand how to derive and implement these gradients from scratch, frameworks like PyTorch become much less magical -- they're just automating this same process with automatic differentiation.

Summary

Backpropagation is just the chain rule applied systematically:

  1. Start from the loss
  2. Multiply gradients backwards through each layer
  3. Accumulate gradients from all paths (for parameters used in multiple places)
  4. For batches, sum gradients across examples

The key to getting it right: respect the chain rule, keep dimensions consistent, and always use column vectors in the denominator. Do that, and the gradients will flow.
