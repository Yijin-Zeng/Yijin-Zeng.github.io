Backpropagation: From Scratch to Batch

Machine Learning

A concise handwritten version of this note is available as a PDF.

Backpropagation is the algorithm that makes neural networks work. It's how we compute gradients efficiently through the chain rule -- without it, training deep networks would be impossibly slow. Let's implement it from scratch, starting with a single training example and then extending to batches.

Setup: Numerator Layout

Before we dive in, let's establish a convention. We'll stick to numerator layout for derivatives, which means if z = xTy, then:

∂z/∂x = yT    and    ∂z/∂y = xT

This convention is crucial because it keeps dimensions consistent and makes the chain rule cleaner. More importantly: always use columns ONLY in the denominator to preserve the chain rule. This will become clear as we derive the gradients.

A Simple Neural Network

Let's build a simple two-layer network:

  • Input: x ∈ ℝⁿ (a column vector)
  • Intermediate layer: m = xΔ₁ + b₁, then z = ReLU(m)
  • Output: ŷ = zΔ₂ + b₂
  • Loss: L(y, ŷ) = (ŷ - y)²

Here's the architecture visually:

x₁ ──┐
x₂ ──┤
 ⋮   ├──→ m ──→ ReLU ──→ z ──→ ŷ
xₙ ──┘

The dimensions work out like this:

  • x ∈ ℝⁿˣ¹
  • Δ₁ ∈ ℝⁿˣᵐ (transforms n-dimensional input to m-dimensional hidden layer)
  • m, z ∈ ℝᵐˣ¹
  • Δ₂ ∈ ℝᵐˣ¹ (transforms m-dimensional hidden to scalar output)
  • ŷ, y ∈ ℝ (scalar output)

Forward Pass

The forward pass computes the prediction step by step:

m = xΔ₁ + b₁
z = ReLU(m) = max(0, m)
ŷ = zΔ₂ + b₂
L = (ŷ - y)²

Straightforward. Now comes the interesting part -- computing gradients.

Backward Pass: Deriving Gradients

To train the network with gradient descent, we need ∂L/∂Δ₂, ∂L/∂b₂, ∂L/∂Δ₁, and ∂L/∂b₁. Let's derive each one using the chain rule.

Gradient w.r.t. Δ₂

Start with the loss and apply the chain rule:

∂L/∂Δ₂ = (∂L/∂ŷ) · (∂ŷ/∂Δ₂)
       = 2(ŷ - y) · zT

The second term comes from ŷ = zΔ₂ + b₂. When we take ∂ŷ/∂Δ₂, we get zT (remember: denominator layout means Δ₂ is a column in the denominator, so we transpose z).

Gradient w.r.t. b₂

Similarly:

∂L/∂b₂ = (∂L/∂ŷ) · (∂ŷ/∂b₂)
       = 2(ŷ - y) · 1
       = 2(ŷ - y)

This one's easier since ∂ŷ/∂b₂ = 1.

Gradient w.r.t. Δ₁

Now it gets more interesting. The chain rule needs to go through multiple layers:

∂L/∂Δ₁ = (∂L/∂ŷ) · (∂ŷ/∂z) · (∂z/∂m) · (∂m/∂Δ₁)

Let's break this down:

  • ∂L/∂ŷ = 2(ŷ - y) (scalar)
  • ∂ŷ/∂z = Δ₂T ∈ ℝ¹ˣᵐ (since ŷ = zΔ₂ + b₂)
  • ∂z/∂m = diag(𝟙{Mⱼ > 0}) ∈ ℝᵐˣᵐ (ReLU derivative)
  • ∂m/∂Δ₁: here's where dimensions matter!

Since m = xΔ₁ + b₁, we have Mⱼ = Σᵢ xᵢΔ₁(i,j). Taking the derivative:

∂Mⱼ/∂Δ₁ = (0T, 0T, ..., xT, ..., 0T)  where xT is in column j

This gives us:

∂m/∂Δ₁ =
┌                ┐
│ xT            │ ∈ ℝᵐˣⁿᵐ
│    ⋱           │
│       xT       │
└                ┘

Putting it all together (this is where the magic happens):

∂L/∂Δ₁ = 2(ŷ - y) · Δ₂T · diag(𝟙{Mⱼ > 0}) · (block diagonal of xT)

After matrix multiplication, this simplifies to:

∂L/∂Δ₁(i,k) = 2(ŷ - y) · xᵢ · Δ₂(k) · 𝟙{Mₖ > 0}

Or in matrix form:

∂L/∂Δ₁ = 2(ŷ - y) · x · (Δ₂ ⊙ 𝟙{M > 0})T

where ⊙ denotes element-wise multiplication.

Gradient w.r.t. b₁

Finally:

∂L/∂b₁ = (∂L/∂ŷ) · (∂ŷ/∂z) · (∂z/∂m) · (∂m/∂b₁)
       = 2(ŷ - y) · Δ₂T · diag(𝟙{M > 0}) · I
       = 2(ŷ - y) · (Δ₂ ⊙ 𝟙{M > 0})

The Chain Rule in Practice

Here's the key insight: the chain rule flows backwards through the network. We start from the loss and propagate gradients layer by layer:

  1. Compute ∂L/∂ŷ at the output
  2. Multiply by ∂ŷ/∂z to get gradients w.r.t. the hidden layer
  3. Pass through the ReLU derivative
  4. Multiply by ∂m/∂Δ₁ to get gradients w.r.t. the first layer weights

This is backpropagation -- literally propagating errors backward through the network.

Extending to Batches

Training on single examples is inefficient. In practice, we process batches of B examples at once. How do we extend our gradients?

Option 1: 3D Tensors

Make X ∈ ℝ¹ˣⁿ into X ∈ ℝᴮˣ¹ˣⁿ, a 3D tensor. NumPy would return tensors for all operations. This works but can be awkward to implement.

Option 2: Matrix Batches (Cleaner)

Make X ∈ ℝ¹ˣⁿ into X ∈ ℝᴮˣⁿ. Now each row is one training example. We need to update our chain rule accordingly.

The forward pass becomes:

M = XΔ₁ + 1ᴮb₁T    (M ∈ ℝᴮˣᵐ)
Z = ReLU(M)
Ŷ = ZΔ₂ + b₂1ᴮₓ₁    (Ŷ ∈ ℝᴮˣ¹)

The loss is now summed over all examples:

L(Y, Ŷ) = (Y - Ŷ)T(Y - Ŷ)

Batch Gradients

The gradients now involve sums over the batch:

For Δ₂:

∂L/∂Δ₂ = (∂L/∂Ŷ) · (∂Ŷ/∂Δ₂)
       = 2(Ŷ - Y)T · Z    ∈ ℝᵐˣ¹

For b₂:

∂L/∂b₂ = (∂L/∂Ŷ) · (∂Ŷ/∂b₂)
       = 2(Ŷ - Y)T · 1ₘₓ₁    (sum over batch)

Note that ∂Ŷ/∂b₂ = 1ᴮₓ₁ (each example contributes 1), so we sum across the batch.

For Δ₁:

∂L/∂Δ₁ = (∂L/∂Ŷ) · (∂Ŷ/∂Z) · (∂Z/∂M) · (∂M/∂Δ₁)

The key difference is in ∂M/∂Δ₁. For each example k in the batch:

∂Mₖⱼ/∂Δ₁(i,k) = {  0       if i≠j
                   { Xₖ,ᵢ    if i=j

After working through the chain rule (which involves some careful index juggling), we get:

∂L/∂Δ₁ = Σₖ₌₁ᴮ Xₖᵢ · Δ₂(lₖ,j) · 𝟙{Mₖⱼ > 0}

Or more compactly:

∂L/∂Δ₁ = XT · [2(Ŷ - Y) · Δ₂T ⊙ 𝟙{M > 0}]

For b₁:

∂L/∂b₁ = Σₖ [2(Ŷₖ - Yₖ) · (Δ₂ ⊙ 𝟙{Mₖ > 0})]

Implementation Tips

When implementing this in NumPy:

  • Always check dimensions. If something doesn't match, you've probably made a transpose error or forgotten to sum over the batch dimension.
  • Use broadcasting carefully. Adding biases to batches relies on NumPy's broadcasting rules -- make sure you understand when b gets added to each row vs each column.
  • Vectorize everything. Avoid loops over the batch dimension -- matrix operations handle this automatically.
  • Test with numerical gradients. Compute (f(x + ε) - f(x - ε)) / (2ε) and compare to your analytical gradients. They should match to high precision.

Why This Matters

Understanding backpropagation at this level is crucial because:

  • It's the foundation of all modern deep learning frameworks (PyTorch, TensorFlow, JAX)
  • Debugging gradient issues requires knowing exactly how gradients flow
  • Custom loss functions, architectures, and layers all need correct gradient implementations
  • Efficiency tricks (gradient accumulation, mixed precision training) manipulate these gradients

Once you understand how to derive and implement these gradients from scratch, frameworks like PyTorch become much less magical -- they're just automating this same process with automatic differentiation.

Summary

Backpropagation is just the chain rule applied systematically:

  1. Start from the loss
  2. Multiply gradients backwards through each layer
  3. Accumulate gradients from all paths (for parameters used in multiple places)
  4. For batches, sum gradients across examples

The key to getting it right: respect the chain rule, keep dimensions consistent, and always use column vectors in the denominator. Do that, and the gradients will flow.
