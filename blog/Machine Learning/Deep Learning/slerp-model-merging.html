SLERP for Model Merging

Machine Learning

A concise handwritten version of this note is available as a PDF.

Model merging is the idea of combining two models into one without retraining. The core operation is interpolating their weight matrices, and the naive approach (linear interpolation) has a subtle but important problem: it shrinks the magnitude (norm) of the result. As illustrated by the figrue below. SLERP fixes this by interpolating along the arc of a sphere.

Geometric intuition: Linear interpolation (LERP) will result the merged vector live on the red line (thus shrinkage); while NLERP and SLERP both resulting the merged vectors on the green arch (keeping the norm unchanged).

Method 1: LERP (Linear Interpolation)

The simplest approach is a direct weighted average of the two vectors:

V = α V₁ + (1 - α) V₂ ,   where α ∈ [0, 1]

Problem: Shrinkage

The norm of the interpolated vector is generally smaller than the norm of either input:

||V||₂  <  ||V₁||₂   or   ||V₂||₂

For model weights, this shrinkage can degrade performance because the magnitudes of weight matrices carry important information about learned representations.

Thus, the interpolated vector should generally have a norm on the same order as the originals.

Method 2: NLERP (Normalized LERP)

NLERP addresses the shrinkage problem by decoupling direction and magnitude, handling each separately:

Step 1: Compute the direction (unit vector)

U = (α V₁ + (1 - α) V₂) / ||α V₁ + (1 - α) V₂||₂

This normalizes the LERP result to a unit vector, so we only care about direction at this stage (norm = 1).

Step 2: Compute the magnitude (scale)

L = α ||V₁||₂ + (1 - α) ||V₂||₂

The target magnitude is a linear interpolation of the original norms. This cares about norm only.

Step 3: Rescale

V ← U · L

We multiply the unit direction by the interpolated magnitude to get the final merged vector.

NLERP fixes the shrinkage problem, but it does not traverse the arc evenly. As α moves from 0 to 1, the interpolated direction does not cover equal angular distances in equal steps.

Method 3: SLERP (Spherical Linear Interpolation)

Compared with NLERP, SLERP moves along the arc at constant angular velocity, producing evenly-spaced intermediate points.

Step 1: Normalize both vectors

V₁' ← V₁ / ||V₁||₂
V₂' ← V₂ / ||V₂||₂

Scale both vectors to unit length so they sit on the same unit sphere (circle in 2D).

Step 2: Compute the angle between them

cos(θ) = V₁' · V₂'       (dot product of unit vectors)
           = (V₁ · V₂) / (||V₁||₂ · ||V₂||₂)

Step 3: Spherical interpolation of direction

U = [sin(αθ) / sin(θ)] V₁' + [sin((1 - α)θ) / sin(θ)] V₂'

Note that ||U||₂ = 1 by construction. As α varies from 0 to 1, U travels from V₂' to V₁' along the great-circle arc, covering equal angles for equal increments of α.

Step 4: Interpolate the magnitude

L = α ||V₁||₂ + (1 - α) ||V₂||₂

Step 5: Rescale

V ← U · L

Comparing SLERP and NLERP

Both methods solve the shrinkage problem of plain LERP and produce vectors with appropriate magnitude. The key difference lies in how they traverse the angular space:

  • SLERP (α: 0 → 1): moves evenly along the circle. Equal increments of α produce equal angular steps. This gives a geometrically uniform interpolation.
  • NLERP (α: 0 → 1): moves unevenly. The angular speed varies. It moves faster near the midpoint and slower near the endpoints. This is because normalizing a linear combination distorts the angular spacing.

In practice, SLERP is preferred for model merging because the even angular traversal means it would be (practially) easier to tune or learn the optimal interpolation parameter &alpha.
