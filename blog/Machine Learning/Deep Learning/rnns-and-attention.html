RNNs and Attention

Machine Learning

A concise handwritten version of this note is available as a PDF.

Before Transformers, the attention mechanism arrives to solve the short-term memory issues with RNNs.

Simple RNN

Consider a single neuron with output y and input x, feeding its own previous output back in at every step. Unrolled through time, this looks like:

The blue arrows are the recurrence: each step's output feeds into the next step's computation.

The formulation is

ŷ⁽ᵗ⁾ = σ( wy · ŷ⁽ᵗ⁻¹⁾ + wxᵗ x⁽ᵗ⁾ + b )

where σ is the activation function, wy is a scalar, wx is a vector of length d (the dimension of inputs), and b is a scalar.

With multiple neurons, the output y and input x are vectors, and the same unrolling applies (same diagram, just vector-valued at every arrow), except the ŷ⁽ᵗ⁻¹⁾ terms at each time step are also known as hidden states:

ŷ⁽ᵗ⁾ = σ( Wyᵗ ŷ⁽ᵗ⁻¹⁾ + Wxᵗ x⁽ᵗ⁾ + b )

Apparently, we can stack many layers of RNN to make our model more representative.

Problem with Simple RNN: short-term memory. ŷ⁽ᵗ⁾ contains less and less information about x⁽¹⁾ as t increases.

LSTM

LSTM (long short-term memory) cells solve the short-term memory problem partly by introducing gates to divide memory into short-term memory h⁽ᵗ⁾ and long-term memory C⁽ᵗ⁾.

All four boxes take both h⁽ᵗ⁻¹⁾ and x⁽ᵗ⁾ as input. The forget and input gates decide how much of C⁽ᵗ⁻¹⁾ to keep versus overwrite with a new candidate, giving C⁽ᵗ⁾; the output gate then decides how much of tanh(C⁽ᵗ⁾) becomes h⁽ᵗ⁾ and y⁽ᵗ⁾.

Pros of LSTM: it decides what information to forget and keep, so in theory important information can be kept.

Cons of LSTM: it is very expensive to compute.

GRU

A simplified version of LSTM is GRU (gated recurrent units), which only has a forget gate and an input gate, and merges the short-term and long-term memory into a single hidden state h⁽ᵗ⁾.

One sigmoid vector (bottom left box) controls both gates: it feeds the input gate directly, and its complement (1−·) feeds the forget gate.

Encoder-Decoder for Machine Translation

An encoder-decoder network for machine translation works as follows. The encoder is an RNN that produces y⁽⁰⁾, y⁽¹⁾, ..., y⁽ᵗ⁾, and the last of these is used to initialize the hidden state of the first layer of the decoder. The decoder has an embedding layer and generates tokens autoregressively, e.g. translating "milk, drink, I" (the encoder input is reversed, because "I" is normally the first word to translate) into a sequence of Chinese tokens ending in <eos>.

Decoder during inference: autoregressive. At time t, layer i's hidden state hᵢ⁽ᵗ⁻¹⁾ feeds layer i+1's hᵢ₊₁⁽ᵗ⁻¹⁾. Each layer deals with one time step and moves immediately to the next layer.

Decoder during training: teacher forcing. The decoder behaves exactly like the encoder by applying teacher forcing — each layer processes all time steps before moving to the next layer. For predicting y⁽ᵗ⁾, we assume the model predicted y⁽¹⁾, ..., y⁽ᵗ⁻¹⁾ correctly.

Problem with standard encoder-decoder: information bottleneck. We need to encode the whole sentence into a fixed-length vector. As the sequence becomes longer, earlier information gets diluted.

Bahdanau Attention

In a standard encoder-decoder, only the last embedding of the encoder is used for decoding, because it is the only one with all of the input's information. In Bahdanau attention, at each decoder time step, all encoder embeddings y⁽⁰⁾, y⁽¹⁾, ..., y⁽ᵗ⁾ are weighted-averaged instead. This new embedding determines which word the decoder should focus on at that time step.

The formulas are

e(t,i) = vᵗ tanh( W [ h_{t-1} ; y⁽ⁱ⁾ ] )

s(t,i) = exp(e(t,i)) / Σᵢ exp(e(t,i))

weighted average = Σᵢ y⁽ⁱ⁾ s(t,i)

where h_{t-1} is the decoder's hidden state at time t-1, used to determine the distribution of the next token at time t-1.

How to use it: (1) concatenate it with the current input before feeding into the RNN, or (2) use it for the output only — get y_(t) as usual, then do softmax(Wc [ y_(t) ; c_(t) ]).

Why is attention mechanism revolutionary? It breaks the information bottleneck. Without attention, the whole sentence — 3 words long or 100 words long — is compressed into one fixed-length vector. With attention, information is represented as number of words × vector length, so it scales dynamically with sequence length.
