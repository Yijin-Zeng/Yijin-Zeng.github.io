Parameter Initialization

Machine Learning

A concise handwritten version of this note is available as a PDF.

It is well-known that proper parameters initialization is critical for training (especially deep) neural networks.

What Goes Wrong Without Proper Initialization

Consider a standard feedforward layer:

fk = βk + Ωkhk
   = βk + Ωk a(fk-1)

where a(·) is the activation function (say, ReLU). Suppose we initialize βk to 0 and every element of Ωk independently from N(0, σ²). Then during forward process:

  • If σ is small (e.g. 0.001), the magnitude of fk is much smaller than fk-1 -- activations shrink at every layer.
  • If σ is large (e.g. 100), the magnitude of fk is much larger than fk-1 -- activations blow up.

In a deep network this snowballs: the magnitude problem gets worse and worse through each layer.

And the backward pass has exactly the same problem. The gradient flowing into layer k-1 is:

∂L/∂fk-1 = (∂L/∂fk) · (∂fk/∂fk-1)
        = (∂L/∂fk) · Ωk · diag(I{fk-1 ≥ 0})    (if a = ReLU)

The gradient gets multiplied by Ωk at every layer, so its scale depends directly on the scale of Ωk. Initialize badly and the gradients either shrink towards zero (vanishing) or grow without bound (exploding). Either way, the training would be unstable and hard.

Proper Initialization to Keep the Variance Constant

So what would "proper" initialization look like? The idea is to choose σ² well so that the variance stays unchanged as signals pass through each layer, in both directions:

Forward pass:   Var(fk) ≈ Var(fk-1)
Backward pass:  Var(∂L/∂fk-1) ≈ Var(∂L/∂fk)

If neither the activations nor the gradients change scale layer by layer, we can stack as many layers as we like without the signal degrading.

Forward Pass: Deriving the Variance

Some notation to keep things readable: write f = fk-1, f′ = fk, Ω = Ωk, and fi for the i-th element. Biases are initialized to 0. The i-th output is f′i = βi + Σⱼ Ωij a(fj), summing over the m neurons of the previous layer.

First, the mean:

E(f′i) = E(βi) + Σⱼ E(Ωij a(fj))
      = 0 + Σⱼ E(Ωij) E(a(fj))    (weights independent of layer outputs)
      = Σⱼ 0 · E(a(fj)) = 0

The expectation splits because the parameters are initialized independently of the layer outputs. For the variance:

Var(f′i) = Var(Σⱼ Ωij a(fj))
        = Σⱼ Var(Ωij) Var(a(fj))
        = Σⱼ σ²Ω (E(a(fj)²) - E²(a(fj)))
        = Σⱼ σ²Ω E(a(fj)²)

Use the fact that a = ReLU and split by the law of total expectation:

E(a(fj)²) = P(fj > 0) E(a(fj)² | fj > 0) + P(fj ≤ 0) E(a(fj)² | fj ≤ 0)
         = 1/2 *  E(fj² | fj > 0) + 0

Here we assume that the input is symmetric around 0 (reasonable if we preprocess each input to standard normal), so fj is positive half the time and the negative half gets zeor out by ReLU. Using the symmetry again, E(fj² | fj > 0) contributes exactly half of the full second moment, so E(a(fj)²) = 1/2 * σ²f. Putting it together, we have:

Var(f′i) = 1/2 *  m σ²Ω σ²f

So, if we want σ²f′ = σ²f, we need to let:

σ²Ω = 2/m        (He initialization)

where m is the number of neurons in the previous layer (i.e. the number of columns of Ωk, the "fan-in"). The factor of 2 exists purely because ReLU throws away half the variance -- I find that a satisfying way to remember it.

Backward Pass

For the backward pass, the logic is similar. Denote g′ = ∂L/∂fk and g = ∂L/∂fk-1, so gi = Σⱼ g′j Ωji 𝟙{fi ≥ 0}, now summing over the m′ neurons of the next layer. The mean is 0 by the same independence argument. For the variance:

Var(gi) = E((Σⱼ g′j Ωji I{fi ≥ 0})²)
        = Σⱼ E(g′j²) E(Ωji²) E(I{fi ≥ 0}²)    (cross terms vanish; assuming independence)
        = m′ σ²g′ σ²Ω · 1/2

The indicator is 1 with probability 1/2 (symmetry again), which is where the final 1/2 comes from. So if we want σ²g = σ²g′, we need to have:

σ²Ω = 2/m′

Overall, to keep the variance unchanged during backward propogation, we need to initialize the variance of the parameters to be m′ (fan-out).

When Fan-In and Fan-Out Disagree

Here we are with a small conflict: the forward pass wants σ² = 2/m, the backward pass wants σ² = 2/m′.

  • If m = m′ (equal layer widths), there's no conflict, we can keep both forward and backward passes stable. (One reason we should choose networks with uniform hidden widths.)
  • If m ≠ m′, we compromise by replacing m (or m′) with their average (m + m′)/2, so σ²Ω = 4/(m + m′).

Neither pass is perfectly preserved in the second case, but neither is badly broken either, and in practice it works. This averaging trick is the same move Glorot and Bengio made for linear/tanh activations (where the factor is 2/(m + m′) instead, no ReLU halving); He et al. adapted the analysis to ReLU, which is where the extra 2 comes from.

Summary

  • Bad initialization snowballs layer by layer: activations and gradients either vanish or explode.
  • To fix this, we need to initialize the parameters well by choosing σ²Ω so that variance is preserved through each layer for both forwards and backwards.
  • For ReLU, the forward pass demands σ² = 2/m (He initialization); the backward pass demands σ² = 2/m′; the factor 2 is ReLU's fault for zero out half the signal.
  • When m ≠ m′, we compromise with σ² = 4/(m + m′).
