Parameter Initialization

Machine Learning

A concise handwritten version of this note is available as a PDF.

The first time I trained a deep network with weights drawn from a plain N(0, 1), the loss just sat there. Not diverging, not improving -- just flat. It turns out the network was dead before the first gradient step even happened, and the culprit was something I had treated as an afterthought: how you initialize the parameters. Why would random numbers you pick before training matter so much? Let's work it out.

What Goes Wrong Without Proper Initialization

Consider a standard feedforward layer:

fk = βk + Ωkhk
   = βk + Ωk a(fk-1)

where a(·) is the activation function (say, ReLU). Suppose we initialize βk to 0 and every element of Ωk independently from N(0, σ²). What happens as the signal flows forward?

  • If σ is small (e.g. 0.001), the magnitude of fk is much smaller than fk-1 -- activations shrink at every layer.
  • If σ is large (e.g. 100), the magnitude of fk is much larger than fk-1 -- activations blow up.

In a deep network this compounds: the magnitude problem gets worse and worse through each layer. Twenty layers of "slightly too small" is exponentially too small.

And the backward pass has exactly the same disease. The gradient flowing into layer k-1 is:

∂L/∂fk-1 = (∂L/∂fk) · (∂fk/∂fk-1)
        = (∂L/∂fk) · Ωk · diag(𝟙{fk-1 ≥ 0})    (if a = ReLU)

The gradient gets multiplied by Ωk at every layer, so its scale depends directly on the scale of Ωk. Initialize badly and the gradients either shrink towards zero (vanishing) or grow without bound (exploding). Either way: hard to train. This isn't a "training is a bit slow" problem -- with vanishing gradients, training effectively never starts.

The Fix: Keep the Variance Constant

So what would "good" initialization look like? The idea is simple and, I think, quite elegant: choose σ² so that the variance stays unchanged as signals pass through each layer, in both directions:

Forward pass:   Var(fk) ≈ Var(fk-1)
Backward pass:  Var(∂L/∂fk-1) ≈ Var(∂L/∂fk)

If neither the activations nor the gradients change scale layer by layer, we can stack as many layers as we like without the signal degrading. Let's derive what σ² has to be.

Forward Pass: Deriving the Variance

Some notation to keep things readable: write f = fk-1, f′ = fk, Ω = Ωk, and fi for the i-th element. Biases are initialized to 0. The i-th output is f′i = βi + Σⱼ Ωij a(fj), summing over the m neurons of the previous layer.

First, the mean:

E(f′i) = E(βi) + Σⱼ E(Ωij a(fj))
      = 0 + Σⱼ E(Ωij) E(a(fj))    (weights independent of layer outputs)
      = Σⱼ 0 · E(a(fj)) = 0

The expectation splits because the parameters are initialized independently of the layer outputs -- the weights haven't seen any data yet. Now the variance:

Var(f′i) = Var(Σⱼ Ωij a(fj))
        = Σⱼ Var(Ωij) Var(a(fj))
        = Σⱼ σ²Ω (E(a(fj)²) - E²(a(fj)))
        = Σⱼ σ²Ω E(a(fj)²)

Now use the fact that a = ReLU and split by the law of total expectation:

E(a(fj)²) = P(fj > 0) E(a(fj)² | fj > 0) + P(fj ≤ 0) E(a(fj)² | fj ≤ 0)
         = ½ E(fj² | fj > 0) + 0

Here I'm assuming the input is symmetric around 0 (reasonable if we preprocess each input to standard normal), so fj is positive half the time and the negative half gets killed by ReLU. Using symmetry again, E(fj² | fj > 0) contributes exactly half of the full second moment, so E(a(fj)²) = ½ σ²f. Putting it together:

Var(f′i) = ½ m σ²Ω σ²f

This is the punchline. If we want σ²f′ = σ²f, we need:

σ²Ω = 2/m        (He initialization)

where m is the number of neurons in the previous layer (i.e. the number of columns of Ωk, the "fan-in"). The factor of 2 exists purely because ReLU throws away half the variance -- I find that a satisfying way to remember it.

Backward Pass: Same Logic, Different Direction

Does the same σ² also keep gradients stable? Almost. Denote g′ = ∂L/∂fk and g = ∂L/∂fk-1, so gi = Σⱼ g′j Ωji 𝟙{fi ≥ 0}, now summing over the m′ neurons of the next layer. The mean is 0 by the same independence argument. For the variance:

Var(gi) = E((Σⱼ g′j Ωji 𝟙{fi ≥ 0})²)
        = Σⱼ E(g′j²) E(Ωji²) E(𝟙{fi ≥ 0}²)    (cross terms vanish; assuming independence)
        = m′ σ²g′ σ²Ω · ½

The indicator is 1 with probability ½ (symmetry again), which is where the final ½ comes from. So if we want σ²g = σ²g′, we need:

σ²Ω = 2/m′

Same formula, but with m′ -- the fan-out -- instead of the fan-in m. The forward and backward passes are pulling in slightly different directions.

When Fan-In and Fan-Out Disagree

Here we are with a small conflict: the forward pass wants σ² = 2/m, the backward pass wants σ² = 2/m′.

  • If m = m′ (equal layer widths), there's no conflict -- one choice keeps both forward and backward passes stable. One more reason networks with uniform hidden widths are pleasant to work with.
  • If m ≠ m′, we compromise by replacing m (or m′) with their average (m + m′)/2, giving σ²Ω = 4/(m + m′).

Neither pass is perfectly preserved in the second case, but neither is badly broken either -- and in practice that's enough. This averaging trick is the same move Glorot and Bengio made for linear/tanh activations (where the factor is 2/(m + m′) instead, no ReLU halving); He et al. adapted the analysis to ReLU, which is where the extra 2 comes from.

Summary

  • Bad initialization compounds layer by layer: activations and gradients either vanish or explode, and with vanishing gradients training never really starts.
  • The fix is a design principle, not a trick: pick σ²Ω so that variance is preserved through each layer, forwards and backwards.
  • For ReLU, the forward pass demands σ² = 2/m (He initialization); the backward pass demands σ² = 2/m′; the factor 2 is ReLU's fault for killing half the signal.
  • When m ≠ m′, split the difference: σ² = 4/(m + m′).
  • The derivation leans on assumptions worth remembering: weights independent of activations, inputs symmetric around 0 (hence: standardize your inputs), and independence across terms in the backward sum.

My Take

What I like about this derivation is how little machinery it needs -- it's just means, variances, and the law of total expectation, yet it produces a formula that every deep learning framework ships as a default (kaiming_normal_ in PyTorch is exactly σ² = 2/m). Before working through this, "He initialization" was a magic string I passed to an initializer; now the 2 in 2/m reads as "ReLU deletes half the variance, so pre-inflate by 2". I also think the caveats deserve more attention than they usually get: the whole argument assumes symmetric, standardized inputs and independence everywhere, which is exactly true only at step zero of training. The moment gradients update the weights, the assumptions start eroding -- initialization buys you a good starting point, not a guarantee. But in deep networks, a good starting point is the difference between training and staring at a flat loss curve.
