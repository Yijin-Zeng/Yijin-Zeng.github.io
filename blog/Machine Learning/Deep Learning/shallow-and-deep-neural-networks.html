Shallow and Deep Neural Networks

Machine Learning

A concise handwritten version of this note is available as a PDF.

Neural networks with one hidden layer are normally called shallow, and those with multiple hidden layers are called deep. But why does depth matter? Can't a wide shallow network do everything a deep network can? Let's explore what makes deep networks special.

Shallow Neural Networks

A shallow neural network has exactly one hidden layer between the input and output. The architecture is simple:

  • Input layer: your data $x$
  • Hidden layer: $h$ neurons that compute intermediate representations
  • Output layer: produces the final prediction

Mathematical formulation: For a shallow network with $h$ hidden units, the computation looks like:

$$\begin{aligned} h_i &= \theta_{i0} + \theta_{i1} \cdot x \qquad \text{for } i = 1, \ldots, h \\ y &= \beta_0 + \beta_1 \cdot a(h_1) \end{aligned}$$

where $a(\cdot)$ is the activation function (ReLU, sigmoid, etc.). The hidden layer computes linear combinations of the input, then the activation function decides if and how much each neuron should "fire."

The Universal Approximation Theorem

Here's the remarkable result: a shallow neural network can approximate any continuous function to any specified precision.

This sounds amazing! If shallow networks are universal approximators, why bother going deep?

The intuition: Think of building a function piece by piece. With enough neurons, you can create tons of tiny linear segments. By combining these with different activation functions—constant slopes, deviations, sigmoids—you can approximate arbitrarily complex curves. Each neuron contributes a "piece" of the function, and together they assemble the full approximation.

However, there's a catch: "can approximate" doesn't mean "efficiently approximates." The theorem says it's possible in theory, but it might require an impractically huge number of neurons.

Linear Regions: Shallow vs. Deep

Here's where things get interesting. Neural networks with ReLU activations create piecewise linear functions—the output is made up of multiple linear segments glued together at "kink" points.

Shallow Networks

For a shallow network:

  • When input is 1D, there are at most $D + 1$ linear regions (or at most one fold)
  • When input is in $\mathbb{R}^k$ and there are $D$ hidden units, there are at most $2^D$ linear regions

So if you have 10 hidden neurons, you can create at most $2^{10} = 1{,}024$ different linear regions. That sounds like a lot!

Deep Networks

Deep networks have multiple hidden layers, typically denoted $A_1$, $A_2$, ..., $A_n$. The computation flows through each layer:

$$\begin{aligned} A_1 &= a\left(\theta_1^{(1)} + \theta_{11}^{(1)} x\right) \\ A_2 &= a\left(\theta_2^{(2)} + \theta_{21}^{(2)} A_1 + \ldots + \theta_{2h}^{(2)} A_1\right) \\ &\;\;\vdots \\ y &= a\left(\theta_y^{(n+1)} + \theta_{y1}^{(n+1)} A_n\right) \end{aligned}$$

Equivalently, we can write this as nested compositions:

$$y = a_m\left(\beta_m^T \Omega_m\, a_2\left(\beta_2^T \Omega_2\, a\left(\beta_1^T \Omega_1 x\right)\right) \ldots\right)$$

Like shallow networks, deep networks can also approximate any continuous function. But here's the key insight:

Given the same number of parameters, deep neural networks create exponentially more linear regions than shallow ones.

Why Depth Matters: A Simple Example

Consider a simple network architecture. As we pass data through multiple layers with activation functions, each layer transforms the input space. The visualizations show how:

  • Layer 1 creates initial linear segments
  • Layer 2 folds and transforms those segments further
  • After activation, you get even more complex boundaries

By the time you reach the final layer, the same number of parameters has carved the input space into many more regions. This is the power of composition—each layer doesn't just add regions, it multiplies them.

The Practical Takeaway

Both shallow and deep networks are universal approximators in theory. But in practice:

  • Shallow networks might need an enormous number of neurons to approximate complex functions accurately. This means more parameters, more memory, and more training data.
  • Deep networks can represent the same functions with far fewer parameters by exploiting compositional structure. Each layer learns hierarchical features—edges, then textures, then objects—building complexity incrementally.

Think of it like building with LEGO. A shallow network tries to build everything directly from individual bricks. A deep network builds small modules first, then combines those modules into bigger structures, then assembles those structures into the final object. The hierarchical approach is exponentially more efficient.

This is why modern deep learning relies on depth. It's not that shallow networks can't work—they can, theoretically. But deep networks achieve the same expressiveness with dramatically fewer parameters, making them faster to train and better at generalizing from limited data.
